# CUMCM 2026 提示词模板

配合 `交付/1_skill/`（即 `8_skill/cumcm-abc/`）使用。
装好 skill 后直接说"开始建模"即可走 10 阶段流程；下面这些是**不装 skill 也能用**的独立提示词，
或用于在流程中插入某个专项动作。

**结构**：0（判型+选题）→ 1（通用深挖）→ **1B（按题型深挖，五选一）**
→ 2（求解与呈现）→ 3（摘要）→ 4（终审）→ 5（纠偏）。

**用法约定**：`【】` 里的内容替换成你的实际情况；`> ` 开头的是给你看的说明，不要粘进去。

---

## 0. 总起：开赛后第一条指令

> 开赛拿到题面后发这一条。它把"选题 + 题型判别 + 反模式排查"压在一轮里完成。

```
你是 CUMCM 国赛本科组的建模顾问。我给你 A/B/C 三道题的题面，请完成：

1. 逐题判定题型（**五选一**，题号不是题型）：
   机理/几何/运动类 | 工程反演/测量类 | 数据/统计类 | 统计决策类 | 成分数据类
   判据：给物理规律/几何关系且数据量小 → 机理类；给测量信号要反推物理量 → 反演类；
        给观测表要找关系/分组/判定 → 数据类；给参数表无数据附件做离散决策 → 决策类；
        各分量之和为常数 → 成分数据类（**方法全变**）。
   给出判定依据（引题面原话）。判完后按第 1B 条挑对应的深挖提示词。
2. 逐题列出：子问题数、每问要交付的结果文件、数据结构上的决定性事实
   （观测是否独立、变量是否受约束、是否有配对样本、参数是否随条件变化）。
3. 逐题给出我们最可能拿分的路线，以及最可能踩的 3 个坑。
4. 最后给选题建议，按「与我们能力匹配度 / 官方偏好路数的稳定性 / 可交付性」三项打分。

硬约束（每问都要检查）：
- 组委会连续四年批评"不从问题出发，乱套方法"，点名 AHP、模糊综合评价、熵权法、
  回归、主成分、聚类、灰色、遗传算法、神经网络、深度学习。不是禁用，
  但每个方法必须能说出"为什么这道题必须用它"。判据：方法段落换到另一道题上
  如果照样成立，就是套路。
- 上监督学习之前先问：训练标签在哪里？没有配对样本就不是监督学习问题。
- 数据各分量和为常数（成分/占比）时，必须先归一化 + 中心对数比变换(CLR)，
  Pearson 相关在成分数据上有偏负倾向、结论是假的。
- 机理类不能拿数据硬拟合；写了模型必须给具体算法。

题面如下：
【粘贴 A 题题面】
【粘贴 B 题题面】
【粘贴 C 题题面】
```

## 1. 单题深挖：Stage 2–3（结构诊断 + 选模型）

```
我们选了【X】题。请按下面顺序输出，不要跳步：

一、数据/结构诊断表
   逐行列出「事实 → 出处（题面原话）→ 建模含义」。
   必须覆盖：观测是否独立（同一对象多条记录？）、因变量取值范围与是否需变换、
   变量间是否存在和为常数等约束、参数是否随条件变化（需按条件取值/插值）、
   样本是否有偏、要预测的量在数据里有没有配对观测。

二、要不要做数据预处理
   判据：题目给的是原始流水/交易数据 → 需要聚合、异常处理、筛选；
        给的是已整理的检测/观测表 → 默认不清洗。
   注意：看着像"质量指标"的列（GC 含量、读段数、过滤比例）多半是
        给你做分层校正的协变量，不是筛样本的门槛。把协变量当过滤条件等于自己扔信息。

三、逐问方法选择
   每问给出：主模型 + 求解算法 + 为什么这道题必须用它（一句话）+ 交付物。
   有解析解的情形必须先给解析解，再用数值验证——不要直接上搜索算法。
   组合数在几十以内的离散决策，全枚举即精确解；枚举前先用逻辑必要条件剪枝。
   命题人的解法节奏几乎都是"从最简情形起步，逐步加约束"，请照这个节奏组织。

四、反模式自查
   逐条回答"是/否/不适用"并说明：
   ① 有序连续变量（BMI/年龄/水深）分组是否误用了聚类？
      正解是在分点集合上优化"组内差异小、组间差异大" + 惩罚项定组数。
   ② 罕见事件的"异常判定"是否被当成普通二分类？
      正解是经验零分布 + 分层校正 + 多重检验校正 + 三级判定（阴性/可疑/阳性）。
   ③ 方向/参数/分组数的选择有没有给证明或引权威规范？
      工业工程类先查国标（如 GB/T 2828 抽样检验、GB 12327 海道测量规范）。
   ④ 有没有把主成分当成"变量选择"？（PCA 一个原变量都没剔除，不算选择）
   ⑤ 题面给的定义是否带前提条件、本问是否仍然成立？
      不成立要显式重述推广定义，并做方向对称性检查（交换两对象顺序结果应不变）。

题面：【粘贴】
附件结构：【粘贴列名说明 / 前 20 行】
```

## 1B. 按题型深挖：接在第 1 条后面用

> **题号不是题型。** B 题最近四年是 2022B 计算几何、2023B 几何+优化、
> 2024B 统计决策、2025B 光学反演——**零次评价类**。
> 先用第 0 条判出题型，再从下面五条里挑**对应的一条**追加。挑错了比不用更糟。

### 1B-① 机理/几何/运动类

```
本题判定为机理/几何/运动类。在上一轮基础上补充：

一、先找解析解
   有没有闭式解？有就必须先给，数值只用来验证。
   （2022A 官方给出最优阻尼的闭式解 c_p = √((p₁²+p₂²)/(q₁²+q₂²))，
     这种题上遗传算法搜索是丢分。）
   空间几何关系优先用"点法式"（方向与法向内积为零）——2023B 官方原话：
   "公式推导最简单的方法是'点法式'…公式过于复杂会失去直观性"。

二、把该自己推的量列出来
   组合体的质心、转动惯量、水线面积，题目通常不给。
   非惯性系要显式写科氏力与牵连惯性力，或改用拉格朗日方程。
   初值先解静力平衡，别取全零。

三、极限退化自检清单（必做，不是可选）
   逐条写出："令【参数】取【边界值】，公式应退化为【上一问的哪个结果】"。
   **先枚举模型的每个自由度**（每根坐标轴、每个角的每个符号、每个可取极限的参数），
   逐一标注由哪条自检覆盖，空白格就是漏洞。
   （2023A 演练里 10 项自检全过，仍漏掉方位角起算方向搞反——
     因为它们只验了东西方向，南北方向一次都没验过。）

四、若涉及遮蔽/覆盖/可见性
   ① 离散判别点集只取表面，不放内部点（导弹看不到内部点）。
   ② 能对参数求导解析求极值就别加密采样。
   ③ 多遮挡体共同遮蔽有体积目标时，量词是 ∀点∃体，不是 ∃体∀点。
   ④ 时长用"网格定位 + 二分细化"，不要直接二分。
```

### 1B-② 工程反演/测量类

```
本题判定为工程反演/测量类。在上一轮基础上补充：

一、观测量 ≠ 被估量
   写下一行："我量到的量 = 被估量的什么函数"。
   若右端含被估量的**导数**，就不能直接代反演公式。
   （2025B 里量到的是群量 L_g = d(νL)/dν = L + ν·dL/dν，
     折射率有色散时与 L 不等，混用让厚度偏 +5.89%，而谱看起来完全正常。）

二、给正演模型留一个"标定增益"
   凡是用**绝对幅值**反演参数的做法，都对仪器标定偏差敞口。
   留 g、b 两个自由度，换来对一整类系统误差的免疫。
   （2025B 实测：留了增益后独立解出附件间 10% 的标定差。）

三、题面说"某参数不是常数、与 X 有关" = 要你把它当待估量
   不是提示你去查文献值。先算数据量够不够定那几个参数。
   （2025B 官方原话："按常数计算…**没有达到题目的要求**"。）

四、多工况数据默认是联合约束，不是联立求解
   联合拟合 = 同一组参数受更多约束（良态）；
   联立求解 = 用工况间之差解新增未知量（常常病态）。
   要联立就先算误差放大倍数。（2025B 两角联立的放大倍数是 356×。）

五、交叉验证用"未参与定目标量的参数是否自动对上"
   比"两次算出来一样"强得多——它检验的是模型结构，不只是数值稳定性。
```

### 1B-③ 数据/统计类

```
本题判定为数据/统计类。在上一轮基础上补充：

一、要不要预处理，按数据形态判，不要照搬讲评里的某句话
   给原始流水/交易数据 → 需要聚合、异常处理、筛选；
   给已整理的检测/观测表 → 默认不清洗。
   看着像"质量指标"的列（GC 含量、读段数、过滤比例）多半是
   给你做**分层校正的协变量**，不是筛样本的门槛——当过滤条件用等于自己扔信息。

二、观测独立性
   同一对象有多条记录 → 混合效应模型 / GEE，不能当独立样本。
   报 R² 时说清是边际还是条件；随机效应会让边际 R² 虚高。

三、有序连续变量分组不是聚类
   BMI/年龄/水深这类有序变量，正解是在分点集合上优化
   "组内差异小、组间差异大" + 惩罚项定组数，不是 K-means。

四、罕见事件的判定不是普通二分类
   正解 = 经验零分布 + 分层校正 + 多重检验校正 + 三级判定（阴性/可疑/阳性）。

五、上监督学习之前先问：训练标签在哪里？
   没有配对样本就不是监督学习问题。
```

### 1B-④ 统计决策类（给参数表、无数据附件）

```
本题判定为统计决策类。在上一轮基础上补充：

一、先数组合数
   几十以内就**全枚举**，并在正文写明"因组合数仅 N，枚举即精确解"——这句话本身是得分点。
   别上遗传/退火/粒子群。

二、枚举前先用逻辑必要条件剪枝
   （2024B 官方原文："如果在装配成品时，零配件没有做过检测，则拆解时一定要对
     零配件做检测，否则不合格的零配件永远在成品中，将会有无限次的拆解或赔偿。"）

三、有回收/退货/返工就是闭环
   一趟流水线算不出期望利润，要不动点迭代或等比级数求解到收敛。

四、"检测次数尽可能少"是在提示序贯抽样（SPRT）

五、参数由抽样得到时，交付的不是重算一遍数字，是**决策翻转边界**
   注意：用正态近似代替二项精确检验**不算错**。2024B 官方原话：
   "不能说一定是错误的…重要的是，抽样数要与次品数有关。"
```

### 1B-⑤ 成分数据类（各分量之和为常数）

```
本题判定为成分数据类。**这一类方法全变**，在上一轮基础上补充：

一、成分数据活在单纯形上，不是欧氏空间
   流程：剔除无效样本 → 归一化到 100% → 零值用小量 ε 填充后再归一
        → CLR 中心对数比变换 → 在欧氏空间做统计 → 逆变换回成分（自动满足定和）。

二、Pearson 相关必然失真，有偏负倾向
   官方极端例子：只有两个成分时 PCC(x₁,x₂) = −1。变换前算的相关结论是假的。

三、聚类前的变量选择是独立难点
   官方称其为"典型的无监督变量选择问题"。
   可行实现：R 型聚类选代表变量 / PLS-DA 的 VIP 重要性 / 主成分载荷系数大的原变量。

四、PCA 不是变量选择
   用几个主成分去聚类，一个原变量都没剔除——那不叫选择。
```

## 2. 求解与结果呈现：Stage 5–7

> **这一步的失分占比最高。** 2022A 讲评 9 条评阅问题里 5 条与建模无关，
> 而是"计算方法不清楚 / 结果不完整 / 没有很好地呈现结果 / **没有对结果进行分析** /
> **没有结果文件或文件格式不对**"。

```
问题【N】的模型已确定为【…】。请产出：

1. 可运行代码（Python 优先，注明依赖版本），要求：
   - 显式写出初始化、迭代式、终止条件、步长/容差；
   - 关键中间量落盘，便于核对；
   - 结果严格按题目要求的文件名与列格式导出（如 result1.xlsx）。
2. 结果数值表：决策变量/结果逐个列出（坐标、时刻、分组边界、参数值），
   不要只报聚合结论。
3. 对结果的分析（不是罗列）：物理/业务含义、是否符合直觉、
   不符合时解释为什么、异常点归因、与基线对比。
4. 极限退化自检：新引入的参数取边界值时，结果应退化回上一问的简单情形。
   请实际执行这一步并报告是否通过。
5. 灵敏度：关键参数扰动 ±【x】% 后结论是否翻转；给出翻转边界。

图表要求：坐标轴含义与单位齐全、对比类结果画在同一张图、
优先用等高线/热力图而非一堆数字。
```

## 3. 摘要撰写：Stage 8

> 参数来自 44 篇官方展示论文（一等奖级）实测。

```
请按下面的实测规律写摘要，不要自由发挥：

结构：
  开场 2–4 句（背景一句，别抄题面 + 本文建立了什么框架、研究什么问题）
  针对问题一：目标 → 模型（写全名，如"线性混合效应模型(LMM)"）→ 算法 → 具体数值结果
  针对问题二/三/四：同上
  可选收尾：创新点（仅当每条都能在正文找到对应章节）

硬指标（44 篇一等奖实测）：
  - 中文字数 848–1010（p50=927），不超过一页
  - 91% 写出具体数值结果 → 每个"针对问题"段必须落到数字，最好带对照基线
  - 86% 用"针对问题X"分段；82% 明写模型名称
  - 只有 11% 写"模型评价/优缺点" → 别写，那是正文倒数第二章的事
  - 只有 5% 提"创新" → 别硬凑；组委会把"声称创新却无正文证据"列为反模式
  - 关键词 4 个左右，务必含问题域词而不是全是方法名

正文材料：【粘贴各问的模型名、算法名、关键数值结果】
```

## 5. 一条通用的纠偏指令

> 当 AI 给出的方案"看起来很高级但说不清为什么"时用这条。

```
停一下。请对你刚才给出的每个方法回答两个问题：
1. 把这段方法描述换到另一道完全不同的题上，它是否照样成立？
   如果是，说明这是套路，请重新从题目本身推导。
2. 这个方法依赖的前提假设是什么？题目数据满足吗？用什么检验来验证？

另外请注意：命题人对"用了近似方法"是宽容的。2024B 讲评原文说，
用正态近似代替二项精确检验"不能说一定是错误的…方法是相同的。
总之，是否使用公式一不重要，重要的是，抽样数要与次品数有关"。
所以不要因为"不够严格"就推翻可用方案——只要说明适用条件与误差量级即可。
判据是逻辑是否闭合、量与量的依赖关系对不对。
```
