# 开赛操作手册：拿到题之后怎么做

回答那个核心问题：**能不能直接把今年的题丢给 Claude Code + skill 分析？**

**能，链路已实测跑通。** 但它不是解题机器——下面把能做什么、不能做什么、
以及每一步的具体命令写清楚。

## 二、开赛当天：五步

### Step 0　装 skill（赛前就做，别等开赛）

```bash
cp -r "D:/Desktop/数学建模/交付/1_skill" ~/.claude/skills/cumcm-abc
S=~/.claude/skills/cumcm-abc

# 完整预检（含**真编译一次** xelatex + 建模依赖）：应为 19 passed / 0 failed
python $S/scripts/doctor.py --competition cumcm --require-renderer --require-modeling

# 只做静态检查（不碰 LaTeX/建模栈）：13 passed
python $S/scripts/doctor.py --competition cumcm --skip-tools

# 绘图环境自检：六段图全出才算通（顺带验中文字体与 Pillow 灰度校样）
python $S/figures/starter.py --out ./_figcheck
```

`xelatex` 与 `pandoc` 都已在**用户 PATH** 上，不需要手动 `export`。
唯一要留意的是：**开赛当天新开一个终端**再干活。
沿用一个装 TeX 之前就开着的终端，它的环境变量是旧快照，手敲 `xelatex` 会说找不到命令
（doctor 会把这条报成 `latex-engine-on-path` 的 optional warning，并明确说"新开终端就好"，
不要误当成没装）。

### Step 1　建工作目录，把题面和附件放进去

```
2026C/
├── 题面.pdf
├── 附件1.xlsx
└── （skill 会自己建 state/ results/ figures/ paper_workspace/）
```

### Step 2　在该目录启动 Claude Code，说：

```
开始建模
```

skill 会问你 4 件事（题号、队员分工、截止时间、题面路径），然后进 Stage 0。
**Stage 0 会强制先读 `competitions/cumcm/current_rules.md`**——2026 规则与 AI 披露链路。

**19 项预检里这几项赛前最值钱**：`latex-smoke`（真编译，不是只查 `xelatex --version`）、`cn-font`（找到字体后真渲染一张带中文和单位的图——装了 matplotlib 却没中文字体时，图里每个汉字都是空方框，matplotlib 只刷一条警告、**图照出**）、`gates-smoke`（给 5 个提交门各喂一份故意有问题的输入，要求它们报出来）。

**有附件的题，Stage 1/2 必跑附件结构体检**（Stage 2 退出条件之一，不要跳）：

```bash
python $S/scripts/scan_attachments.py 附件/ --json > state/scan.json
```

它扫的是**读题面看不出来、看漏了整条方法主线就错**的结构性事实：
一组列之和是否恒为常数（→ 成分数据，必须先 CLR，否则 Pearson 相关有偏负倾向、结论是假的）、同一对象是否有多条记录（→ 观测不独立，回归要上混合效应）、名字像标签的列是否只有一个取值（→ 真标签在别处，监督学习退化成零正例**且不报错**）、Excel 合并单元格残留（→ 不 ffill 直接 groupby，每组只剩 1 行）。
另有四条「不报错只出错数」的静默坑：混合类型列、大小写/空白不一致、两列本该自洽却对不上、恒等式变量共线。

### Step 3　如果不想走完整 10 阶段，用独立提示词

`2_提示词模板.md` 里 6 条可以单独用。开赛最有价值的是第 0 条
（三题一起判型 + 选题建议），大约 10 分钟出结果。

### Step 4　提交前必跑

```bash
python ~/.claude/skills/cumcm-abc/scripts/check_compliance.py \
    --paper 论文.pdf --support 支撑材料.zip
```

15 项机器判定 + 5 项人工确认，**任一 FAIL 都不要提交**（退出码 1）。
Stage 9 会自动调它，这里是不走完整流程时的手动入口。

**一共 5 个门，分属不同阶段——别只在提交前才想起来：**

```bash
S=~/.claude/skills/cumcm-abc/scripts

# Stage 2（有附件数据就必跑）：数据口径决定必须逐问写下来并给出可追溯依据
python $S/check_data_decisions.py --decision-log state/decision_log.json \
    --scan state/scan.json

# Stage 6 与 Stage 9 各跑一次：自检承诺与「局限」是否都了结
python $S/check_selfaudit.py --ledger state/self_audit.json \
    --paper 论文.tex --workspace paper_workspace/ --results results/

# Stage 9：论文里每个数字都能在 results/ 里找到同一个值
python $S/check_numbers.py --paper 论文.tex --results results/

# Stage 9：缺图文件、悬挂 \ref（PDF 里印成 ??）、重复 label
python $S/check_figures.py --paper 论文.tex --figures figures/ --topic <A|B|C>
```

**5 个门全退出码 0 才算过。** 注意两处刻意的宽严之分，别当噪声划过去：

- `check_data_decisions.py` 的**反方向只报 WARN**——全问全 `keep_as_is` 时它提醒「有没有哪一问的领域方法内在就要求质控」，但不 FAIL。因为多数题目全不动数据就是正确答案，判成 FAIL 会逼你为过门去动数据，正好掉进讲评点名的那一类。
- `check_figures.py` 的**图表数量类只报 WARN**——经验分布不是规则，图少不违规。但 WARN 要逐条读完：官方点名的是「结果不完整」「没有对结果进行分析」。

`doctor.py` 的 `gates-smoke` 已在赛前真跑过这 5 个门（各喂一份故意有问题的输入、要求它们报出来），所以赛中它们坏掉的概率很低。

它比肉眼多抓三类东西：**中文能不能从 PDF 提取出来**（fandol 字体的坑，
编译不报错、显示也正常，评委却检索不到）、**PDF 元数据里残留的作者/单位**、
**压缩包里到底有没有 `AI工具使用详情.pdf` 和源程序**（中文文件名会先从
cp437 乱码还原成 GBK 再比对，否则"文件名完全一致"永远判不对）。

> `_tools/check_paper.py` 是它的前身，已不再维护——那份用 `"".join(pages)`
> 拼页，整页只有"目录"两个字时反而漏检。以 skill 里这份为准。

## 三、它能做什么，不能做什么

### 能做（5 轮方案级 + 5 轮端到端盲测验证过）

- **判题型 + 选方法主线**：五类题型的路数都验过，命中了官方点名的大面积失分点
  （反 K-means 分组、反"异常判定当二分类"，这两处当年分别是"超半数队伍"和
  "绝大多数队伍"栽掉的地方）。
- **挡住套路化**：组委会连续四年点名 AHP/熵权法/遗传算法/深度学习等；
  skill 里有 66 条反模式，Z 段每条都有官方原文或演练实测出处。
- **读数据、跑模型、出图、写结果文件**：整条链路实测通过。
- **合规兜底**：AI 声明位置、摘要单页、无目录、附录源程序，脚本能自动查。

### 不能做

- **不能替你解题**。它给的是方法路线和反模式，具体推导、调参、结果解释还是人的活。
- **不能替你判断对错**。自检承诺现在由 `check_selfaudit.py` 强制了结（写了没跑就 FAIL），
  但**裁定得对不对仍是人的判断**；没写进论文的承诺它也看不见。
- **公式不可盲信**。蒸馏文档的公式来自 OCR，复杂公式有错。引用前回原 PDF 核对。
- **不预测获奖**。分位数只用于"这篇是不是明显异常"。

### 一条容易用反的地方

反模式清单是挡**乱套方法**和**逻辑断裂**的，**不是用来判"简化近似"有罪**。

> 2024B 讲评原文（针对用正态近似代替二项精确检验）：「学生使用公式一，
> **不能说一定是错误的**…方法是相同的。总之，是否使用公式一不重要，
> **重要的是，抽样数要与次品数有关**。」

命题人看的是逻辑闭合与量间依赖关系，不是工具够不够严格。

## 五、两个已知的坑，别重踩

1. **TeX Live 不能装在含中文的路径下**。第一次装到 `_tools/texlive`
   （路径含"数学建模"）时安装器**静默失败**——目录是空的、退出码却是 0。
   **现在装在 `C:	exlive6b`**（`which xelatex` 可核；本文件第一节那一行才是对的）。
2. **LaTeX 模板必须用 `fontset=windows`**。用 `fandol` 编译不报错、显示也正常，
   但中文**无法从 PDF 复制或检索**（FandolSong 缺 ToUnicode CMap）。
   组委会要跑高相似度检测，这是实际风险。换字体后务必再验证一次：

   ```bash
   python -c "from pypdf import PdfReader; print((PdfReader('main.pdf').pages[0].extract_text() or '')[:80])"
   ```
