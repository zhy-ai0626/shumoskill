## skill 安装与自检

```bash
cp -r 1_skill ~/.claude/skills/cumcm-abc
python ~/.claude/skills/cumcm-abc/scripts/doctor.py
```

体检应报 **`16 passed, 0 failed`**；`python -m pytest tests/ -q` 应报 **128 passed**。已在本机装好并实测：
`latex-smoke` 一项是**真编译一次** `smoke.tex`，报 "produced a 56 KiB PDF" 才算过——
不是只问一句 `xelatex --version`。`gates-smoke` 同理：给三个提交门各喂一份**故意有问题**的最小输入，
要求它们真的报出来。只确认脚本文件存在是不够的——语法错、依赖缺失、
甚至判定逻辑整段失效，都要到交卷前 20 分钟才会暴露。pandoc 3.11、TeX Live 2026b（含 ctex）均已就位。

可能出现的 optional warning 只有一类：**`latex-engine-on-path`**。
它的意思不是"没装"，而是**这个终端的环境变量是装 TeX 之前的快照**。
doctor 会在进程内自动补好路径（所以它自己能编译），但同一个终端里手敲
`xelatex paper.tex` 仍会找不到命令——**新开一个终端**就正常了。

## 已知边界

- **公式不可直接引用**：讲评与论文原为图片型 PDF，经 OCR 得到文本；散文可信，
  复杂公式有识别错误。要用公式请回 `../2_官方讲评/`、`../3_优秀论文/官方展示/` 的原 PDF 核对。
- **分位数不是评分线**，只用于"这篇是不是明显异常"的提示，不预测获奖。
- **~~skill 能提醒该做什么，不能保证真去做~~** —— 这条已经从"提醒"升级为"强制"。
  第 2 轮演练写了极限自检却没执行、2025B 那轮「自己指出了出路却把它写成局限」，
  同一个失效模式重复三次，说明散文提醒治不了它。现在由
  `scripts/check_selfaudit.py` 做外部判定：论文里的自检承诺、局限句、
  "取常数/文献值"的自陈，每一类都必须在 `state/self_audit.json` 台账里被了结，
  否则退出码非零。**承诺写在论文里而台账没有，同样 FAIL**——只查台账等于自己查自己。

  2023A 那轮首次实测就复现了同类情形：论文把"截断采样未与遮挡耦合"写成局限，
  gate 判成 `should-have-done` 并拦下；做掉之后单位面积功率提高了 8.7%。

- **仍然不能保证的**：gate 只认它扫得到的句式。没写进论文的承诺它看不见，
  裁定得对不对也还是人的判断——它保证的是"每一条都被显式裁定过"，不是"裁定正确"。

## 图：主要得分位，不是装饰

2022A 讲评 9 条评阅问题里 **5 条与建模无关**，全是呈现类；一等奖图数中位 **20 张**。

`1_skill/figures/cumcm_style.py` 把这件事做成默认正确：坐标轴单位**强制必填**
（缺了直接报错）、颜色与线型/填充网格/标记**捆绑发放**、`save()` 顺手出灰度校样。

最重要的一条是**评委会打印**。实测这套配色灰度下的相对亮度里，
aqua↔magenta 只差 0.017、blue↔green 0.025、blue↔red 0.028——**打印后基本同色**。
所以颜色永远不能单独承载身份。按题型的 7 张范例在 `1_skill/figures/gallery/`，
每张都有 `_gray.png`：**那才是判卷人看到的东西**。

## 三个强制门（提交前必过）

| 脚本 | 管什么 | 不过的后果 |
|---|---|---|
| `scripts/check_compliance.py` | 15 项合规机器判定：A4、≤20 MB、摘要单页、无目录、正文页数、**中文能否从 PDF 提取**、AI 声明三项、附录源程序、正文与 **PDF 元数据**里的身份信息、支撑材料压缩包内容 | 退出码 1 = 不得提交 |
| `scripts/check_numbers.py` | 论文里每个数值都能在 `results/` 的 `.json`/`.csv` 里找到 | 有未追溯的数字 |
| `scripts/check_selfaudit.py` | 自检承诺已执行、"局限"已逐条裁定 | 有未了结项 |

Stage 6 跑 `check_selfaudit`，Stage 9 三个全跑。
`check_compliance` 的 `--json` 输出可直接写进 `decision_log.stages.9.compliance_checks`，
其中 `null` 表示"这项没测到"，必须人工确认后改成布尔值——
写成 `false` 会让人去修一个不存在的问题，写成 `true` 更糟。

## 自包含性

`1_skill/` 装到 `~/.claude/skills/` 后**不依赖资料库其余部分**：
2026 AI 规定、论文格式规范、参赛规则、`format2025.doc`、AI 详情模板
都放在 `1_skill/assets/official/` 里随包分发。

唯二不打包的是原始 PDF（`2_官方讲评/` 110 MB、`3_优秀论文/官方展示/` 1.1 GB），
只在**核对公式**时才需要——蒸馏文档里的散文可信，复杂公式有 OCR 错误。
文档里凡引用这两处的地方都已标注"不随 skill 分发"。
