## §0 选算法前先问三个问题

这三问排在所有算法之前，因为**选错族比选错族内成员的代价大一个量级**。

**问题一：我要求的是"解"还是"最优解"？**

- 求解（方程有唯一答案）→ §1 数值求解。别上优化器——把方程写成 `min |f(x)|²` 再用遗传算法搜，
  是国赛里最常见的降智操作，精度差几个数量级还慢。
- 求最优（有决策自由度）→ §3 优化。此时**必须先写清决策变量、目标函数、约束**，
  2025A 讲评点名"没有给出具体算法"就是指这一步没写。

**问题二：解析解存不存在？**

先花 10 分钟试着推。2022A 的最优阻尼有闭式解 `c_p = √((p₁²+p₂²)/(q₁²+q₂²))`，
这种题上遗传算法是直接丢分。判断依据：目标函数对决策变量可导且驻点方程能解 → 有解析解。
**推不出来也不亏**——推的过程会告诉你目标函数的单调性和大致量级，够你定搜索范围了。

**问题三：我的不确定性从哪来？**

| 不确定性来源 | 对应工具 |
|---|---|
| 数值离散误差（步长、网格） | 步长减半重算，看结果变化（§1.1 坑位） |
| 测量噪声 | 最小二乘 + 残差分析（§3.5）、误差传播（§4.13） |
| 参数只知道分布 | 蒙特卡洛（§4.12）、随机规划（§5.2）、贝叶斯（§4.8） |
| 模型形式本身可能错 | 交叉验证、留一参数不参与定标（`4_知识点总结` §三技法 3） |

写论文时"稳健性分析"那一章写什么，取决于这一格的答案。四种混着写等于没写。

# 第一族 · 数值计算与方程求解

**这一族的共同点**：问题有唯一确定的答案，你要做的是把它算出来并控制误差。
**共同的坑**：所有迭代法都要写收敛判据和最大迭代次数，两者缺一，赛场上必挂。

## §1.1 常微分方程数值解（龙格-库塔 / `solve_ivp`）

**是什么**｜给定 $\dot{\mathbf{y}}=f(t,\mathbf{y})$ 和初值 $\mathbf{y}(t_0)$，逐步推出 $\mathbf{y}(t)$。
四阶龙格-库塔（RK4）是最常用的显式单步法。

**什么时候用**｜题目给的是**变化率**（速度、加速度、反应速率、传热率）而不是量本身。
看到"牛顿第二定律""受力平衡的动力学方程""浓度随时间变化"就是它。

**核心**｜RK4 一步：
$$
k_1=f(t_n,y_n),\quad k_2=f(t_n+\tfrac h2,\,y_n+\tfrac h2k_1),\quad
k_3=f(t_n+\tfrac h2,\,y_n+\tfrac h2k_2),\quad k_4=f(t_n+h,\,y_n+hk_3)
$$
$$
y_{n+1}=y_n+\tfrac h6(k_1+2k_2+2k_3+k_4),\qquad \text{局部误差 }O(h^5)\text{，全局 }O(h^4)
$$
**二阶方程必须先降阶成一阶方程组**：$m\ddot x+c\dot x+kx=F(t)$ 令 $\mathbf y=(x,\dot x)$，
则 $\dot{\mathbf y}=(y_2,\ (F-cy_2-ky_1)/m)$。

**参数与坑**｜
- **`rtol`/`atol` 默认值（1e-3/1e-6）对国赛偏松**，机理题至少 `rtol=1e-8, atol=1e-10`。
- **刚性方程用 `RK45` 会静默变慢或发散**：若方程里有相差 3 个数量级以上的时间尺度
  （快弹簧 + 慢阻尼、快反应 + 慢扩散），换 `method='Radau'` 或 `'BDF'`。
  判断方法：`RK45` 跑得异常慢、`sol.nfev` 上万，就是刚性。
- **步长自查是必做项**：`h` 减半重算，前 4 位有效数字不变才算收敛。写进论文的"计算方法说明"。
- 要在特定时刻取值用 `t_eval=`，**不要**自己插值；要抓事件（碰撞、穿越零点）用 `events=`，
  它内部做根查找，比"找最接近的网格点"精确好几位。

**国赛出处**｜2022A 垂荡运动方程用四阶龙格-库塔（一等奖论文高频关键词）。
官方讲评的顺序是**先给线性阻尼的精确解，再谈数值**——见 §0 问题二。

**骨架**｜
```python
from scipy.integrate import solve_ivp
import numpy as np

def rhs(t, y, c, k, m, F0, w):
    x, v = y
    return [v, (F0*np.cos(w*t) - c*v - k*x) / m]

def hit_zero(t, y, *a):      # 事件：位移过零
    return y[0]
hit_zero.direction = -1      # 只抓下穿

sol = solve_ivp(rhs, [0, 200], [0.0, 0.0], args=(1e4, 8e3, 4866, 6250, 1.4005),
                method='RK45', rtol=1e-9, atol=1e-11,
                t_eval=np.arange(0, 200, 0.01), events=hit_zero, dense_output=True)
assert sol.success, sol.message          # 别忘了检查
x_at_10s = sol.sol(10.0)                 # dense_output 给连续解
```
模板：`1_skill/code-templates/python/mechanistic/ode_solver_template.py`

**别用它的时候**｜方程能解析积分（常系数线性、可分离变量）→ 先写解析解。
偏微分方程 → 差分/有限元，不是这条。

## §1.2 微元法

**是什么**｜把连续体切成小段，在每段上用简单模型（直线、匀速、常力）近似，再求和/取极限。
本质是"手工离散化"，也是很多解析推导的第一步。

**什么时候用**｜看到**沿曲线分布的量**：曲线长度、沿螺线排布的把手、绳索受力、变截面梁。
特征是"整体不规则，但局部规则"。

**核心**｜三步：
1. **选微元**：$\mathrm d s$（弧长）、$\mathrm d\theta$（角度）、$\mathrm d t$（时间）——选哪个决定后面难度。
2. **写微元上的关系**：把非线性关系在微元内线性化。
3. **积分或累加**：能积出解析式最好，积不出就数值累加，但**必须验证网格无关性**（切细一倍看结果变没变）。

等距螺线 $r=a+b\theta$ 的弧长微元是国赛高频：
$$
\mathrm ds=\sqrt{r^2+\left(\frac{\mathrm dr}{\mathrm d\theta}\right)^2}\,\mathrm d\theta=\sqrt{(a+b\theta)^2+b^2}\,\mathrm d\theta
$$

**参数与坑**｜
- **微元数不是越多越好**：浮点累加误差随 $N$ 增长，$N>10^7$ 时用 `np.cumsum` 或 Kahan 求和。
- **弧长参数化不能用等 $\theta$ 步长冒充**：螺线上等角度间隔 ≠ 等弧长间隔，
  要等弧长必须解 $s(\theta)=s_0$（配 §1.3 二分或 `brentq`）。2024A 板凳龙的把手间距就是这个。
- 累加型微元法的误差是 $O(h)$，中点法则能升到 $O(h^2)$，几乎不加代码量。

**国赛出处**｜2024A 一等奖论文高频（盘入螺线、把手位置迭代）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import brentq
from scipy.integrate import quad

b = 0.55 / (2*np.pi)                       # 螺距 0.55 m
ds = lambda th: np.hypot(b*th, b)          # r = b*theta 的弧长微元
arc = lambda th: quad(ds, 0, th)[0]        # 累计弧长（自适应积分，比手工累加准）

# 求"从 th0 沿曲线退 L 米"对应的角度
def back_along(th0, L):
    s0 = arc(th0)
    return brentq(lambda th: arc(th) - (s0 - L), 0, th0)
```

**别用它的时候**｜关系本身就是线性的（直杆、匀速）→ 直接代公式。
要的是场量分布（温度场、应力场）→ 有限差分/有限元。

## §1.3 二分法与三分法

**是什么**｜二分法在**单调**或**变号**区间上找根，三分法在**单峰**区间上找极值。
每步把区间缩小固定比例，收敛线性但极其稳。

**什么时候用**｜一元、区间已知、函数可能不可导（甚至是仿真黑箱）。
"求临界值""求最小螺距""求最早时刻"这类问法基本都是它。

**核心**｜
- 二分：$f(a)f(b)<0$ 时取 $m=(a+b)/2$，用 $f(m)$ 的符号决定保留哪半。
  $k$ 步后区间长 $(b-a)/2^k$，要 1e-7 精度约需 $\log_2\frac{b-a}{10^{-7}}\approx 24$ 步。
- 三分：单峰函数取 $m_1=a+\frac{b-a}3,\ m_2=b-\frac{b-a}3$，
  $f(m_1)<f(m_2)$（求最大）则弃 $[a,m_1]$。每步缩到 $2/3$。

**参数与坑（这条最重要，官方专门点过名）**｜
> 2025A 讲评："少数参赛队提到了用二分法，但没有给出具体的算法描述。
> **实际上，二分法不能直接使用**。如果某个时间点烟幕不能遮蔽真目标，此时并不能确定这个
> 时间是下界还是上界……由此必须对二分法进行改进才能使用。"

**二分法要求区间两端异号**。判定型问题（遮蔽/不遮蔽）的真值区间可能在中间，
两端同为"假"，二分直接失效。**正确做法是两阶段**：

1. **网格定位**：等步长扫一遍，找出所有"相邻两点判定不同"的子区间——这一步解决上下界不明；
2. **区间内二分**：只在这些子区间里二分端点，精度可压到 1e-7 s。

其余坑：
- 三分法**只对严格单峰有效**。多峰函数上三分会稳稳地收敛到某个局部峰，且不报错。
  用之前先粗扫画个图确认单峰。
- `scipy.optimize.brentq` 比手写二分快得多（结合二分+割线+逆二次插值），
  **有变号区间就用它**，手写二分只在需要自定义判据时用。

**国赛出处**｜2024A（最小螺距、二分法）、2025A（遮蔽时长，上面那段原话）、2021C（二分答案）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import brentq

def occluded(t):  ...          # 判定函数，返回 bool

# 阶段一：网格定位
ts = np.arange(0, 60, 0.01)
flag = np.array([occluded(t) for t in ts])
edges = np.flatnonzero(flag[:-1] != flag[1:])       # 变号位置

# 阶段二：只在变号子区间内二分
g = lambda t: 1.0 if occluded(t) else -1.0
bounds = [brentq(g, ts[i], ts[i+1], xtol=1e-9) for i in edges]
total = sum(bounds[1::2]) - sum(bounds[0::2])       # 成对相减得总时长
```

**别用它的时候**｜多元 → §3.6 局部优化或 §3.8–3.9 群体智能。
函数光滑可导且初值好 → §1.5 牛顿法（二次收敛，快得多）。

## §1.4 变步长遍历与多起点搜索

**是什么**｜先用粗步长扫全域找到候选区，再在候选区附近细化。是"网格搜索"的实用版。

**什么时候用**｜决策变量 1–3 维、目标函数一次求值不贵（毫秒级）、
且你**不信任**局部优化器不掉进局部最优时。国赛里 A 题几乎必用。

**核心**｜
```
粗扫（步长 h₁，覆盖全域） → 取前 k 个候选 → 每个候选邻域细扫（h₂ = h₁/10）
  → 迭代 2–3 轮 → 最后用局部优化器（§3.6）抛光
```
**先做量纲级估算把全域缩小**（`4_知识点总结` §七2）：2023A 讲评一段话就把镜面尺寸
锁进 5×5 到 7×7，比盲扫省一个数量级机时。

**参数与坑**｜
- **粗步长要小于目标函数的特征波长**，否则会整个跳过最优区。定粗步长的方法：
  先在一条线上密采 200 点画图，看峰有多宽，粗步长取峰宽的 1/3。
- **候选区不要只留第一名**：留前 3–5 个，因为粗网格上的排名经常在细化后翻转。
- **一定要做向量化**。`np.meshgrid` + 数组运算比 Python 双重循环快 50–200 倍，
  这个差距决定了你能不能在 72 小时里扫完。
- 别删搜索维度。2023A 那轮演练把"行距"从搜索空间里删掉，**明确失分 5.3%**。

**国赛出处**｜2021A（变步长遍历）、2023A（变步长搜索 + 分区域布局）、2025A（多起点变步长）。

**骨架**｜
```python
import numpy as np

def coarse_to_fine(f, lo, hi, n=41, rounds=3, keep=3):
    """f 接受 (N,d) 数组返回 (N,) 目标值（越大越好）"""
    lo, hi = np.asarray(lo, float), np.asarray(hi, float)
    best = None
    for r in range(rounds):
        axes = [np.linspace(l, h, n) for l, h in zip(lo, hi)]
        grid = np.stack(np.meshgrid(*axes, indexing='ij'), -1).reshape(-1, len(lo))
        val = f(grid)                                   # 向量化求值
        idx = np.argsort(val)[-keep:]
        best = (grid[idx[-1]], val[idx[-1]])
        span = (hi - lo) / (n - 1) * 2                  # 下一轮只在邻域搜
        lo, hi = grid[idx[-1]] - span, grid[idx[-1]] + span
    return best
```

**别用它的时候**｜维度 ≥ 4 → 网格点数指数爆炸，改 §3.9 差分进化，
或先做**解析重参数化**把维度降下来（2025A 把 4 维盲搜变成"起爆点+时刻"，见 `4_知识点总结` §二）。

## §1.5 牛顿迭代与割线法

**是什么**｜用切线（牛顿）或割线逼近函数零点。收敛快：牛顿二阶，割线约 1.618 阶。

**什么时候用**｜反演题的核心工具——正演模型 $y=g(\theta)$ 已知，测得 $y^\*$，要解 $\theta$。
也用于隐式方程（$\theta$ 出现在方程两边解不开）。

**核心**｜
$$
\theta_{k+1}=\theta_k-\frac{f(\theta_k)}{f'(\theta_k)}\quad\text{（牛顿）},\qquad
\theta_{k+1}=\theta_k-f(\theta_k)\frac{\theta_k-\theta_{k-1}}{f(\theta_k)-f(\theta_{k-1})}\quad\text{（割线）}
$$
导数难求时用割线法或数值导数 $f'\approx\frac{f(\theta+\varepsilon)-f(\theta-\varepsilon)}{2\varepsilon}$，
$\varepsilon\approx\sqrt{\epsilon_{\text{mach}}}\cdot|\theta|\approx10^{-8}|\theta|$。

**参数与坑**｜
- **初值不好会跑飞**，且跑飞时不报错，只给你一个荒谬的数。**必须加物理合理性检查**
  （厚度为负、折射率 < 1 → 直接判失败重来）。
- $f'\approx0$ 附近步长爆炸。加**阻尼**：$\theta_{k+1}=\theta_k-\lambda f/f'$，$\lambda\in(0,1]$，
  或直接改用 `brentq`（有区间时更稳）。
- 收敛判据用**相对**变化 `|Δθ| < 1e-10 * max(1,|θ|)`，别用绝对值——量纲一变判据就失效。
- **多解问题**：干涉级次 $m$ 未知时方程有一族解，要先用别的信息（粗测厚度、相邻峰间距）定 $m$，
  再牛顿细化。直接牛顿会收到随便哪个解上。

**国赛出处**｜2025B（牛顿迭代反演厚度，一等奖论文关键词）。

**骨架**｜
```python
from scipy.optimize import newton, brentq

# 有导数、初值好：
theta = newton(lambda t: forward(t) - y_obs, x0=7.0, fprime=dforward, tol=1e-12, maxiter=100)
# 无导数、有变号区间（更稳，优先）：
theta = brentq(lambda t: forward(t) - y_obs, 1.0, 20.0, xtol=1e-12)
assert 1.0 < theta < 20.0, "反演结果超出物理范围"
```

**别用它的时候**｜多个观测值拟合少数参数（超定）→ §3.5 非线性最小二乘，不是求根。
目标是最优化而非求根 → §3.6。

## §1.6 插值与三次样条

**是什么**｜用光滑曲线穿过已知点，在点之间取值。三次样条分段三次、二阶导连续。

**什么时候用**｜测量数据要取任意点的值/导数、离散曲线要求切线方向、
数据要在非均匀采样上重采样到均匀网格（FFT 前的必要步骤）。

**核心**｜三次样条在每段 $[x_i,x_{i+1}]$ 上是三次多项式，
要求函数值、一阶导、二阶导在节点处连续，加两个边界条件（自然边界 $S''=0$，或 not-a-knot 默认）。
$n$ 个点 → $4(n-1)$ 个未知量，方程数刚好凑齐，解一个三对角系统。

**参数与坑**｜
- **插值 ≠ 拟合**。数据有噪声时插值会把噪声一起放大（导数尤其严重），
  这时该用**平滑样条** `UnivariateSpline(..., s>0)` 或先滤波（§6.4）。
  这是国赛反演题最常见的静默错误之一。
- **绝不外推**。`interp1d(..., fill_value='extrapolate')` 在区间外会给出离谱的值且不警告。
  默认设 `bounds_error=True`。
- 高次多项式插值（`polyfit` 次数 > 5）会有龙格现象，端点剧烈震荡——**用样条，不要用高次多项式**。
- 需要保单调（如累计分布）→ `PchipInterpolator`，样条会过冲。

**国赛出处**｜2025B（三次样条，一等奖论文关键词）。

**骨架**｜
```python
from scipy.interpolate import CubicSpline, UnivariateSpline, PchipInterpolator

cs = CubicSpline(x, y, bc_type='not-a-knot')
y_new, dy_new = cs(x_new), cs(x_new, 1)          # 顺带拿到解析导数

sp = UnivariateSpline(x, y, s=len(x)*noise_var)  # 有噪声：平滑样条，s 按噪声定
mono = PchipInterpolator(x, y)                   # 需要保单调
```

**别用它的时候**｜想外推 → 建物理模型（§1.5 的正演），不是插值。
只要一个整体趋势 → 低次多项式拟合或 §4.3 回归。

## §1.7 数值积分（辛普森 / 自适应 / 高斯）

**是什么**｜算 $\int_a^b f(x)\mathrm dx$ 的数值近似。

**什么时候用**｜面积、体积、能量、期望、接收比，凡是"对连续量求和"的都是。

**核心**｜
- 梯形：误差 $O(h^2)$；辛普森：$O(h^4)$，代价一样，**默认用辛普森**。
- 自适应（`quad`）：内部按误差估计自动加密，一维首选。
- 高维（>3）→ 网格法点数爆炸，改蒙特卡洛（§4.12），误差 $O(N^{-1/2})$ 与维度无关。

**参数与坑**｜
- `quad` 遇到**振荡被积函数或积分区间含奇点**会给出错误结果并**只发 warning**。
  遇到警告要么给 `points=[...]` 标出奇点，要么分段积。
- 被积函数由仿真给出（每次求值几百毫秒）→ 别用 `quad`（求值次数不可控），
  改固定阶高斯求积 `np.polynomial.legendre.leggauss(n)`，求值次数正好 $n$ 次。
- **积分结果必须做网格无关性检查**：节点数翻倍，结果前 4 位不变。

**国赛出处**｜2021A（蒙特卡洛积分算接收比；也可用确定性积分交叉验证）。

**骨架**｜
```python
import numpy as np
from scipy.integrate import quad, simpson

I, err = quad(f, 0, 1, epsabs=1e-12, epsrel=1e-12)   # 一维首选，err 要看
x = np.linspace(0, 1, 2001); I2 = simpson(f(x), x=x) # 只有采样点时
xg, wg = np.polynomial.legendre.leggauss(64)         # 求值贵时：固定 64 次
I3 = 0.5*(b-a) * wg @ f(0.5*(b-a)*xg + 0.5*(a+b))
```

**别用它的时候**｜维度 ≥ 4 或积分域不规则 → §4.12 蒙特卡洛。

# 第二族 · 几何与空间关系

**这一族的共同点**：全部可以用向量代数写出来，而且**写成向量形式比写成三角函数简单得多**。
2023B 讲评原话就是这个意思："公式推导最简单的方法是'点法式'…公式过于复杂会失去直观性"。

**共同的坑**：sin/cos 配对错、角度符号反、坐标系转错向。这类错误**数值上完全合理**，
只能靠 §2.1 的**极限退化自检**发现。第 2 轮演练写了这条自检却没执行，sin/cos 配反就漏过去了。

## §2.1 坐标变换与旋转矩阵

**是什么**｜在不同参考系之间换算点/向量的坐标。三维旋转用 $3\times3$ 正交矩阵表示。

**什么时候用**｜题目里出现两个及以上参考系：地面系 vs 机体系、全局系 vs 镜面局部系、
惯性系 vs 随体系。**A 题几乎必考**。

**核心**｜
- 绕 $z$ 轴转 $\theta$：$R_z(\theta)=\begin{pmatrix}\cos\theta&-\sin\theta&0\\ \sin\theta&\cos\theta&0\\ 0&0&1\end{pmatrix}$，
  绕 $y$、$x$ 同理（注意 $R_y$ 的负号位置和另两个相反）。
- **点变换 vs 系变换互为转置**：把点在固定系里转 $\theta$ 用 $R$，
  把同一个点换到转了 $\theta$ 的新系里用 $R^{\mathsf T}$。**这里错了整题全错，而且看不出来。**
- 复合旋转不可交换：$R_zR_y\ne R_yR_z$，必须写清顺序和绕的是**固定轴还是动轴**。
- 齐次坐标把旋转+平移合成一个 $4\times4$ 矩阵，多级变换时省事。

**参数与坑**｜
- **验证三件套**（每次写完旋转矩阵都跑）：`R @ R.T ≈ I`、`det(R) ≈ +1`（$-1$ 是含镜像，错了）、
  **拿一个已知答案的特例代进去**（如转 90° 后 x 轴应变成 y 轴）。
- **极限退化自检**：角度取 0 应退化成恒等；取 90° 应给出直觉上的结果。
  这是整个第二族最有效的一条自检。
- 用 `scipy.spatial.transform.Rotation` 比手写省事且不会写错号，
  但要看清它的 `'zyx'` 是**内旋**（动轴）、大写 `'ZYX'` 是**外旋**（固定轴）。

**国赛出处**｜2021A（坐标变换，一等奖高频）、2025A（导弹/无人机/目标三套坐标）。

**骨架**｜
```python
import numpy as np
from scipy.spatial.transform import Rotation as Rot

R = Rot.from_euler('ZYX', [yaw, pitch, roll], degrees=True).as_matrix()  # 外旋
assert np.allclose(R @ R.T, np.eye(3)) and np.isclose(np.linalg.det(R), 1)
assert np.allclose(Rot.from_euler('Z', 90, degrees=True).apply([1,0,0]), [0,1,0])  # 特例
p_world = R @ p_body + origin          # 体系 → 世界系
p_body  = R.T @ (p_world - origin)     # 世界系 → 体系
```

**别用它的时候**｜只有二维 → 直接用 $2\times2$ 或复数乘法，别拉三维。
要插值姿态（球面平滑过渡）→ 四元数 `Rotation.slerp`。

## §2.2 点法式与空间解析几何

**是什么**｜用"点 + 法向量"描述平面/直线，把几何条件写成内积、叉积等式。

**什么时候用**｜求交点、求距离、求投影、判断共面、求法线方向。
**几乎所有空间几何题的第一选择**——官方明确推荐过。

**核心**｜设平面过点 $\mathbf p_0$、法向 $\mathbf n$：
$$
\mathbf n\cdot(\mathbf p-\mathbf p_0)=0
$$
由此导出的常用式子（背下来，赛场直接用）：

| 要什么 | 公式 |
|---|---|
| 点到平面距离 | $d=\dfrac{|\mathbf n\cdot(\mathbf p-\mathbf p_0)|}{\|\mathbf n\|}$ |
| 点到直线距离 | $d=\dfrac{\|(\mathbf p-\mathbf a)\times\mathbf d\|}{\|\mathbf d\|}$ |
| **点到线段距离** | 先求 $t=\mathrm{clip}\!\big(\tfrac{(\mathbf p-\mathbf a)\cdot\mathbf d}{\mathbf d\cdot\mathbf d},0,1\big)$，再算 $\|\mathbf p-(\mathbf a+t\mathbf d)\|$ |
| 两向量夹角 | $\cos\alpha=\dfrac{\mathbf u\cdot\mathbf v}{\|\mathbf u\|\|\mathbf v\|}$ |
| 直线与平面交点 | $t=\dfrac{\mathbf n\cdot(\mathbf p_0-\mathbf a)}{\mathbf n\cdot\mathbf d}$，交点 $\mathbf a+t\mathbf d$ |
| 反射方向 | $\mathbf r=\mathbf d-2(\mathbf d\cdot\hat{\mathbf n})\hat{\mathbf n}$ |

**参数与坑**｜
- **点到线段 ≠ 点到直线**。忘了 `clip(t,0,1)` 是遮蔽/碰撞类题目的头号 bug——
  目标在线段延长线外时，直线距离会小得离谱，判成"被遮蔽"。2025A 那类题上这一处错就全盘错。
- 法向量**没归一化**时距离公式会漏掉除以 $\|\mathbf n\|$。养成算完就 `n /= norm(n)` 的习惯。
- $\mathbf n\cdot\mathbf d\approx0$ 表示直线与平面平行，要单独判，否则除零得到 `inf`/`nan`。
- 反射公式里的 $\hat{\mathbf n}$ **必须是单位向量**，且入射向量指向表面（符号弄反反射就朝里）。

**国赛出处**｜2023B（官方点名推荐点法式）、2023A（镜面法线与反射）、2025A（视线与云团球心距离）。

**骨架**｜
```python
import numpy as np

def pt_seg_dist(p, a, b):
    """点到线段距离，向量化：p (...,3), a/b (3,)"""
    d = b - a
    t = np.clip(((p - a) @ d) / (d @ d), 0.0, 1.0)      # 关键：clip 到 [0,1]
    return np.linalg.norm(p - (a + t[..., None] * d), axis=-1)

def reflect(d, n):
    n = n / np.linalg.norm(n)
    return d - 2.0 * (d @ n) * n
```

**别用它的时候**｜二维且只关心相交 → §2.5 计算几何的专用判据更快。
凸多面体互相碰撞 → §2.3 分离轴定理。

## §2.3 分离轴定理（SAT）

**是什么**｜两个**凸**物体不相交 ⟺ 存在一条轴，两者在该轴上的投影区间不重叠。

**什么时候用**｜判断矩形/长方体/凸多边形**是否碰撞**。
"板凳是否相撞""包络是否重叠"这类问法就是它。

**核心**｜
1. 候选轴 = 两物体所有**面法向** ∪ 所有**边方向的两两叉积**（二维只要面法向，即各边的法线）。
2. 把两物体的顶点投影到轴上，取各自 $[\min,\max]$。
3. **只要有一条轴上区间不重叠 → 一定不碰**（可以立刻返回）；**所有轴都重叠 → 一定碰**。

二维两个矩形：4 条边法向（实际只要 2+2 条不重复的）就够。

**参数与坑**｜
- **只对凸形有效**。凹形要先做凸分解，或退化成"顶点在不在对方内"的近似判据（会漏判）。
- 三维要加**边叉积轴**（$3\times3=9$ 条），只用 6 条面法向会漏掉"棱贴棱"的相交情形。
- 浮点相切：加容差 `if max1 < min2 - eps` 而不是 `<`，`eps` 取尺度的 1e-9。
- **提前返回是性能关键**：找到一条分离轴立刻 `return False`，别把所有轴都算完。

**国赛出处**｜2024A（一等奖论文用分离轴定理判板凳碰撞）。

**骨架**｜
```python
import numpy as np

def sat_2d(P, Q):
    """P,Q: (n,2)/(m,2) 凸多边形顶点（按序）。返回是否相交"""
    for poly in (P, Q):
        e = np.roll(poly, -1, 0) - poly
        axes = np.stack([-e[:, 1], e[:, 0]], 1)          # 边法向
        for ax in axes / np.linalg.norm(axes, axis=1, keepdims=True):
            p, q = P @ ax, Q @ ax
            if p.max() < q.min() - 1e-9 or q.max() < p.min() - 1e-9:
                return False                              # 找到分离轴，提前返回
    return True
```

**别用它的时候**｜圆/球 → 直接比圆心距与半径和，别用 SAT。
需要**相交深度**而不只是是否相交 → SAT 可以顺带给出最小重叠量（取所有轴上重叠量的最小值）。

## §2.4 离散判别点集与可见性判据

**是什么**｜把"整个物体是否被遮蔽/覆盖"化归为"有限个代表点是否都被遮蔽"。

**什么时候用**｜遮蔽、覆盖、可见性、探测这一类。2025A 是典型。

**核心（官方原话直接给了答案）**｜
> 2025A 讲评："部分参赛队将圆柱体内部点放在离散判别点集中，或者将**下底面圆的内部点**
> 放在离散判别点集中，这些点都是不必要的，**因为导弹是看不到这些点的**。"
> 更强的化简："只要真目标上下底面的圆周均被烟幕遮蔽，则整个真目标也被遮蔽。"

所以三条规则：
1. **只取表面**，不取内部；
2. **只取轮廓/极值点**（凸体的遮蔽由边界决定）；
3. 能证明"边界被遮 ⟹ 整体被遮"就**只判边界**，点数从 $O(n^2)$ 降到 $O(n)$。

**量词顺序**｜多个遮挡体共同遮蔽有体积目标，判据是 $\forall$点 $\exists$体，**不是** $\exists$体 $\forall$点。
写反了会把"协同遮蔽"整段做错（2025A 端到端实证，见 `anti_patterns.md` Z19）。

**能求导就别加密采样**｜2025A 官方对参数 $\theta$ 求导，把
$\max_\theta \mathrm{dist}(\text{球心},\ \text{线段}(\text{观测者},\text{目标圆周点}\ \theta))\le r$
整理成关于 $\sin\theta$ 的 4 次（或 2 次）方程，最多 4 个（或 2 个）实根，
"点点判断"就变成"少数几个点的判断"。离散采样够用但慢且不优雅。

**参数与坑**｜
- **点数要做收敛性检查**：点数翻倍，遮蔽时长变化 < 1e-4 才算够。写进论文计算方法说明。
- 采样点分布要均匀（圆周等角、球面用 Fibonacci 格点），别用经纬度均匀（两极过密）。
- 判据函数一定要**向量化**：`(N_point, N_time)` 一次算完，Python 双循环在这类题上跑不完。

**国赛出处**｜2025A（讲评把"离散判别点集的选取"直接列为评阅问题）。

**骨架**｜
```python
import numpy as np

def cylinder_boundary(center, r, h, n=200):
    """只取上下底面圆周——官方化简"""
    th = np.linspace(0, 2*np.pi, n, endpoint=False)
    ring = np.stack([r*np.cos(th), r*np.sin(th), np.zeros(n)], 1)
    return np.vstack([ring + center, ring + center + [0, 0, h]])

def all_covered(pts, eye, balls):        # balls: (M,4) = 球心+半径
    d = np.stack([pt_seg_dist(pts, eye, c) - rr for *c, rr in balls])  # (M,N)
    return bool((d <= 0).any(axis=0).all())     # ∀点 ∃体 —— 注意顺序
```

**别用它的时候**｜目标是点或球 → 直接解析判据，不需要点集。
要的是遮蔽**比例**而非布尔 → 改蒙特卡洛面积估计（§4.12）。

## §2.5 计算几何基础（圆交、凸包、最近点对）

**是什么**｜一组处理平面点/线/圆的经典算法。

**什么时候用**｜定位（由距离/角度反推位置）、包络、聚集程度、边界提取。

**核心**｜
- **两圆交点**：圆心距 $d=\|\mathbf c_2-\mathbf c_1\|$，
  $a=\frac{d^2+r_1^2-r_2^2}{2d}$，$h=\sqrt{r_1^2-a^2}$，
  交点 $=\mathbf c_1+a\hat{\mathbf e}\pm h\hat{\mathbf e}^{\perp}$。
  先判 $|r_1-r_2|\le d\le r_1+r_2$，否则无交点。
- **正弦定理定位**：已知两观测角和基线，解三角形得位置（2022B 的官方主线之一）。
- **凸包**：`scipy.spatial.ConvexHull`，$O(n\log n)$。用于求最小包围、最大跨度。
- **最近点对 / 邻域查询**：`scipy.spatial.cKDTree`，把 $O(n^2)$ 降到 $O(n\log n)$。
  点数上千的"两两距离"必须用它，否则内存直接爆。

**参数与坑**｜
- **两圆交点有两个解，选哪个要靠额外信息**（第三个观测、物理约束、连续性）。
  只用两个圆定位是**本质二义**的，论文里必须写清怎么消歧。
- 浮点导致 $r_1^2-a^2$ 略小于 0 → `sqrt` 得 `nan`。加 `h = sqrt(max(r1**2 - a**2, 0.0))`。
- 三点几乎共线时解三角形病态，误差放大几个数量级。要检查条件数或换用最小二乘多点定位。

**国赛出处**｜2022B（两圆相交定位 / 正弦定理定位，官方主线；一等奖论文关键词"计算几何"）。

**骨架**｜
```python
import numpy as np
from scipy.spatial import ConvexHull, cKDTree

def circle_intersect(c1, r1, c2, r2):
    c1, c2 = map(np.asarray, (c1, c2))
    d = np.linalg.norm(c2 - c1)
    if d > r1 + r2 or d < abs(r1 - r2) or d == 0:
        return []                                   # 无交点，必须先判
    a = (d*d + r1*r1 - r2*r2) / (2*d)
    h = np.sqrt(max(r1*r1 - a*a, 0.0))              # 防浮点负数
    e = (c2 - c1) / d;  ep = np.array([-e[1], e[0]])
    return [c1 + a*e + h*ep, c1 + a*e - h*ep]

hull = ConvexHull(pts)                              # hull.vertices 是边界点下标
tree = cKDTree(pts); pairs = tree.query_pairs(r=0.5)
```

**别用它的时候**｜三维 → 回 §2.2 向量代数。
点很多且要反复查询 → 一定用 KD 树，不要手写双循环。

# 第三族 · 优化

**这一族的共同点**：有决策自由度，要在可行域里找最好的。
**进这一族之前必须先写清三件事**（2025A 讲评点名"没有给出具体算法"就是查这个）：

```
决策变量：x = (…)，各自的定义域与量纲
目标函数：max/min f(x)，物理含义是什么
约束条件：g(x) ≤ 0, h(x) = 0，每条的来源（物理/工艺/题面）
```

**再写清算法本身**：用什么算法、参数怎么定、收敛判据是什么、跑了多少次、结果稳不稳定。
这四句缺一句都算"没有给出具体算法"。

**选优化算法的顺序（从上往下，能停就停）**：

| 情形 | 用什么 | 章节 |
|---|---|---|
| 目标与约束都线性 | 线性规划（单纯形/内点） | §3.1 |
| 变量取整数且线性 | 整数规划（分支定界） | §3.1 |
| 有阶段结构、状态可数 | 动态规划 | §3.2 |
| **组合数 ≤ 几十** | **全枚举**（这是精确解，写进论文得分） | §3.3 |
| 连续、光滑、有导数、初值好 | BFGS / SLSQP / trust-constr | §3.6 |
| 超定拟合（残差平方和） | 非线性最小二乘 LM | §3.5 |
| 连续、多峰、维度 ≤ 20 | 差分进化 / PSO | §3.9 / §3.8 |
| 离散排列组合、邻域好定义 | 模拟退火 / 遗传 | §3.10 / §3.7 |
| 多个冲突目标 | NSGA-II 出 Pareto 前沿 | §3.12 |

**最容易犯的错**：跳过前四行直接用遗传算法。2022A 有闭式解、2024B 只有 16 种组合，
这两题上用智能算法都是丢分。

## §3.1 线性规划与 0-1 整数规划

**是什么**｜目标与约束都是线性函数时的最优化。变量限定为整数时是整数规划（IP），
限定 0/1 时是 0-1 规划。

**什么时候用**｜资源分配、选址、指派、种植/生产计划。
标志：目标是各项的**加权和**，约束是"总量不超过""每样至少一个"。

**核心**｜
$$
\min\ \mathbf c^{\mathsf T}\mathbf x\quad \text{s.t.}\quad A_{ub}\mathbf x\le \mathbf b_{ub},\ A_{eq}\mathbf x=\mathbf b_{eq},\ \mathbf l\le\mathbf x\le\mathbf u
$$
LP 有多项式算法（内点法），**全局最优有保证**。IP 是 NP 难，靠分支定界：
解松弛 LP → 若某变量非整则按它分两支 → 用界剪枝。

**常用建模技巧（这才是难点，求解器是现成的）**：
- **逻辑"或"**：$x$ 取 0 或 $\ge L$ ⟹ 引入 0-1 变量 $z$，写 $Lz\le x\le Mz$（$M$ 为大常数）。
- **固定成本**：用了才付 $f$ ⟹ 目标加 $f z$，约束 $x\le Mz$。
- **绝对值/极大极小**：$\min\max_i g_i$ ⟹ 引入 $t$，$\min t$ s.t. $g_i\le t$。
- **禁止组合**：$x_i+x_j\le1$。

**参数与坑**｜
- **大 M 取太大会数值病态**（求解器给出错误的整数解且不报错），
  取"物理上界的 1.5 倍"，别写 `1e9`。
- `scipy.optimize.linprog` 只做 LP；整数规划用 `milp`（scipy ≥1.9）或 `pulp`。
  国赛机器上 `pulp` 未必有，**优先用 `scipy.optimize.milp`**。
- 解完检查 `res.status`，别只看 `res.x`。不可行/无界时 `res.x` 是 `None` 或垃圾值。

**国赛出处**｜2024C（0-1 规划，一等奖论文关键词）、2021C（分配决策）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import milp, LinearConstraint, Bounds

c = -profit                                       # milp 求 min，最大化取负
cons = LinearConstraint(A_area, -np.inf, area_cap)
res = milp(c=c, constraints=[cons], integrality=np.ones(n),   # 1=整数, 0=连续
           bounds=Bounds(0, np.inf))
assert res.success, res.message
```
模板：`1_skill/code-templates/python/optimization/integer_programming_template.py`

**别用它的时候**｜目标或约束非线性 → 先试能不能线性化（分段线性、对数变换），
不行再上 §3.9。

## §3.2 动态规划

**是什么**｜把问题拆成阶段，每阶段的最优解只依赖上一阶段的状态，逐阶段递推。

**什么时候用**｜三个特征同时满足：**阶段划分明确**（时间/位置/物品序号）、
**无后效性**（未来只看当前状态，不看怎么来的）、**子问题重叠**。
"多阶段决策""分几批""到第 k 天为止"就是它。

**核心**｜写出三样东西，DP 就写完了：
```
状态定义   dp[i][s] = 前 i 阶段、状态为 s 时的最优值    ← 最难的一步
转移方程   dp[i][s] = opt_a { dp[i-1][s'] + cost(s', a, s) }
边界与答案 dp[0][·] = ?，答案 = opt_s dp[n][s]
```
**状态定义写好了，转移方程通常是显然的**。反过来也成立：转移写不出来，多半是状态少了一维。

**参数与坑**｜
- **无后效性一定要验证**。带"累计已用量"影响未来的问题，必须把累计量放进状态，
  否则 DP 给出的答案偏优且不报错。
- 连续状态要离散化，**离散精度直接决定误差**，要做精度收敛检查。
- 复杂度 = 状态数 × 转移数。先估这个数，$>10^8$ 就要想办法压维（滚动数组、单调队列）。
- **必须能回溯出决策路径**，光有最优值不行——2022A 讲评那条"计算结果不完整"就是指这个。
  存 `choice[i][s]` 再反向走一遍。

**国赛出处**｜2021C（动态规划，一等奖）、2024B（多阶段决策，官方主线之一）。

**骨架**｜
```python
import numpy as np
NEG = -np.inf
dp = np.full((n+1, S), NEG); dp[0, s0] = 0.0
choice = np.zeros((n+1, S), int)
for i in range(1, n+1):
    for s in range(S):
        for a in actions(s):
            s_prev, gain = prev_state(s, a), reward(i, s, a)
            if dp[i-1, s_prev] + gain > dp[i, s]:
                dp[i, s], choice[i, s] = dp[i-1, s_prev] + gain, a
best_s = int(np.argmax(dp[n])); path = []            # 回溯决策序列
for i in range(n, 0, -1):
    path.append(choice[i, best_s]); best_s = prev_state(best_s, choice[i, best_s])
path.reverse()
```

**别用它的时候**｜状态维度 ≥ 4 → 维数灾难，改近似 DP 或启发式。
没有阶段结构 → 不是 DP，别硬套。

## §3.3 全枚举 + 逻辑剪枝

**是什么**｜把所有可行组合列出来逐个算，取最好。**这是精确解，不是"笨办法"。**

**什么时候用**｜组合数在几十到几百万之间（现代 CPU 每秒能算 $10^6$ 个中等复杂度的组合）。
国赛的统计决策类题目**经常故意把组合数设计得很小**。

**核心**｜
```
枚举全部组合 → 用逻辑必要条件剪掉不可行的 → 对每个可行组合算目标 → 取最优
```
**剪枝要靠反证，不是靠经验。** 2024B 官方原文：
> "如果在装配成品时，零配件没有做过检测，则**拆解时一定要对零配件做检测**，
> 否则不合格的零配件永远在成品中，将会有**无限次的拆解或赔偿**。"

这段话把一整类组合直接排除了，且给出了严格理由——**这样的剪枝论证本身就是得分点**。

**参数与坑**｜
- **在正文里明确写"因组合数仅 N，枚举即得精确解"**。2024B 官方就是逐一列出 16 种组合
  （`NNN、NNY、…、NYY_YNY`）。写了这句，评委知道你判断过复杂度；不写，看起来像不会优化。
- 别忘了**输出完整的组合对比表**（每种组合的期望利润），不要只报最优那一行。
  这直接对上"计算结果不完整""没有很好地呈现结果"。
- 用 `itertools.product` / `combinations` 生成，别手写嵌套循环（容易漏）。

**国赛出处**｜**2024B 官方主线就是枚举**。这是"简单方法拿满分"的标准案例。

**骨架**｜
```python
from itertools import product
import pandas as pd

rows = []
for combo in product([0, 1], repeat=k):           # 2^k 种组合
    if not feasible(combo):                       # 逻辑剪枝，附论证
        continue
    rows.append({**dict(zip(names, combo)), 'profit': expected_profit(combo)})
df = pd.DataFrame(rows).sort_values('profit', ascending=False)
df.to_csv('results/combos.csv', index=False)      # 完整表，不只最优行
```

**别用它的时候**｜组合数 $>10^7$ → 先剪枝，剪不动再上 §3.10 或 §3.7。
连续变量 → 离散化后枚举只是近似，要说明离散精度。

## §3.4 贪心与启发式

**是什么**｜每步取当前看起来最好的选择，不回溯。快，但一般不最优。

**什么时候用**｜① 问题有**拟阵结构**（如最小生成树）时贪心是精确的；
② 需要一个**快速可行解**当基线或当智能算法的初始种群；③ 规模太大只能要近似解。

**核心**｜定义"当前最好"的评价指标（贪心准则）→ 排序 → 依次取，取不了就跳过。
贪心的全部技术含量在**准则怎么选**：单位成本收益比、最早截止时间、最大剩余容量……
准则不同结果差很多，**论文里要说明为什么选这个准则**，并给出与其他准则的对比。

**参数与坑**｜
- **贪心的结果必须给出与上界/下界的差距**，否则评委无法判断好坏。
  最简单的上界：松弛掉整数约束的 LP 最优值。写"贪心解为 LP 上界的 96.3%"比只报一个数强得多。
- **贪心一定要配一个改进步骤**（局部搜索、2-opt、或喂给 §3.10 当初始解）。
  只报贪心结果容易被认为没做优化。

**国赛出处**｜2021C、2022B、2023B、2024C（一等奖论文均有"贪心"关键词，
但都是作为骨架的一环，不是唯一方法）。

**骨架**｜
```python
order = sorted(range(n), key=lambda i: value[i] / cost[i], reverse=True)  # 贪心准则
picked, used = [], 0.0
for i in order:
    if used + cost[i] <= budget:
        picked.append(i); used += cost[i]
lp_bound = linprog(-value, A_ub=[cost], b_ub=[budget], bounds=(0,1)).fun * -1
print(f'贪心/LP上界 = {sum(value[i] for i in picked)/lp_bound:.3%}')   # 必报
```

**别用它的时候**｜要精确解且规模允许 → §3.1 或 §3.3。
问题有明显的阶段结构 → §3.2 DP 通常又快又精确。

## §3.5 非线性最小二乘（LM / trust-region）

**是什么**｜给定正演模型 $y=g(\mathbf x;\boldsymbol\theta)$ 和观测 $\{y_i\}$，
求使残差平方和最小的参数：$\min_{\boldsymbol\theta}\sum_i \big(y_i-g(x_i;\boldsymbol\theta)\big)^2$。

**什么时候用**｜**反演题的主力**。观测点数 > 参数个数（超定），要"最好地解释全部数据"。

**核心**｜Levenberg–Marquardt 在高斯-牛顿和梯度下降之间插值：
$$
(\mathbf J^{\mathsf T}\mathbf J+\lambda\,\mathrm{diag}(\mathbf J^{\mathsf T}\mathbf J))\,\Delta\boldsymbol\theta=\mathbf J^{\mathsf T}\mathbf r
$$
$\lambda$ 大时像梯度下降（稳），小时像高斯-牛顿（快）。每步按残差降没降调整 $\lambda$。

**参数与坑（这一条的坑最多，也最值钱）**｜
- **参数量纲差几个数量级会毁掉收敛**。厚度 $10^{-6}$ m 和折射率 $\sim3$ 放一起，
  Jacobian 条件数上万。**必须无量纲化**：把每个参数除以其典型值，让所有参数都在 $O(1)$。
- **给正演模型留标定自由度**。凡是用绝对幅值反演的，加增益 $g$ 和偏置 $b$ 两个待估量。
  2025B 实测：加了之后独立检出附件间 10% 的标定差；不加，这份误差全变成折射率/厚度误差（各 7%）。
- **要输出参数不确定度**，不是只给点估计：
  $\mathrm{Cov}(\hat{\boldsymbol\theta})\approx \hat\sigma^2(\mathbf J^{\mathsf T}\mathbf J)^{-1}$，$\hat\sigma^2=\mathrm{RSS}/(n-p)$。
  `least_squares` 的 `res.jac` 可以直接算。**报 $\pm$ 就比只报数值高一档。**
- **残差必须画图看**。残差有结构（趋势、周期）说明模型形式错了，光看 RSS 看不出来。
- 多解/局部极小 → 多组初值跑，看是否收敛到同一处；不同就说明问题病态，要加正则或减参数。
- 用 `method='trf'` 支持参数上下界（物理约束），比无约束的 `'lm'` 更适合国赛。

**联合拟合 vs 联立求解**｜多工况数据的默认用法是**联合拟合**（同一组参数受更多约束，良态），
不是**联立求解**（用工况之差解新增未知量，常常病态）。2025B 实测后者误差放大 **356×**。

**国赛出处**｜2021A（非线性最小二乘）、2025B（Cauchy 色散模型联合拟合，官方与一等奖主线）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import least_squares

theta0 = np.array([7.0, 2.6, 1.0, 0.0])                 # d, n0, gain, bias
scale  = np.array([1.0, 1.0, 1.0, 1.0])                 # 先无量纲化到 O(1)

def resid(p):
    d, n0, g, b = p * scale
    return g * forward(d, n0) + b - y_obs

res = least_squares(resid, theta0/scale, method='trf',
                    bounds=([1, 1, .5, -.2], [20, 5, 2, .2]),
                    x_scale='jac', xtol=1e-14, ftol=1e-14)
J = res.jac; dof = len(y_obs) - len(theta0)
cov = np.linalg.inv(J.T @ J) * (res.fun @ res.fun) / dof
print(res.x * scale, '±', np.sqrt(np.diag(cov)) * scale)   # 必须报不确定度
```

**别用它的时候**｜残差有重尾/离群点 → 加 `loss='soft_l1'` 或 `'huber'`。
参数个数 ≥ 观测数 → 欠定，要加正则（岭/Lasso）或减参数。

## §3.6 局部优化（BFGS / SLSQP / trust-constr）

**是什么**｜从初值出发，沿下降方向迭代到局部最优。BFGS 用梯度和近似 Hessian，
SLSQP 处理带约束问题。

**什么时候用**｜目标光滑、维度中等、**初值靠谱**（通常来自 §1.4 粗扫或物理估算）。
也用作群体智能算法的"抛光"步骤。

**核心**｜BFGS 每步：$\mathbf d_k=-H_k^{-1}\nabla f$，线搜索定步长，用 $(\Delta\mathbf x,\Delta\nabla f)$ 更新 $H$。
带约束时 SLSQP 解一个二次规划子问题得下降方向。

**参数与坑**｜
- **无量纲化同 §3.5**：变量尺度差异大时先归一化，否则收敛极慢或早停。
- **数值梯度默认步长常常不合适**。目标函数由仿真给出（含离散化噪声）时，
  数值梯度是噪声，优化器会原地打转。此时改用无梯度方法（`Nelder-Mead`、`Powell`）或 §3.9。
- **`success=True` 不代表找到全局最优**，只代表满足了局部收敛判据。
  **必须多起点验证**：随机取 20 个初值都跑，看最优值是否一致。
- 约束写成 `{'type':'ineq','fun':g}` 时，scipy 的约定是 $g(x)\ge0$（**不是 $\le$**）。写反是高频 bug。

**国赛出处**｜2021A（BFGS，一等奖论文关键词）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import minimize

cons = [{'type': 'ineq', 'fun': lambda x: cap - x.sum()}]    # 注意：≥0 的约定
best = None
for x0 in rng.uniform(lo, hi, size=(20, d)):                  # 多起点
    r = minimize(obj, x0, method='SLSQP', bounds=list(zip(lo, hi)),
                 constraints=cons, options={'ftol': 1e-12, 'maxiter': 500})
    if r.success and (best is None or r.fun < best.fun):
        best = r
print(best.x, best.fun, '| 收敛次数:', best.nit)
```

**别用它的时候**｜目标多峰且初值不明 → 先 §1.4 粗扫或直接 §3.9。
不可导/离散 → §3.10。

## §3.7 遗传算法（GA）

**是什么**｜维护一个解的种群，通过选择、交叉、变异迭代进化。

**什么时候用**｜目标不可导、解空间离散或混合（连续+离散）、可行解结构复杂
（排列、分组、拓扑）。**连续无约束问题上它通常不如差分进化（§3.9）**。

**核心**｜
```
初始化种群 → 评估适应度 → 选择（轮盘赌/锦标赛）→ 交叉 → 变异
  → 精英保留（最优个体直接进下一代）→ 回到评估，直到收敛
```
**编码方式是 GA 的全部技术含量**：
- 连续变量 → 实数编码（别用二进制，精度受位数限制）
- 排列问题（TSP、调度）→ 顺序编码 + 部分映射交叉（PMX）/顺序交叉（OX），
  **普通单点交叉会产生非法解**
- 分组问题 → 组标签编码，注意标签置换等价（同一分组有多种编码）

**参数与坑**｜
- 常用参数：种群 50–200、交叉率 0.7–0.9、变异率 0.01–0.1、代数 200–1000。
  **论文里必须写出实际用的值**和"怎么定的"（试了几组、看收敛曲线）。
- **精英保留必须开**，否则最优解会被交叉/变异破坏，收敛曲线会往回跳。
- **必须固定随机种子并报多次独立运行的统计**（最优/均值/标准差，至少 10 次）。
  只报一次运行的最优值，评委无法判断稳定性。
- **必须画收敛曲线**（代数 vs 最优/平均适应度）。这是"给出具体算法"的直接证据。
- 约束处理：优先**修复法**（把非法解拉回可行域）> 罚函数 > 直接丢弃。
  罚函数的权重难调，权重不对会把可行域外的解选进来。

**国赛出处**｜2022A（遗传搜索）、2023A、2024B（遗传+精英策略）、2024C（DEGA）、2025C。
一等奖论文里出现 3 次。**注意 2022A 的正解是闭式解，遗传只是辅助验证。**

**骨架**｜
```python
from scipy.optimize import differential_evolution   # 连续问题：直接用 DE，见 §3.9
# 离散/排列问题用自写 GA 或 deap；关键是这三行必须有：
rng = np.random.default_rng(42)                     # 固定种子
history = []                                        # 记录每代最优 → 收敛曲线
runs = [ga_once(seed=s) for s in range(10)]         # 10 次独立运行报统计
print(f'最优 {max(runs):.4f}  均值 {np.mean(runs):.4f}  标准差 {np.std(runs):.4f}')
```
模板：`1_skill/code-templates/python/optimization/ga_template.py`

**别用它的时候**｜有解析解（2022A）、组合数很小（2024B）、目标光滑可导 → 都别用 GA。
纯连续问题 → §3.9 差分进化通常更好且参数更少。

## §3.8 粒子群（PSO）

**是什么**｜每个粒子记住自己的历史最优 $p_i$ 和群体最优 $g$，速度向两者靠拢。

**什么时候用**｜连续、低到中维（≤ 30）、目标求值不太贵。收敛快，参数少，代码短。

**核心**｜
$$
\mathbf v_i\leftarrow w\mathbf v_i+c_1r_1(\mathbf p_i-\mathbf x_i)+c_2r_2(\mathbf g-\mathbf x_i),\qquad
\mathbf x_i\leftarrow\mathbf x_i+\mathbf v_i
$$
经典参数：$w$ 从 0.9 线性降到 0.4（前期探索后期收敛），$c_1=c_2=2.0$（或 1.49445 配 $w=0.729$ 的收缩因子版）。

**参数与坑**｜
- **必须限速**：$|v|\le v_{\max}=0.2\times$（变量范围），不限速粒子会飞出可行域然后震荡。
- **早熟收敛是 PSO 的典型病**：所有粒子挤到一起后就不动了。
  检测方法是看种群标准差；救法是加变异或重启部分粒子。
- 边界处理：反弹（速度取反）比截断（clip）好，截断会让粒子粘在边界上。
- 同 §3.7：**固定种子、多次运行报统计、画收敛曲线**，三件缺一不可。

**国赛出处**｜2023A（讲评 §2.4 展示了粒子群结果）、2024A（一等奖）。

**骨架**｜
```python
import numpy as np
def pso(f, lo, hi, n=40, iters=300, seed=0):
    rng = np.random.default_rng(seed)
    lo, hi = np.asarray(lo,float), np.asarray(hi,float)
    x = rng.uniform(lo, hi, (n, len(lo))); v = np.zeros_like(x)
    vmax = 0.2 * (hi - lo)
    p, pv = x.copy(), f(x); g = p[pv.argmin()].copy(); gv = pv.min(); hist=[gv]
    for k in range(iters):
        w = 0.9 - 0.5 * k / iters                          # 惯性权重线性递减
        r1, r2 = rng.random((2, n, len(lo)))
        v = np.clip(w*v + 2*r1*(p-x) + 2*r2*(g-x), -vmax, vmax)   # 限速
        x = np.clip(x + v, lo, hi)
        val = f(x); upd = val < pv; p[upd], pv[upd] = x[upd], val[upd]
        if pv.min() < gv: gv, g = pv.min(), p[pv.argmin()].copy()
        hist.append(gv)
    return g, gv, hist                                     # hist 用来画收敛曲线
```

**别用它的时候**｜维度 > 30 或强约束 → §3.9 差分进化更稳。
离散排列 → §3.7 GA 或 §3.10 SA。

## §3.9 差分进化（DE）

**是什么**｜用种群中个体之间的**差向量**作为变异步长，自适应地匹配目标函数的尺度。

**什么时候用**｜**连续多峰全局优化的默认选择**。参数少、鲁棒、scipy 自带、支持约束和整数变量。
国赛里凡是"连续变量 + 目标不可导或多峰"，先试它。

**核心**｜对每个个体 $\mathbf x_i$：
$$
\mathbf v=\mathbf x_{r_1}+F(\mathbf x_{r_2}-\mathbf x_{r_3}),\quad
\mathbf u_j=\begin{cases}v_j,&\text{rand}<CR\ \text{或}\ j=j_{\text{rand}}\\ x_{ij},&\text{否则}\end{cases}
$$
$f(\mathbf u)<f(\mathbf x_i)$ 才替换（贪心选择）。$F\in[0.5,1]$，$CR\in[0.7,0.9]$。

**参数与坑**｜
- scipy 的 `differential_evolution` 默认 `mutation=(0.5,1)` 是**抖动**（每代随机取），
  比固定 $F$ 更鲁棒，一般不用改。
- **`polish=True`（默认）会在最后调 L-BFGS-B 抛光**——这是好事，但如果目标函数不可导，
  抛光可能把解弄坏。不可导时设 `polish=False`。
- **`workers=-1` 开多进程**能快好几倍，但要求目标函数可 pickle（不能是 lambda 或闭包）。
  国赛里这个加速经常是"跑得完"和"跑不完"的区别。
- `init='sobol'` 或 `'latinhypercube'` 比随机初始化覆盖更均匀。
- 同前：**固定 `seed=`、多次运行报统计、画收敛曲线**。

**国赛出处**｜2025A（差分进化，一等奖论文关键词）。

**骨架**｜
```python
from scipy.optimize import differential_evolution, NonlinearConstraint

nlc = NonlinearConstraint(lambda x: g(x), -np.inf, 0.0)    # g(x) ≤ 0
res = differential_evolution(obj, bounds=list(zip(lo, hi)),
                             constraints=(nlc,), strategy='best1bin',
                             maxiter=2000, popsize=25, tol=1e-10,
                             init='sobol', seed=42, workers=-1, polish=True,
                             callback=lambda xk, convergence: hist.append(obj(xk)))
print(res.x, res.fun, res.nit, res.message)
```

**别用它的时候**｜维度很高（>50）→ 先降维/重参数化（2025A 的做法）。
问题其实是求根或超定拟合 → §1.5 / §3.5，精度高好几位。

## §3.10 模拟退火（SA）

**是什么**｜以概率接受变差的解（温度越高越容易接受），随温度下降逐渐只接受改进，从而跳出局部最优。

**什么时候用**｜**离散组合优化**（排列、分组、选址）、邻域结构容易定义、目标函数增量可快速计算。

**核心**｜
```
当前解 s，温度 T
  新解 s' = 邻域扰动(s)
  Δ = f(s') − f(s)
  若 Δ 改进 或 rand() < exp(−|Δ|/T)  →  接受
  T ← α·T   (α ∈ [0.95, 0.99])
```
Metropolis 准则 $\exp(-\Delta/T)$ 是全部理论所在。

**参数与坑**｜
- **初温要按目标函数尺度定，不能拍脑袋**。做法：随机采 100 对邻域解，
  取 $|\Delta|$ 的均值，令初温使初始接受率约 0.8，即 $T_0\approx \overline{|\Delta|}/\ln(1/0.8)$。
  **初温写死成 100 是最常见的错误**——目标函数尺度一变，退火就退化成随机游走或纯爬山。
- **邻域设计比降温策略重要得多**。排列问题用 2-opt / swap / insert 三种混合，
  只用 swap 容易陷住。
- **增量计算目标函数**（只算变化部分）能快 10–100 倍，这决定了迭代次数够不够。
- 每个温度下要迭代若干次（Markov 链长度，通常 100–1000）才降温。
- 同前：固定种子、多次运行报统计、画"温度-最优值"曲线。

**国赛出处**｜2023B、2023C、2024B（一等奖论文关键词）。

**骨架**｜
```python
import numpy as np
def sa(f, s0, neighbor, iters=200_000, alpha=0.997, seed=0):
    rng = np.random.default_rng(seed)
    d = [abs(f(neighbor(s0, rng)) - f(s0)) for _ in range(100)]
    T = np.mean(d) / np.log(1/0.8)                    # 按尺度定初温
    s, fs = s0, f(s0); best, fbest, hist = s0, fs, []
    for _ in range(iters):
        s2 = neighbor(s, rng); f2 = f(s2); delta = f2 - fs
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-12)):
            s, fs = s2, f2
            if fs < fbest: best, fbest = s, fs
        T *= alpha; hist.append(fbest)
    return best, fbest, hist
```
模板：`1_skill/code-templates/python/optimization/sa_template.py`

**别用它的时候**｜连续变量 → §3.9 DE 通常更好。
组合数很小 → §3.3 枚举给精确解。

## §3.11 蚁群算法（ACO）

**是什么**｜蚂蚁按信息素浓度概率地选路，走得好的路上信息素积累更多，逐渐收敛到好路径。

**什么时候用**｜**路径类组合问题**：TSP、车辆路径、网络流、有向图上的序列决策。
它的优势是天然处理"构造式"解（一步步搭出一个解）。

**核心**｜选择概率
$$
p_{ij}=\frac{\tau_{ij}^{\alpha}\eta_{ij}^{\beta}}{\sum_k \tau_{ik}^{\alpha}\eta_{ik}^{\beta}},\qquad
\tau_{ij}\leftarrow(1-\rho)\tau_{ij}+\sum_m \Delta\tau^m_{ij}
$$
$\eta$ 是启发式信息（常取 $1/d_{ij}$），$\alpha\approx1$、$\beta\approx2\text{–}5$、蒸发率 $\rho\approx0.1$。

**参数与坑**｜
- **$\beta$ 太大退化成贪心，$\alpha$ 太大过早收敛**。$\beta/\alpha\approx2\text{–}5$ 是经验区间。
- 要加**信息素上下界**（MAX-MIN 蚁群），否则某条路信息素归零后永远选不到。
- 蚂蚁数通常取城市数量级；迭代几百代。**计算量比 SA/GA 大**，规模大时要掂量。
- 国赛里 ACO 用得比 SA/GA 少，用它就要说清**为什么这个问题适合构造式搜索**，
  否则正好撞在"乱套方法"上。

**国赛出处**｜2024B（一等奖论文关键词）。

**骨架**｜见 `1_skill/code-templates/python/optimization/`（可参考 GA/SA 模板改写），
或用 `networkx` 做图结构 + 上面的公式手写，代码量约 40 行。

**别用它的时候**｜不是路径/构造型问题 → 用 SA 或 GA，别为了"看起来高级"上蚁群。

## §3.12 多目标优化与 NSGA-II

**是什么**｜多个冲突目标时不存在单一最优，求的是 **Pareto 前沿**：
没有别的解在所有目标上都不差且至少一项更好。

**什么时候用**｜题面同时要求"成本最低"和"风险最小"、"产量最大"和"污染最少"。
**关键判断**：这些目标能不能合理加权成一个？能就别用多目标（加权法更简单可解释）。

**核心（NSGA-II 三个部件）**｜
1. **非支配排序**：把种群分层，第 1 层是当前 Pareto 前沿；
2. **拥挤距离**：同层内偏好稀疏区域的个体，保持前沿分布均匀；
3. **精英合并**：父代+子代合并后再选，保证前沿不退化。

**处理多目标的三条路（按国赛适用性排序）**：

| 方法 | 适用 | 说明 |
|---|---|---|
| **主要目标法** | 有明确主次 | 主目标优化，次目标转成约束（"成本不超过 X"）。最简单，最好解释 |
| **加权和 / 理想点法** | 权重有依据 | 权重必须说明来源（§八"任何选择都要有依据"），别拍脑袋 |
| **NSGA-II 出前沿** | 真要看权衡 | 前沿画出来后**仍要选一个推荐解**并说明选择理由 |

**参数与坑**｜
- **目标必须先归一化**，否则量纲大的目标主导拥挤距离，前沿会畸形。
- **前沿画出来不算完**。2022A 讲评"没有对结果进行分析"就是指这个——
  要指出前沿的拐点（knee point）、说明哪一段是有实际意义的、最后**给一个推荐方案**。
- 目标数 ≥ 4 时非支配解占比激增，NSGA-II 失效，要改 NSGA-III 或降目标数。
- 同前：固定种子、多次运行、报超体积（hypervolume）等前沿质量指标。

**国赛出处**｜2023C（NSGA-II、VIKOR，一等奖论文关键词）、2023B（多目标主要目标法）。

**骨架**｜模板：`1_skill/code-templates/python/optimization/nsga2_template.py`
```python
# 简化版非支配排序（判断第一前沿）
import numpy as np
def pareto_front(F):                 # F: (n, m)，各列越小越好
    keep = np.ones(len(F), bool)
    for i in range(len(F)):
        if keep[i]:                                    # i 已被淘汰就不必再用它筛
            # 被 i 支配 = 各项都不比 i 好，且至少一项更差
            dominated = np.all(F >= F[i], 1) & np.any(F > F[i], 1)
            keep[dominated] = False
    return np.flatnonzero(keep)
# 自检：目标越小越好时，[[1,5],[2,3],[3,1],[4,6]] 的前沿应是 [0,1,2]
assert list(pareto_front(np.array([[1.,5],[2,3],[3,1],[4,6]]))) == [0,1,2]
```

**别用它的时候**｜目标其实不冲突（同增同减）→ 只留一个。
有明确主次 → 主要目标法，写论文更清楚。

# 第四族 · 统计推断

**这一族的共同点**：从有限样本说关于总体的话，**每句话都要带不确定性**。
**共同的坑**：报一个点估计就完事。国赛里"给出置信区间/显著性/敏感性"几乎总是加分项。

**这一族的核心纪律（2022C/2023C/2025C 连续三年被批的同一件事）**：
> "简单套用机器学习方法进行预测，是**完全错误的**"（2022C）
> "仅做简单的预测、拟合和回归是**不够的**"（2023C）
> "忽略了**异常判定与普通分类的区别**"（2025C）

翻译过来：**先想清楚统计问题是什么（估计？检验？判定？分组？），再选工具。**

## §4.1 分布拟合与 K-S 检验

**是什么**｜给一组样本，找一个理论分布来描述它，并检验拟合是否可接受。

**什么时候用**｜需要**分布本身**而不只是均值：算超额概率、做随机模拟的输入、
定安全库存、算风险。看到"服从什么分布""波动特征"就是它。

**核心**｜
```
先分离确定性成分（趋势、季节、时间效应）→ 对残差拟合分布 → 参数估计（MLE）
  → K-S / A-D 检验 → 看 Q-Q 图
```
K-S 统计量 $D_n=\sup_x|F_n(x)-F(x)|$，检验 $F_n$ 与理论 $F$ 的最大偏离。

**参数与坑**｜
- **顺序不能反**。2023C 的官方路径是**先分离时间效应再拟合分布**。
  直接对原始序列拟合分布，趋势会被当成"厚尾"，拟合出的分布完全没意义。
- **参数由同一批数据估出来时，标准 K-S 的 p 值是错的（偏保守）**。
  严格做法用 Lilliefors 检验或参数自助（bootstrap）重算临界值。
  国赛里至少要在论文里点出这个限制。
- **样本量大时 K-S 几乎必然拒绝**（$n>1000$ 时微小偏差也显著）。
  此时要看**效应量**（$D_n$ 本身多大）和 Q-Q 图，别只看 p 值。
- **候选分布要多试几个再比**（正态、对数正态、Gamma、Weibull、t），
  用 AIC/BIC 排序。只试正态然后说"服从正态"是站不住的。

**国赛出处**｜2023C（分布拟合 + K-S 检验，官方主线）。

**骨架**｜
```python
import numpy as np
from scipy import stats

resid = y - trend_fit(y)                                   # 先去趋势
cands = ['norm', 'lognorm', 'gamma', 'weibull_min', 't']
rows = []
for name in cands:
    dist = getattr(stats, name); par = dist.fit(resid)
    ll = dist.logpdf(resid, *par).sum(); k = len(par)
    D, p = stats.kstest(resid, name, args=par)
    rows.append((name, 2*k - 2*ll, D, p))                  # AIC, D, p
for r in sorted(rows, key=lambda t: t[1]): print(r)
stats.probplot(resid, dist='norm', plot=plt)               # Q-Q 图必画
```

**别用它的时候**｜只关心均值差异 → t 检验/ANOVA（§4.11）。
数据明显多峰 → 混合分布（GMM）或分组后分别拟合。

## §4.2 相关性：Pearson / Spearman / 卡方 / Fisher

**是什么**｜度量两个变量之间的关联强度并检验其显著性。

**什么时候用**｜"分析 X 与 Y 的关系""哪些因素影响 Z"。**几乎每道 C 题都要用。**

**核心与选择**｜

| 数据类型 | 用什么 | 说明 |
|---|---|---|
| 两个连续、近似正态、关系近似线性 | **Pearson** $r$ | 只测线性关系 |
| 两个连续、非正态或有离群点或单调非线性 | **Spearman** $\rho$ | 秩相关，稳健 |
| 有大量并列值的有序变量 | **Kendall** $\tau$ | 比 Spearman 更适合并列多的情形 |
| 两个分类变量 | **卡方检验** | 需要期望频数 ≥ 5 |
| 分类变量、期望频数不足 | **Fisher 精确检验** 或 Yates 校正 | 2×2 表首选 Fisher |
| **成分数据** | **先 CLR 变换（§9.1）再算** | 直接算 Pearson 必然失真 |

**参数与坑**｜
- **默认选 Spearman**。2023C 官方就是用 Spearman 而非 Pearson。
  国赛数据几乎不满足正态+线性，Pearson 用了要先给正态性证据。
- **相关不是因果**，且**相关系数大 ≠ 有用**。$n=1000$ 时 $r=0.07$ 也显著（$p<0.05$），
  但解释力 $r^2=0.5\%$，等于没有。**必须同时报 $r$ 和 $p$，并对 $r$ 的大小做解释。**
- **多重比较**：算 $k$ 个变量的两两相关就是 $\binom k2$ 次检验，
  要做 FDR 校正（§4.9），否则 20 个变量必然"发现"若干假相关。
- **成分数据的 Pearson 有偏负倾向**。官方极端例子：只有两个成分时 $\mathrm{PCC}(x_1,x_2)=-1$，
  与实际关系无关。看到"占比之和为 1"立刻转 §9.1。
- 卡方检验：期望频数 < 5 的格子超过 20% 就不能用，换 Fisher。

**国赛出处**｜2023C（Spearman，官方主线）、2024C（Spearman）、2022C（卡方/Fisher/Yates，官方）。

**骨架**｜
```python
from scipy import stats
from statsmodels.stats.multitest import multipletests
import numpy as np

rho, p = stats.spearmanr(x, y)
tab = np.array([[a, b], [c, d]])
if (stats.chi2_contingency(tab)[3] < 5).mean() > 0.2:      # 期望频数不足
    odds, p = stats.fisher_exact(tab)
else:
    chi2, p, dof, exp = stats.chi2_contingency(tab, correction=True)   # Yates
ps = [stats.spearmanr(X[:, i], y)[1] for i in range(X.shape[1])]
rej, q, *_ = multipletests(ps, alpha=0.05, method='fdr_bh')            # 必做
```

**别用它的时候**｜要控制混杂变量 → 偏相关或直接上回归（§4.3）。
关系非单调（U 型）→ 相关系数会接近 0 却不代表无关，改画图 + 分段分析。

## §4.3 回归：OLS / 多项式 / 分段线性

**是什么**｜用自变量的函数解释因变量的均值：$\mathbb E[y\mid \mathbf x]=f(\mathbf x;\boldsymbol\beta)$。

**什么时候用**｜要**量化影响大小**（不只是有没有关系）、要预测、要控制混杂变量。

**核心**｜OLS $\hat{\boldsymbol\beta}=(X^{\mathsf T}X)^{-1}X^{\mathsf T}\mathbf y$。四个前提假设：
线性、误差独立、同方差、（推断时）误差正态。**每个假设都对应一个诊断和一个补救**：

| 假设 | 怎么查 | 违反了怎么办 |
|---|---|---|
| 线性 | 残差 vs 拟合值图有无弯曲 | 加二次项、取对数、分段（下面） |
| 独立 | 同一对象多条记录？残差自相关（DW） | **混合效应模型 §4.5**、聚类稳健标准误 |
| 同方差 | 残差图有无喇叭形；BP 检验 | 取对数、WLS、稳健标准误 HC3 |
| 无多重共线 | VIF > 10 | 删变量、岭回归、PCA（但注意 §7.2） |

**分段线性回归**（2025C 官方路径的第二步）：在断点 $c$ 处分段，
用 $(x-c)_+=\max(x-c,0)$ 做基，即 $y=\beta_0+\beta_1x+\beta_2(x-c)_++\varepsilon$，
这样在 $c$ 处连续。**断点 $c$ 可以一起估**（网格搜 $c$，取 RSS 最小），
但要报断点的置信区间。

**参数与坑**｜
- **多项式次数 > 3 基本都是过拟合**，且端点外推会飞。要高次先想想是不是该分段或换机理形式。
- **$R^2$ 会随变量个数单调上升**，比较模型要用调整 $R^2$ 或 AIC/BIC。
- **标准化系数才能比较重要性**。原始系数的大小受量纲支配，不能横向比。
- **一定要报回归诊断图**（残差 vs 拟合、Q-Q、杠杆值）。只报系数表是"仅做简单回归"，
  这正是 2023C 讲评批的。

**国赛出处**｜2021B（多元多项式回归）、2025C（探索性简单回归 → 分段线性 → 非线性混合效应，
官方明确的三步递进）。

**骨架**｜
```python
import numpy as np, statsmodels.api as sm

X = sm.add_constant(np.column_stack([x, np.maximum(x - c, 0)]))   # 分段线性基
m = sm.OLS(y, X).fit(cov_type='HC3')                              # 稳健标准误
print(m.summary())
# 断点一起估：网格搜 c
c_grid = np.linspace(x.min()+1, x.max()-1, 200)
rss = [sm.OLS(y, sm.add_constant(np.column_stack([x, np.maximum(x-c,0)]))).fit().ssr
       for c in c_grid]
c_hat = c_grid[int(np.argmin(rss))]
```

**别用它的时候**｜同一对象多条记录 → §4.5 混合效应（否则独立性假设破了）。
因变量是 0/1 → §4.4 Logistic。因变量是计数 → 泊松/负二项回归。

## §4.4 Logistic 回归

**是什么**｜因变量是二分类时，建模 $\log\frac{p}{1-p}=\boldsymbol\beta^{\mathsf T}\mathbf x$。

**什么时候用**｜"是否达标""是否异常""会不会发生"。也是分类问题的**基线模型**——
上任何复杂 ML 之前先跑它，作为对照。

**核心**｜$p=\dfrac{1}{1+e^{-\boldsymbol\beta^{\mathsf T}\mathbf x}}$，MLE 用 IRLS 求解。
系数 $\beta_j$ 的解释是**对数几率比**：$x_j$ 加 1，几率乘 $e^{\beta_j}$。

**参数与坑**｜
- **阈值 0.5 不是天经地义的**。代价不对称（漏检 vs 误报代价差很多）时，
  阈值应由代价矩阵定：$p^\*=\frac{C_{FP}}{C_{FP}+C_{FN}}$，或按给定 FPR 定。
  **国赛里不讨论阈值怎么定，基本就是丢分。**
- **完全分离**（某变量能完美区分）时 MLE 不存在，系数跑向无穷。用惩罚（Firth / L2）解决。
- 类别极不平衡时**别用准确率**，看 AUC、PR 曲线、给定 FPR 下的召回。
- **罕见事件判定不要直接用它**——见 §4.10，2025C 讲评点名批过。

**国赛出处**｜2021B（Logistic，一等奖论文关键词）。

**骨架**｜
```python
import statsmodels.api as sm, numpy as np
m = sm.Logit(y, sm.add_constant(X)).fit(disp=0)
print(m.summary(), '\nOR =', np.exp(m.params))        # 报几率比更好解释
p = m.predict(sm.add_constant(X))
thr = C_fp / (C_fp + C_fn)                            # 阈值由代价定，不用 0.5
```

**别用它的时候**｜罕见事件 + 控假阳性 → §4.10 统计判定。
关系强非线性且样本多 → §7.3 树模型（但要报为什么线性不够）。

## §4.5 混合效应模型（LMM / NLME）

**是什么**｜在普通回归上加**随机效应**，处理"同一对象的多条记录不独立"。

**什么时候用（这是 2025C 的官方主线，命中率极高）**｜
数据里存在**分组结构**：同一个人多次测量、同一个店多天销售、同一块地多年产量。
**看到"重复测量""纵向数据""每个对象若干条"就是它。**

**核心**｜
$$
\mathbf y_i=X_i\boldsymbol\beta+Z_i\mathbf b_i+\boldsymbol\varepsilon_i,\qquad
\mathbf b_i\sim N(\mathbf 0,\ G),\ \ \boldsymbol\varepsilon_i\sim N(\mathbf 0,\sigma^2I)
$$
$\boldsymbol\beta$ 是**固定效应**（人群平均规律，你要报的），
$\mathbf b_i$ 是**随机效应**（个体偏离）。
- **随机截距**：每个个体基线不同；
- **随机斜率**：每个个体的变化速率也不同（`re_formula='~x'`）。

**参数与坑（这一条的静默陷阱最多，本项目实测栽过）**｜
- **`fittedvalues` 含随机效应**。用它算的 $R^2$ 是**条件** $R^2$，会比边际 $R^2$ 高一倍多，
  报出去就是虚高。要边际预测用 `exog @ params`，别用 `fittedvalues`。
  （2025C 端到端演练实测，见 `静默陷阱.md` §0。）
- **`MixedLM` 的 `.aic` 可能是 NaN**，用 REML 拟合时 AIC 不可比。
  比较固定效应结构必须 `reml=False`（改用 ML），比较随机效应结构才用 REML。
- **不收敛很常见**，且 `summary()` 照样打印。**必须检查 `m.converged`**。
  不收敛的救法：简化随机结构（先只留随机截距）、中心化自变量、换优化器 `method='powell'`。
- 随机斜率与随机截距的相关项会让模型过参数化，样本少时先设 `re_formula` 不含相关。
- 用**方差分解恒等式**自查：总方差 ≈ 固定效应方差 + 随机效应方差 + 残差方差。对不上说明取值取错了。

**国赛出处**｜2025C（讲评首推非线性混合效应模型；一等奖论文关键词"线性混合效应模型"）。

**骨架**｜
```python
import statsmodels.formula.api as smf, numpy as np

m = smf.mixedlm('y ~ x + z', data=df, groups=df['id'], re_formula='~x').fit(reml=False)
assert m.converged, '未收敛：先简化随机结构或中心化自变量'
print(m.summary())

# 边际预测（不含随机效应）——别用 m.fittedvalues
import patsy
Xd = patsy.dmatrix('x + z', df, return_type='dataframe')
y_marg = Xd.values @ m.fe_params.values
r2_marg = 1 - np.var(df.y - y_marg) / np.var(df.y)
```

**别用它的时候**｜每个对象只有一条记录 → 普通回归就够。
分组只是想控制，不关心组间方差 → 固定效应（加分组哑变量）更简单。

## §4.6 假设检验与区间估计（含二项检验）

**是什么**｜用样本判断关于总体参数的命题，并给出参数的区间估计。

**什么时候用**｜**抽样检验方案设计**（2024B 的官方主线就是这个）、
比较两组有无差异、判断是否达标。

**核心**｜抽样方案设计的完整逻辑：
```
定 H0/H1（"次品率 ≤ p0" vs "> p0"）
  → 定两类错误：α（第一类，弃真）与 β（第二类，取伪）
  → 由 α、β、p0、p1 反解样本量 n 与判定界 c
  → 报出 n 与 c，以及 OC 曲线
```
二项精确检验：$P(X\ge c\mid p_0)=\sum_{k\ge c}\binom nk p_0^k(1-p_0)^{n-k}\le\alpha$。
正态近似：$c\approx np_0+z_{1-\alpha}\sqrt{np_0(1-p_0)}$。

**官方对"用哪个"的态度（重要，别判错）**｜
> 2024B 讲评："**学生使用公式一（正态近似），不能说一定是错误的**…只是数值上略有差异，
> 方法是相同的。总之，是否使用公式一不重要，**重要的是，抽样数要与次品数有关**。"

命题人查的是**量与量的依赖关系对不对、逻辑闭不闭合**，不是"用没用最严格的工具"。

**参数与坑**｜
- **$n$ 小或 $p$ 靠近 0/1 时正态近似不好**（经验规则 $np\ge5$ 且 $n(1-p)\ge5$），
  但按官方态度，用了要说明，不必然是错。稳妥做法：**两种都算，列表对比**，说明差异多大。
- **比例的置信区间别用正态公式**（Wald 区间在 $p$ 靠近 0/1 时会超出 $[0,1]$）。
  用 **Wilson** 或 **Clopper-Pearson**（`statsmodels.stats.proportion.proportion_confint`）。
- **p 值不是"H0 为真的概率"**，也不是效应大小。论文里报 p 值必须同时报**效应量和置信区间**。
- 双侧还是单侧要和题面对上（"是否超过标准"是单侧）。

**国赛出处**｜**2024B 官方主线**："抽检方案 = 假设检验 + 区间估计"。查国标 GB/T 2828.1-2012。

**骨架**｜
```python
import numpy as np
from scipy import stats
from statsmodels.stats.proportion import proportion_confint

def design(p0, p1, alpha=0.05, beta=0.10, nmax=5000):
    """反解最小样本量 n 与判定界 c（二项精确）"""
    for n in range(1, nmax):
        c = stats.binom.ppf(1-alpha, n, p0) + 1              # 控制 α
        if stats.binom.cdf(c-1, n, p1) <= beta:              # 检查 β
            return n, int(c)
    return None
n, c = design(0.10, 0.20)
lo, hi = proportion_confint(count=x, nobs=n, alpha=0.05, method='wilson')
```

**别用它的时候**｜要在检测数量上再省 → §4.7 序贯抽样。
参数本身有先验信息 → §4.8 贝叶斯。

## §4.7 序贯抽样（SPRT）

**是什么**｜每抽一个样本就更新一次判断，达到阈值立刻停止，不必抽满固定样本量。
平均样本量比定量抽样少 30–50%。

**什么时候用**｜题面出现"**检测次数尽可能少**""在保证可靠性前提下降低成本"。
**这几个字就是在提示 SPRT。**

**核心**｜对数似然比逐样本累加：
$$
\Lambda_n=\sum_{i=1}^n\log\frac{f_1(x_i)}{f_0(x_i)},\qquad
\Lambda_n\ge\log\frac{1-\beta}{\alpha}\Rightarrow\text{接受 }H_1,\quad
\Lambda_n\le\log\frac{\beta}{1-\alpha}\Rightarrow\text{接受 }H_0
$$
两界之间就继续抽。伯努利情形 $\log\frac{f_1}{f_0}$ 只有两个值（次品/正品各一个），实现极简单。

**参数与坑**｜
- **必须设最大样本量截断**，否则理论上可能永不停止。截断后要重新核算实际的 $\alpha,\beta$。
- **要报平均样本量 ASN**（用蒙特卡洛模拟不同真实 $p$ 下的 ASN 曲线），
  这是 SPRT 相对定量抽样的全部卖点，不报等于白用。
- 实际的 $\alpha,\beta$ 与设计值有偏差（Wald 近似），要用模拟校验。

**国赛出处**｜2024B。官方点评："如果学生使用序贯抽样检验…还是一种不错的方法"——
**这是被官方明确认可的加分路线**。

**骨架**｜
```python
import numpy as np
def sprt(sample_fn, p0, p1, alpha=.05, beta=.10, nmax=1000, rng=None):
    A, B = np.log((1-beta)/alpha), np.log(beta/(1-alpha))
    l1, l0 = np.log(p1/p0), np.log((1-p1)/(1-p0))
    L, n = 0.0, 0
    while n < nmax:
        n += 1; L += l1 if sample_fn(rng) else l0
        if L >= A: return 'H1', n
        if L <= B: return 'H0', n
    return 'truncated', n

for p in [.05,.10,.15,.20,.30]:                       # ASN 曲线：必报
    ns = [sprt(lambda r: r.random() < p, .10, .20, rng=np.random.default_rng(s))[1]
          for s in range(2000)]
    print(f'p={p}: ASN={np.mean(ns):.1f}')
```

**别用它的时候**｜必须一次性抽完（破坏性检测、批量到货）→ 回 §4.6 定量抽样。

## §4.8 贝叶斯估计与共轭先验

**是什么**｜把参数当随机变量，用先验 + 数据得到后验分布。

**什么时候用**｜① 参数由**小样本抽样**得到，点估计不可靠；
② 有历史信息/行业经验可当先验；③ 要给**决策的翻转边界**而不只是一个数。

**核心（共轭对，背这三个够用）**｜

| 似然 | 共轭先验 | 后验 |
|---|---|---|
| 二项 $\mathrm{Bin}(n,p)$ | $\mathrm{Beta}(a,b)$ | $\mathrm{Beta}(a+x,\ b+n-x)$ |
| 泊松 $\mathrm{Pois}(\lambda)$ | $\mathrm{Gamma}(a,b)$ | $\mathrm{Gamma}(a+\sum x_i,\ b+n)$ |
| 正态（$\sigma$ 已知） | $N(\mu_0,\tau^2)$ | 精度加权平均 |

后验均值 = 先验与数据的加权平均，权重是各自的"等效样本量"。

**参数与坑**｜
- **先验必须说明来源**（历史数据、行业标准、无信息先验 Beta(1,1)），并**做先验敏感性分析**：
  换 2–3 组先验，看结论变不变。不做这一步，评委会认为先验是凑出来的。
- **交付的不是"重算一遍数字"，而是决策翻转边界**。
  2024B 那类题：把后验分布代进期望利润，报"当次品率后验均值超过 $p^\*$ 时，决策从 A 翻到 B"。
  这才是贝叶斯在决策题里的价值。
- 非共轭情形要 MCMC（`pymc`），国赛机器上未必装得了。**优先把模型凑成共轭形式**。
- 别把贝叶斯当成"多写一个模型"。用它必须回答："先验从哪来？后验怎么改变了决策？"

**国赛出处**｜2024B（贝叶斯估计 + 共轭先验，一等奖论文关键词）。

**骨架**｜
```python
from scipy import stats
import numpy as np
a, b = 2, 18                                    # 先验 Beta(2,18)：等效 20 次里 2 次品
post = stats.beta(a + x, b + n - x)
print('后验均值', post.mean(), '95% 可信区间', post.interval(0.95))

for prior in [(1,1), (2,18), (5,45)]:           # 先验敏感性：必做
    p = stats.beta(prior[0]+x, prior[1]+n-x)
    print(prior, '→ 决策', 'A' if p.mean() < p_star else 'B')
```

**别用它的时候**｜样本量很大 → 先验影响可忽略，频率派更简洁。
没有可辩护的先验来源 → 用无信息先验并说明，或干脆走 §4.6。

## §4.9 多重检验校正（Bonferroni / FDR）

**是什么**｜同时做 $m$ 次检验时，控制"至少一个假阳性"或"假阳性比例"。

**什么时候用**｜**逐个位点/逐个变量/逐个分组做检验**时。
$m=20$ 且各自 $\alpha=0.05$，至少一次假阳的概率是 $1-0.95^{20}=64\%$——不校正等于必然出错。

**核心**｜
- **Bonferroni**：用 $\alpha/m$ 作阈值。控制族错误率 FWER，**保守**，$m$ 大时几乎什么都发现不了。
- **Benjamini–Hochberg（FDR）**：把 p 值升序排，找最大的 $k$ 使 $p_{(k)}\le \frac km\alpha$，
  拒绝前 $k$ 个。控制的是**假发现比例**，功效高得多，**探索性分析的默认选择**。

**参数与坑**｜
- **"做了多少次检验"要诚实计数**，包括你试过但没写进论文的。
  只对最后报的 3 个变量校正，而实际筛了 50 个，是自欺。
- BH 假定检验独立或正相关；强负相关时用 BY 方法（`method='fdr_by'`）。
- **报校正后的 q 值，不是原始 p 值**。表格里两列都放最好。

**国赛出处**｜2025C 问题 4（异常判定，多个染色体/多个位点同时判定必须校正）。

**骨架**｜
```python
from statsmodels.stats.multitest import multipletests
rej, q, _, _ = multipletests(pvals, alpha=0.05, method='fdr_bh')
df['p'], df['q'], df['显著'] = pvals, q, rej      # p 和 q 都报
```

**别用它的时候**｜只做一次预先指定的检验 → 不需要校正。
目标是预测而非发现 → 用交叉验证的预测指标，不是 p 值。

## §4.10 异常/罕见事件判定（经验零分布 + 分层校正 + 三级判定）

**是什么**｜在"绝大多数是正常、少数异常、且假阳性代价高"的场景下做判定。
**它不是二分类**——这是 2025C 讲评点名批评的核心。

**什么时候用**｜疾病筛查、故障检测、质量异常、欺诈识别。
标志：**正例率 < 5%**、有明确的假阳性代价、要给"落地判定方案"而不只是一个模型。

**核心（照 2025C 官方路线的五步）**｜
```
1. 构造检验统计量 Z（有物理/生物含义，不是黑箱分数）
2. 建经验零分布 —— 用确认为阴性的样本估 Z 的分布，别直接套 N(0,1)
3. 按质量指标分层校正 —— 不同测序深度/不同批次的 Z 尺度不同，先标准化
4. 多重检验校正（§4.9）
5. 三级判定：阴性 / 可疑（建议复检） / 阳性，并报"给定 FPR 下的检出数"
```

**为什么不能用 XGBoost/逻辑回归直接分类**｜
> 2025C 评阅："多选择机器学习算法如 XGBoost、逻辑回归等…**忽略了异常判定与普通分类的区别**，
> **绝大多数队伍**此题完成效果并不理想，未能给出合理的落地判定方案"

三个具体原因：① 极端不平衡下分类器倾向全判阴性，准确率 99% 但毫无用处；
② 分类器给不出**可解释的判定阈值**，而落地方案必须能说"什么条件下判阳性"；
③ 分类器无法直接控制 FPR，而临床/工业场景是先定 FPR 再看检出率。

**这类题的质控要做**｜2025C 官方解问题 4 的第一步就是质控：
原始读段数 L、比对比例 M、唯一比对读段数 O 保留 ≥Q05，
重复读段比例 N、过滤比例 AA 保留 ≤Q95 的**中心 90% 截断**，604 例筛到 501 例。
注意这与"不做常规预处理"不矛盾——**判定流程的质控是领域方法的组成部分**
（见 `4_知识点总结` §四第一步）。本项目那轮演练没试质控路线，性能差了一个量级。

**参数与坑**｜
- **经验零分布必须来自确认阴性的样本**，不能用全体样本（会被阳性污染，阈值偏松）。
- **ML 可以做，但只当对照基线**，且要报 AUC / 给定 Sp 下的 Se，不报准确率。
- 报告格式：**在 Sp=99% 时的检出率**这种形式，比"AUC=0.81"有用得多，因为它可落地。

**国赛出处**｜**2025C 问题 4**（官方逐染色体 Se 0.92–1.00 @ Sp 99%）。

**骨架**｜
```python
import numpy as np
from statsmodels.stats.multitest import multipletests

z = (stat - stat_ref) / sd_ref                       # 1. 统计量
z_null = z[label == 0]                               # 2. 经验零分布（仅阴性样本）
resid = z - strata_model.predict(quality_cov)        # 3. 按质量指标分层校正
p = 2 * (1 - ecdf_null(np.abs(resid)))               # 经验 p 值
q = multipletests(p, method='fdr_bh')[1]             # 4. FDR
call = np.select([q < .01, q < .05], ['阳性', '可疑'], default='阴性')  # 5. 三级

thr = np.quantile(np.abs(z_null), 0.99)              # Sp=99% 的阈值
print('Sp=99% 时检出率 Se =', (np.abs(z[label==1]) > thr).mean())
```

**别用它的时候**｜正负样本均衡且无 FPR 约束 → 普通分类（§4.4 / §7.3）就够。

## §4.11 方差分析（ANOVA）

**是什么**｜比较多组均值是否有差异，把总变异分解成组间和组内。

**什么时候用**｜有 1–2 个**分类因素**（处理、批次、类型），看它们对连续响应有无影响，
以及**因素之间有无交互作用**。

**核心**｜$SS_{\text{total}}=SS_{\text{between}}+SS_{\text{within}}$，
$F=\frac{MS_{\text{between}}}{MS_{\text{within}}}$。双因素还要拆出交互项 $SS_{AB}$。

**参数与坑**｜
- 前提：正态 + 方差齐（Levene 检验）+ 独立。方差不齐用 Welch ANOVA，非正态用 Kruskal-Wallis。
- **F 显著只说明"至少有一组不同"**，要知道哪几组不同必须做事后多重比较（Tukey HSD）。
  只报 F 值就下"A 比 B 好"的结论是错的。
- **交互作用要先看**：交互显著时主效应的解释会变，必须先画交互作用图。
- 不平衡设计（各组样本量不等）要用 Type II/III 平方和，`statsmodels` 默认 Type II 要显式指定。

**国赛出处**｜2021B（双因素方差分析，一等奖论文关键词）。

**骨架**｜
```python
import statsmodels.api as sm, statsmodels.formula.api as smf
from statsmodels.stats.multicomp import pairwise_tukeyhsd
from scipy import stats

print(stats.levene(*groups))                                     # 方差齐性
m = smf.ols('y ~ C(A) * C(B)', data=df).fit()                    # * 含交互
print(sm.stats.anova_lm(m, typ=2))
print(pairwise_tukeyhsd(df.y, df.A))                             # 事后比较
```

**别用它的时候**｜因素是连续的 → 回归（§4.3）。
同一对象重复测量 → 重复测量 ANOVA 或 §4.5 混合模型。

## §4.12 蒙特卡洛模拟与积分

**是什么**｜用随机采样估计确定性的量（积分、概率、期望）或模拟随机系统。

**什么时候用**｜① 高维积分（维度 ≥ 4，网格法爆炸）；
② 不确定性传播（参数有分布，问结果的分布）；③ 复杂系统仿真；④ 给解析结果做独立交叉验证。

**核心**｜$\int_\Omega f\,\mathrm dx\approx \frac{V}{N}\sum_i f(\mathbf x_i)$，
标准误 $\approx \frac{\sigma}{\sqrt N}$——**与维度无关**，这是它对付高维的全部理由。
精度提高 10 倍要 100 倍样本，所以它精度低但可扩展。

**方差缩减（能省一个数量级样本量，写进论文是加分项）**｜
- **对偶变量**：同时用 $u$ 和 $1-u$，负相关抵消方差；
- **重要性采样**：在贡献大的区域多采；
- **分层/拉丁超立方（LHS）**：把空间分层，每层保证有样本。`scipy.stats.qmc.LatinHypercube`；
- **拟蒙特卡洛（Sobol 序列）**：误差可达 $O(N^{-1})$，比随机快一个数量级。`qmc.Sobol`。

**参数与坑**｜
- **必须报标准误或置信区间**。只报一个点估计，评委无法判断样本量够不够。
  $\mathrm{SE}=\hat\sigma/\sqrt N$，报 $\hat I\pm1.96\,\mathrm{SE}$。
- **必须固定随机种子**（`np.random.default_rng(42)`），否则结果不可复现，
  这直接违反"计算方法说明要写到能复现"。
- **别用全局 `np.random.seed()`**，用 `Generator`。前者在多模块/多进程下行为不可控。
- 样本量要做收敛图（$N$ vs 估计值），看它是不是稳住了。

**国赛出处**｜2021A（蒙特卡洛积分算接收比）、2023A（蒙特卡洛）、2024B/2024C（蒙特卡洛模拟）。

**骨架**｜
```python
import numpy as np
from scipy.stats import qmc

rng = np.random.default_rng(42)                     # 固定种子
sob = qmc.Sobol(d=4, scramble=True, seed=42)        # 拟蒙特卡洛，收敛更快
X = qmc.scale(sob.random(2**16), lo, hi)
vals = f(X)
I = vals.mean() * np.prod(np.array(hi) - np.array(lo))
se = vals.std(ddof=1) / np.sqrt(len(vals)) * np.prod(np.array(hi) - np.array(lo))
print(f'I = {I:.6f} ± {1.96*se:.6f} (95%)')         # 必须带误差

Ns = 2**np.arange(8, 17)                            # 收敛图
ests = [vals[:n].mean() for n in Ns]
```

**别用它的时候**｜一维或二维光滑积分 → §1.7 确定性积分快几个数量级且精度高。
问题本身确定性 → 别用随机方法冒充"稳健性分析"。

## §4.13 敏感性分析

**是什么**｜量化"输入参数变化多少，结论变化多少"。

**什么时候用**｜**每道题都要做**。讲评反复要求，也是"稳健性"章节的主要内容。

**核心（三个层次，按工作量递增）**｜

| 层次 | 做法 | 适用 |
|---|---|---|
| **局部（OAT）** | 每个参数单独 ±5%、±10%，看目标变化率 | 参数少、时间紧。**最低要求** |
| **单参数扫描** | 一个参数在合理范围内连扫，画曲线 | 要找**决策翻转点**时 |
| **全局（Sobol）** | 联合采样，分解方差得一阶/总效应指数 | 参数多、有交互作用 |

**局部灵敏度**：$S_j=\frac{\partial f/f}{\partial x_j/x_j}$（弹性系数，无量纲，可横向比较）。
**这个无量纲化很重要**——直接报 $\partial f/\partial x_j$ 无法比较不同量纲的参数。

**参数与坑**｜
- **扰动范围要有依据**：测量精度、行业波动、题面给的区间。拍脑袋取 ±10% 要说明理由。
- **OAT 查不出交互作用**。参数间明显耦合时必须上 Sobol，或至少做两两联合扫描（热力图）。
- **结论要写成"翻转边界"而不是"变化了 3%"**：
  "当运输成本上升超过 18% 时，最优方案从 A 变为 B"——这才是决策者要的。
- 敏感性分析的图**必须是主图之一**（一等奖图数中位 20 张，稳健性通常占 2–3 张）。

**国赛出处**｜2021A、2023A、2024B 讲评均提；2022A 讲评"没有对结果进行分析"直接指向这里。

**骨架**｜
```python
import numpy as np
base = solve(params)
elast = {k: ((solve({**params, k: v*1.05}) - base)/base) / 0.05     # 弹性系数
         for k, v in params.items()}

# 决策翻转点扫描
grid = np.linspace(0.8, 1.5, 71)
flip = [decision({**params, 'cost': params['cost']*g}) for g in grid]
turn = grid[np.flatnonzero(np.diff([f == flip[0] for f in flip]))[0]]
print(f'成本上升至 {(turn-1)*100:.1f}% 时决策翻转')

from SALib.sample import saltelli; from SALib.analyze import sobol   # 全局（可选）
```

**别用它的时候**｜没有不该用的时候。**不做敏感性分析是失分项。**

# 第五族 · 决策与风险

**这一族的共同点**：不确定性已经量化好了（分布已知或已估），现在要在不确定下做决策。
**共同的坑**：把不确定性求个平均就当确定性问题做。
"用期望值代替随机变量"在非线性目标下是错的（Jensen 不等式），且会系统性低估风险。

## §5.1 报童模型

**是什么**｜单周期库存/订货问题：订多了积压、订少了缺货，需求随机，求最优订货量。

**什么时候用**｜**"进多少货""备多少产能""留多少余量"**，且供需不匹配的两侧代价不同。
2023C 的官方解法核心就是它。

**核心（临界分位数公式，一定要会推）**｜
设单位缺货成本 $c_u$（underage）、单位积压成本 $c_o$（overage），需求分布 $F$，则
$$
Q^\*=F^{-1}\!\left(\frac{c_u}{c_u+c_o}\right)
$$
**这个比值叫临界分位数（critical ratio）**。推导：多订一件的期望边际收益
$= c_u P(D>Q)-c_o P(D\le Q)$，令其为 0 即得。

零售场景常写成：$c_u=$ 售价 − 成本（少卖一件损失的毛利），
$c_o=$ 成本 − 残值（多进一件的损失）。**这两个量怎么从题面映射过来，是这类题的真正难点。**

**参数与坑**｜
- **需求分布必须先估**（§4.1），且要**先剥离趋势和季节**再拟合。
  直接用历史需求的经验分位数在有趋势时是错的。
- **$c_u$ 里要不要算商誉损失/顾客流失**，题目通常不明说。
  做法：给一个范围，做敏感性分析（§4.13），报"$c_u$ 在什么区间内最优订货量稳定"。
- 多期、有补货、有残值结转 → 是**多期库存模型**，报童只是单期，要说明为什么可以按单期处理。
- **要报的不只是 $Q^\*$**：还要报期望利润、缺货概率、服务水平，以及 $Q$ 在 $Q^\*$ 附近的利润曲线
  （通常很平坦，这个"平坦性"本身是有价值的结论）。

**国赛出处**｜**2023C 官方主线**（讲评把报童模型作为决策环节的核心）。

**骨架**｜
```python
import numpy as np
from scipy import stats

cu, co = price - cost, cost - salvage
cr = cu / (cu + co)                                     # 临界分位数
dist = stats.lognorm(*stats.lognorm.fit(demand_resid, floc=0))
Q = dist.ppf(cr)

def profit(Q, n=200_000, rng=np.random.default_rng(0)):
    D = dist.rvs(n, random_state=rng)
    return (price*np.minimum(D, Q) + salvage*np.maximum(Q-D, 0) - cost*Q).mean()

Qs = np.linspace(0.5*Q, 1.5*Q, 101)                     # 利润曲线：必画
print(f'Q*={Q:.1f}, 期望利润={profit(Q):.1f}, 缺货概率={1-dist.cdf(Q):.3f}')
```

**别用它的时候**｜需求可以在期内观测后再补货 → 多期/滚动模型。
决策变量不止一个（多品类共享货架/预算）→ §5.2 随机规划。

## §5.2 随机规划与情景法

**是什么**｜参数随机时的优化。两阶段随机规划：第一阶段先决策（此时不知道随机结果），
第二阶段观测到随机量后再补救。

**什么时候用**｜决策必须**提前做**（种什么、建在哪、订多少），而收益依赖之后才知道的随机量。
2024C 是典型。

**核心**｜
$$
\min_{\mathbf x}\ \mathbf c^{\mathsf T}\mathbf x+\mathbb E_{\xi}\big[Q(\mathbf x,\xi)\big],\qquad
Q(\mathbf x,\xi)=\min_{\mathbf y}\{\mathbf q^{\mathsf T}\mathbf y:\ W\mathbf y\ge \mathbf h(\xi)-T(\xi)\mathbf x\}
$$
$\mathbf x$ 是**此时此地**决策，$\mathbf y$ 是**等待观察**后的补救决策。

**情景法（实际做法）**：把 $\xi$ 离散成 $S$ 个情景（概率 $p_s$），
问题就变成一个大的确定性规划：
```
min  cᵀx + Σ_s p_s qᵀy_s
s.t. 每个情景的约束 + 非预期性约束（x 对所有情景相同）
```
这一步做完就能扔给 §3.1 的 LP/MILP 求解器。

**参数与坑**｜
- **情景怎么生成、多少个，必须说清**。做法：历史数据 + 蒙特卡洛抽样 + **情景缩减**
  （聚类到 20–50 个代表情景，保留概率权重）。情景太多问题解不动，太少结果不稳。
- **必须做情景稳定性检验**：换一组情景重解，最优解变不变。变化大说明情景数不够。
- **要报 VSS 和 EVPI 两个量**，它们直接说明"用随机规划比确定性模型好在哪"：
  - **VSS**（随机解的价值）= 用期望值模型的解的实际期望成本 − 随机规划最优值。
    VSS 大就证明了不该用期望值代替随机量。
  - **EVPI**（完全信息价值）= 随机规划最优值 − 各情景分别最优的期望。
  **报了这两个数，"为什么必须用随机规划"就自证了**，正好回应第零节的"套路化"质疑。
- 非预期性约束忘了写，是这类模型最常见的建模错误（相当于允许"先看结果再决策"）。

**国赛出处**｜2024C（随机规划，官方"不确定性模型"环节；一等奖论文关键词）、2021C（双层随机规划）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import milp, LinearConstraint

S, ps = 50, np.full(50, 1/50)                    # 50 个等概率情景
xi = rng.lognormal(mu, sigma, size=(S, n))       # 情景生成
# 决策变量 z = [x (n 个，所有情景共享), y_1..y_S (每情景 m 个)]
c = np.concatenate([c_x, np.concatenate([ps[s]*c_y for s in range(S)])])
# 约束按情景逐块拼；x 只出现一次 → 天然满足非预期性
res = milp(c=c, constraints=blocks, integrality=integ, bounds=bnds)

ev_sol = solve_deterministic(xi.mean(0))         # 期望值模型的解
vss = expected_cost(ev_sol, xi) - res.fun        # VSS：必报
```

**别用它的时候**｜只关心最坏情况 → 鲁棒优化（min-max）。
关心尾部风险 → §5.3 CVaR。单变量单周期 → §5.1 报童就够。

## §5.3 CVaR 与风险度量

**是什么**｜VaR 是损失分布的 $\alpha$ 分位数；**CVaR（条件风险价值）是超过 VaR 那部分损失的均值**，
即"最坏 $(1-\alpha)$ 情形下的平均损失"。

**什么时候用**｜题面出现"**风险**""最坏情况""稳健"，且决策者厌恶尾部损失。
**这是"稳健性"从形容词变成可优化目标的标准做法。**

**核心（Rockafellar–Uryasev，CVaR 可以线性化，这是它比 VaR 好用的根本原因）**｜
$$
\mathrm{CVaR}_\alpha(\mathbf x)=\min_{t}\ \Big\{t+\frac1{1-\alpha}\mathbb E\big[(L(\mathbf x,\xi)-t)^+\big]\Big\}
$$
用情景离散化后，引入辅助变量 $u_s\ge L_s-t,\ u_s\ge0$，目标变成
$$
\min\ t+\frac1{(1-\alpha)S}\sum_s u_s
$$
**全是线性约束**，可以直接扔给 LP/MILP。

**参数与坑**｜
- **VaR 不是凸的、不可加**，直接优化 VaR 是非凸问题；**CVaR 凸且可线性化**。
  论文里点出这一条，就说明了"为什么选 CVaR 而不是 VaR"——一个现成的方法论证。
- $\alpha$ 取 0.90/0.95/0.99，**要做多个 $\alpha$ 的对比**，看解怎么随风险偏好变化。
- **要画"期望收益 vs CVaR"的有效前沿**（这是 §3.12 多目标的特例），
  然后给一个推荐点并说明理由。
- 情景数不够时 CVaR 估计极不稳（它只用了尾部的 $(1-\alpha)S$ 个情景）。
  $\alpha=0.95$、$S=100$ 时尾部只有 5 个点——**至少要 $S\ge 1000$**。这一条经常被忽略。

**国赛出处**｜2024C（CVaR，一等奖论文关键词）。

**骨架**｜
```python
import numpy as np
from scipy.optimize import linprog

S, alpha = 2000, 0.95
# 变量：[x(n), t(1), u(S)]
c = np.concatenate([np.zeros(n), [1.0], np.full(S, 1/((1-alpha)*S))])
# u_s ≥ L_s(x) − t  →  −L_s(x) + t + u_s ≥ 0（L 线性于 x 时可直接写）
A_ub = np.hstack([Loss_coef, -np.ones((S,1)), -np.eye(S)])
res = linprog(c, A_ub=A_ub, b_ub=np.zeros(S), bounds=bnds)
print('CVaR =', res.fun, ' VaR(t) =', res.x[n])
```

**别用它的时候**｜损失分布近似对称且无重尾 → 方差/标准差当风险度量更简单。
只关心绝对最坏 → 鲁棒优化。

## §5.4 不动点迭代与闭环期望

**是什么**｜系统有回流（返工、退货、拆解重装）时，期望值方程自己引用自己，要迭代到收敛。

**什么时候用**｜**看到"拆解后重新装配""退货返修""回收再利用"就是它。**
一趟流水线算不出期望利润——这是 2024B 的核心结构。

**核心**｜两种等价写法：

**写法一（等比级数，能闭式就闭式）**：若每轮以概率 $q$ 回流，每轮成本 $c$，则
$$
\mathbb E[\text{总成本}]=c+q\,\mathbb E[\text{总成本}]\quad\Longrightarrow\quad \mathbb E=\frac{c}{1-q}
$$
**能推出闭式解就一定要给闭式解**（同 §0 问题二），迭代只用来验证。

**写法二（不动点迭代，结构复杂时）**：
```
V₀ = 初值（如只走一趟的期望）
V_{k+1} = f(V_k)          # 把 V 代进期望方程右端
直到 |V_{k+1} − V_k| < 1e-12
```
收敛条件是 $f$ 为压缩映射（$|f'|<1$），实际就是"回流概率 < 1"。

**参数与坑**｜
- **官方用这个结构做过一次关键剪枝**（2024B）：
  > "如果在装配成品时，零配件没有做过检测，则**拆解时一定要对零配件做检测**，
  > 否则不合格的零配件永远在成品中，将会有**无限次的拆解或赔偿**。"
  
  这正是"$q=1$ 时 $\frac{c}{1-q}$ 发散"的实际含义。**用发散性做反证剪枝，是这条的最高用法。**
- **收敛判据用相对变化**，最大迭代次数要设（1000 足够），不收敛要报错而不是静默返回。
- 迭代前**先估 $q$ 的量级**。$q>0.9$ 时收敛很慢（需要几百次迭代），此时优先找闭式。
- 多种回流路径耦合时是一个线性方程组 $\mathbf V=A\mathbf V+\mathbf b$，
  **直接解 $(\mathbf I-A)^{-1}\mathbf b$ 比迭代好**（精确且快）。检查 $\rho(A)<1$。

**国赛出处**｜**2024B 官方主线**（多阶段拆解决策的期望利润必须闭环求解）。

**骨架**｜
```python
import numpy as np

def fixed_point(f, v0, tol=1e-12, maxit=1000):
    v = v0
    for k in range(maxit):
        v_new = f(v)
        if abs(v_new - v) < tol * max(1.0, abs(v)):
            return v_new, k
        v = v_new
    raise RuntimeError('不动点迭代未收敛，检查回流概率是否 ≥ 1')

V, iters = fixed_point(lambda V: c + q * V, v0=c)
assert np.isclose(V, c/(1-q)), '与闭式解不一致'      # 闭式解交叉验证

A = np.array([[...]]); b = np.array([...])          # 多路径耦合：解线性方程组
assert max(abs(np.linalg.eigvals(A))) < 1, '谱半径 ≥ 1，期望发散'
V = np.linalg.solve(np.eye(len(A)) - A, b)
```

**别用它的时候**｜没有回流 → 直接一趟算完。
回流次数有上限（最多返修 2 次）→ 有限项求和，别用无穷级数。

# 第六族 · 时间序列与信号处理

**这一族的共同点**：数据有**序**，相邻点不独立，这个序结构既是信息也是陷阱。
**共同的坑**：把时序数据当独立样本做交叉验证（随机划分会用未来预测过去，指标虚高）。
**时序的交叉验证必须是滚动/前向的**（`TimeSeriesSplit`）。

## §6.1 ARIMA / ARMA

**是什么**｜用序列自身的历史值和历史误差线性预测未来。
ARIMA(p,d,q)：差分 $d$ 次后，$p$ 阶自回归 + $q$ 阶移动平均。

**什么时候用**｜单变量、等间隔、无强外生因素、序列本身有自相关结构。
**是时序预测的基线模型**——上任何复杂模型前先跑它。

**核心**｜
$$
(1-\textstyle\sum_{i=1}^p\phi_iB^i)(1-B)^d y_t=(1+\textstyle\sum_{j=1}^q\theta_jB^j)\varepsilon_t
$$
定阶流程：
```
ADF 检验看平稳性 → 不平稳就差分（定 d）→ 看 ACF/PACF 初判 p,q
  → 网格搜 AIC/BIC 定阶 → 拟合 → 残差白噪声检验（Ljung-Box）
```

**参数与坑**｜
- **残差必须过 Ljung-Box 白噪声检验**。不过说明还有结构没提取，模型不能用。
  只报预测误差不报残差检验，是不完整的。
- **别过度差分**。$d$ 通常 0 或 1，$d=2$ 要有很强理由。过度差分会引入虚假的 MA 结构。
- **有明显季节性必须用 SARIMA**（加 $(P,D,Q)_s$），普通 ARIMA 拟合不了。
- **预测区间要报**，`get_forecast().conf_int()`。只报点预测在国赛是失分的。
- 长期预测会收敛到均值——ARIMA **不适合长期预测**，超过几个周期就没信息量了。要说明预测有效期。

**国赛出处**｜2023C（ARMA/时间序列，一等奖论文关键词）。

**骨架**｜
```python
import statsmodels.api as sm
from statsmodels.tsa.stattools import adfuller
from statsmodels.stats.diagnostic import acorr_ljungbox

print(adfuller(y))                                          # 平稳性
m = sm.tsa.SARIMAX(y, order=(1,1,1), seasonal_order=(1,0,1,12)).fit(disp=0)
print(acorr_ljungbox(m.resid, lags=[10]))                   # 白噪声检验：必做
fc = m.get_forecast(steps=12)
pred, ci = fc.predicted_mean, fc.conf_int()                 # 区间：必报
```
模板：`1_skill/code-templates/python/ml/time_series_forecast_template.py`

**别用它的时候**｜有节假日/促销等外生事件 → §6.2 Prophet 或 ARIMAX。
多个序列相互影响 → VAR。序列很短（< 50 点）→ 简单趋势 + 季节分解就够。

## §6.2 Prophet

**是什么**｜可加分解模型：$y(t)=g(t)+s(t)+h(t)+\varepsilon$，
分别是趋势、周期性、节假日效应。趋势用分段线性 + 自动变点检测。

**什么时候用**｜**有明显的多重周期性 + 节假日效应 + 数据有缺失或异常**的业务序列。
零售、客流、销量类数据的首选。2023C 官方主线用的就是它。

**核心**｜
- 趋势 $g(t)$：分段线性（或 logistic 饱和增长），变点由稀疏先验自动选；
- 周期 $s(t)$：傅里叶级数，年周期用 10 阶、周周期用 3 阶（默认）；
- 节假日 $h(t)$：给定日期列表，每个假日一个（或若干天窗口的）效应参数。

**参数与坑**｜
- **`changepoint_prior_scale` 是最重要的参数**（默认 0.05）：
  大了趋势乱抖（过拟合），小了跟不上转折。**要做交叉验证调它**，并在论文里报调参过程。
- **中国节假日必须自己加**（`add_country_holidays('CN')` 覆盖不全，
  春节按农历移动、调休补班都要手工列）。2023C 那类零售数据不加春节，误差会很大。
- **饱和增长要给 `cap`/`floor`**，否则线性趋势会外推出负销量。
- **Prophet 不是万能**。它是"曲线拟合 + 分解"，不建模自相关。
  残差如果还有自相关，说明该配 ARIMA 或加外生变量。**要检查残差**。
- 环境：`prophet` 包在部分环境装不上（依赖 `cmdstanpy`）。**赛前必须验证能装**，
  装不上就退回 §6.1 SARIMAX + 节假日哑变量，效果接近。

**国赛出处**｜**2023C 官方主线**（预处理 → Prophet → 分布拟合 → 报童）。

**骨架**｜
```python
from prophet import Prophet
from prophet.diagnostics import cross_validation, performance_metrics
import pandas as pd

hol = pd.DataFrame({'holiday': 'spring', 'ds': pd.to_datetime(cn_spring_festival_dates),
                    'lower_window': -7, 'upper_window': 7})     # 春节手工列
m = Prophet(holidays=hol, changepoint_prior_scale=0.05,
            yearly_seasonality=10, weekly_seasonality=True).fit(df)
cv = cross_validation(m, initial='730 days', period='90 days', horizon='90 days')
print(performance_metrics(cv).head())                            # 滚动 CV，不是随机划分
```

**别用它的时候**｜序列短、无明显周期 → §6.1 或简单回归。
需要可解释的机理 → Prophet 是纯统计分解，给不出因果。

## §6.3 傅里叶变换（FFT）

**是什么**｜把信号从时域/空间域变到频域，看它由哪些频率成分组成。

**什么时候用**｜① 找周期（干涉条纹间距、振动主频）；② 滤波（频域截断）；
③ **反演题里由条纹频率直接反解厚度**。

**核心**｜$X_k=\sum_{n=0}^{N-1}x_ne^{-2\pi ikn/N}$。
频率分辨率 $\Delta f=\frac{1}{N\Delta t}$，最高可辨频率（Nyquist）$f_{\max}=\frac{1}{2\Delta t}$。

**干涉类的用法**：反射谱对**波数** $\nu$ 呈周期振荡，周期对应光程差。
对 $R(\nu)$ 做 FFT，峰位就是光程差 $2nd$，直接给出厚度的初值。

**参数与坑**｜
- **必须先重采样到等间隔**。光谱数据常按波长等间隔给，而周期性在**波数**域才是均匀的，
  要先 $\nu=1/\lambda$ 再用 §1.6 样条重采样到等 $\nu$ 网格。**不做这一步，FFT 峰会糊掉。**
- **必须去均值和加窗**（Hann/Hamming），否则直流分量和端点跳变造成的频谱泄漏会淹没真峰。
- **频率分辨率有限**，峰位要**抛物线插值细化**（用峰及左右两点拟合抛物线取顶点），
  能把精度提高约一个量级。
- **FFT 给的是初值，精细值要靠 §3.5 拟合**。只用 FFT 峰位报最终结果精度不够。
- 混叠：采样不够密时高频会折叠成假峰。先检查 $f_{\max}$ 是否覆盖预期频率。

**国赛出处**｜2025B（傅里叶变换，一等奖论文关键词；用于定厚度初值）。

**骨架**｜
```python
import numpy as np
from scipy.interpolate import CubicSpline

nu = 1e4 / lam_um                                  # 波长 → 波数 cm^-1
nu_u = np.linspace(nu.min(), nu.max(), 4096)       # 等间隔重采样：必做
R_u = CubicSpline(nu[::-1], R[::-1])(nu_u)
sig = (R_u - R_u.mean()) * np.hanning(len(R_u))    # 去均值 + 加窗：必做
F = np.abs(np.fft.rfft(sig, n=1<<16))
d_axis = np.fft.rfftfreq(1<<16, d=nu_u[1]-nu_u[0])
k = int(np.argmax(F[1:])) + 1
a, b, c = F[k-1], F[k], F[k+1]                     # 抛物线细化峰位
k_ref = k + 0.5*(a-c)/(a-2*b+c)
opl = k_ref * (d_axis[1]-d_axis[0])                # 光程差 = 2nd
```

**别用它的时候**｜信号非平稳（频率随时间变）→ 短时傅里叶或小波。
只要找几个峰的位置 → §6.4 `find_peaks` 更直接。

## §6.4 滤波与波峰检测

**是什么**｜去掉噪声保留信号（滤波），再定位极值点（峰检测）。

**什么时候用**｜**反演题的标准前处理**。2025B 讲评的实用算法环节就是
`滤波 → 找波峰/波谷 → 计算`。

**核心**｜

| 滤波器 | 特点 | 适用 |
|---|---|---|
| **Savitzky–Golay** | 局部多项式拟合，**保峰形和峰高** | 光谱、色谱。**首选** |
| 移动平均 | 最简单，但会压低峰、展宽峰 | 只做趋势提取 |
| Butterworth 低通（`filtfilt`） | 频域截断干净 | 噪声频带与信号明确分开时 |
| 中值滤波 | 去脉冲/尖刺噪声 | 有孤立野点时 |

峰检测 `scipy.signal.find_peaks` 的四个参数决定一切：
`height`（绝对高度）、`prominence`（**突出度，最有用**）、`distance`（最小间距）、`width`。

**参数与坑（2025B 官方专门辨析过一条）**｜
- **波峰还是波谷，要辨析清楚**。2025B 讲评专门用一节讨论这个，
  因为干涉极值的级次归属取决于反射时有没有半波损失（相位跳变 $\pi$）。
  **选错会让厚度系统性偏差半个条纹周期。** 论文里要写明依据。
- **优先用 `prominence` 而不是 `height`**。基线有起伏时 `height` 会漏掉低处的真峰、
  收进高处的噪声毛刺；突出度是相对局部基线的，稳健得多。
- **`filtfilt` 而不是 `lfilter`**：前者正反各滤一次，**零相位**；
  后者会引入相位延迟，导致峰位系统性偏移。**这是静默错误，峰形看起来完全正常。**
- **S-G 的窗长必须是奇数**，且要显著大于噪声相关长度、显著小于峰宽（经验：峰宽的 1/3～1/2）。
  窗长过大直接把峰削平。多项式阶数取 2 或 3。
- **滤波强度要做敏感性分析**：换 2–3 组参数，看反演结果变多少。这一项写进论文就是稳健性证据。
- 峰位要**亚采样点细化**（抛物线插值，同 §6.3），否则精度被采样间隔锁死。

**国赛出处**｜**2025B 官方主线**（滤波 → 波峰/波谷 → 计算，含"波峰还是波谷"的专门辨析）。

**骨架**｜
```python
import numpy as np
from scipy.signal import savgol_filter, find_peaks, butter, filtfilt, peak_prominences

sm = savgol_filter(y, window_length=21, polyorder=3)         # 奇数窗长，保峰形
b, a = butter(4, 0.15); sm2 = filtfilt(b, a, y)              # filtfilt 零相位

pk, props = find_peaks(sm, prominence=0.02, distance=15)     # 用 prominence
def refine(x, y, i):                                          # 抛物线细化峰位
    a_, b_, c_ = y[i-1], y[i], y[i+1]
    return x[i] + 0.5*(a_-c_)/(a_-2*b_+c_) * (x[1]-x[0])
peaks_x = [refine(x, sm, i) for i in pk if 0 < i < len(sm)-1]

for w in (11, 21, 31):                                        # 滤波强度敏感性
    print(w, len(find_peaks(savgol_filter(y, w, 3), prominence=0.02)[0]))
```

**别用它的时候**｜信号本身就干净 → 别滤，滤波总会损失信息。
要的是全局周期而非单个峰 → §6.3 FFT。

# 第七族 · 机器学习（含"什么时候不该用"）

**这一族的共同点**：从数据学映射，不依赖机理。
**这一族在国赛里的地位**：**辅助与对照，不是主线**。命题人连续三年批评：

> "简单套用机器学习方法进行预测，是**完全错误的**"（2022C）　
> "仅做简单的预测、拟合和回归是**不够的**"（2023C）　
> "忽略了**异常判定与普通分类的区别**"（2025C）

**上机器学习前必须过的三道闸**：

1. **有配对的训练标签吗？**
   > 2022C 讲评："**数据中只有风化后的数据，缺少风化前的数据与之配对，
   > 没有配对的学习样本来建立普通的预测模型。只能通过分布匹配**，在比较强的假设下给出预测"
   
   没有配对样本，就不是监督学习问题。改走分布/均值匹配或机理模型。
2. **问题本质是分类/回归，还是判定/分组/决策？** 是后者就走 §4.10 / §4.3 / 第五族。
3. **能不能解释？** 国赛要的是"落地方案"，纯黑箱输出不构成方案。
   至少要给特征重要性 + 部分依赖图 + 一个可写成规则的简化版。

三道闸都过了，ML 是可以用的，而且**用作对照基线几乎总是加分**（说明你比较过）。

## §7.1 K-means 与层次聚类

**是什么**｜无监督地把样本分成若干组。K-means 最小化组内平方和；层次聚类逐步合并/分裂。

**什么时候用**｜**探索性地看数据有没有自然的簇结构**，或做客户/产品分群。
用在"给我们看看数据长什么样"的环节，不是用在"给出分组方案"的环节。

**核心**｜K-means：随机初始化 $k$ 个中心 → 分配 → 更新中心 → 迭代到不变。
层次聚类：算距离矩阵 → 按连接准则（ward / average / complete）逐步合并 → 树状图剪枝。

**最重要的一条：什么时候绝对不能用**｜
> 2025C 评阅："**超半数队伍**选择 K-means、层次聚类等经典方法直接对 BMI 数据本身进行聚类，
> 未考虑协变量孕周的变化对 BMI 有序分组的影响…整体答题情况较为一般"

**有序连续变量（BMI、年龄、孕周、收入）的分组，不能用聚类。** 两个理由：
1. **聚类不保证区间连续**——可能把 [20,22] 和 [26,28] 分到一组，业务上不可解释；
2. **聚类优化的是"组内平方和"，不是你真正关心的目标**。

**正解是在分点集合上优化**：
```
决策变量：分点 c_1 < c_2 < … < c_{G-1}
目标：组内差异小、组间差异大（如组间平方和 Q(A)）
定组数：加惩罚项，2025C 官方用 argmax Q(A) − λ(G−1)，得 G = 4
求解：G 小时动态规划（§3.2）可得精确最优；G 大时用启发式
```
这样得到的分组天然是**连续区间**，且直接优化了你写下的目标。

**参数与坑**｜
- **必须标准化**（K-means 用欧氏距离，量纲大的变量主导）。
- $k$ 的选择要有依据：肘部法 + 轮廓系数 + **业务可解释性**，三者一起说。
- K-means **只能找球形等方差的簇**，且对初始化敏感（用 `k-means++`、`n_init=10`）。
- **成分数据要先 CLR 变换**（§9.1）再聚类。
- 层次聚类的连接准则会显著改变结果，要说明为什么选 ward（最常用，最小化组内方差增量）。

**国赛出处**｜2022C（亚类划分，官方主线的一环）、2023C（K-means++）；
**2025C 是反例**（超半数队伍用错）。

**骨架**｜

## §7.2 主成分分析（PCA）

**是什么**｜找数据方差最大的正交方向，把 $p$ 维压成 $k$ 维。

**什么时候用**｜① **降维可视化**（看数据结构）；② 去除多重共线性（主成分回归）；
③ 通过**载荷**理解变量之间的结构。

**核心**｜对协方差（或相关）矩阵做特征分解，特征向量 = 主成分方向，特征值 = 该方向方差。
第 $j$ 个主成分 $\mathrm{PC}_j=\sum_i w_{ij}x_i$，$w$ 是**载荷**。

**最重要的一条：PCA 不是变量选择**｜
> 2022C 官方："有同学先做主成分分析，然后用几个主成分作为变量进行聚类，
> **这个不是真正的变量选择**"

理由：**主成分是全部原变量的线性组合，一个原变量都没剔除**。
要做变量选择请看 §7.6。**但载荷可以辅助变量选择**：
取在主要主成分上载荷绝对值大的**原变量**（不是主成分本身），这才是选变量。

**参数与坑**｜
- **必须标准化**（否则量纲大的变量霸占第一主成分）。用相关矩阵 = 标准化后的协方差矩阵。
- **主成分不可解释就别硬解释**。"PC1 代表综合发展水平"这种话要有载荷证据支撑
  （所有载荷同号且量级相近才说得通）。
- 保留多少个：累计方差贡献 ≥ 85%，或碎石图拐点，或 Kaiser 准则（特征值 > 1）。**三选一并说明**。
- **成分数据要先 CLR**（§9.1）再 PCA。
- PCA 是**线性**降维。数据在流形上时用 t-SNE/UMAP 可视化（但那两个不能用于建模，只能看）。

**国赛出处**｜2022C（官方明确指出"这个不是真正的变量选择"）；
连续四年被列在"套路化"清单的数据类里——**用它必须说明为什么这道题需要降维**。

**骨架**｜
```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
import numpy as np, pandas as pd

Z = StandardScaler().fit_transform(X)
p = PCA().fit(Z)
print(np.cumsum(p.explained_variance_ratio_))                 # 累计贡献
load = pd.DataFrame(p.components_[:3].T, index=cols, columns=['PC1','PC2','PC3'])
print(load.abs().max(1).sort_values(ascending=False))         # 用载荷挑原变量
```

**别用它的时候**｜**要选变量 → §7.6，不是 PCA**。
要保持可解释性 → 直接用原变量 + 正则化（Lasso）。

## §7.3 决策树 / 随机森林 / XGBoost

**是什么**｜树模型按特征阈值递归切分空间。随机森林是并行的 bagging，XGBoost 是串行的 boosting。

**什么时候用**｜表格数据、特征间有交互和非线性、样本量够（>几百）、
**且问题确实是预测/分类**。适合当**对照基线**和**特征重要性探索**。

**核心**｜
- 单树：每次选使不纯度（Gini/熵/MSE）下降最大的切分点。可解释但方差大。
- 随机森林：多棵树 + 样本自助 + 特征随机子集，投票/平均。稳，几乎不用调参。
- XGBoost：每棵新树拟合当前残差的负梯度，加正则和收缩。精度高，参数多。

**参数与坑**｜
- **必须交叉验证，且时序数据要用 `TimeSeriesSplit`**。随机划分时序数据 = 用未来预测过去，
  指标虚高且完全无效。
- **特征重要性有偏**：树的 `feature_importances_` 偏好高基数特征。
  要用 **permutation importance** 或 **SHAP**，并且要说明用的是哪种。
- **不能外推**。树模型在训练范围外只会输出边界值。要预测超出历史范围的情形 → 别用树。
- 类别不平衡时用 `scale_pos_weight` / `class_weight`，且看 AUC-PR 而非准确率。
- **XGBoost 要调的参**：`n_estimators` + `learning_rate`（成反比）、`max_depth`(3–8)、
  `subsample`/`colsample_bytree`(0.7–0.9)、`reg_lambda`。**论文里要写调参方式和搜索范围。**

**国赛出处**｜2022C（决策树，一等奖论文关键词）；
**2025C 是反例**——把异常判定当二分类做，"绝大多数队伍完成效果并不理想"。

**骨架**｜
```python
import xgboost as xgb
from sklearn.model_selection import TimeSeriesSplit, cross_val_score
from sklearn.inspection import permutation_importance

cv = TimeSeriesSplit(n_splits=5)                              # 时序必用
m = xgb.XGBClassifier(n_estimators=400, learning_rate=0.05, max_depth=4,
                      subsample=0.8, colsample_bytree=0.8, reg_lambda=1.0,
                      random_state=42)
print(cross_val_score(m, X, y, cv=cv, scoring='roc_auc'))
m.fit(X, y)
imp = permutation_importance(m, X, y, n_repeats=20, random_state=42)  # 不用内置的
```
模板：`1_skill/code-templates/python/ml/xgboost_template.py`、`random_forest_template.py`

**别用它的时候**｜罕见事件判定 → §4.10。要外推 → 机理模型或参数化回归。
样本 < 100 → 过拟合，用简单模型。**没有配对标签 → 根本不是监督学习**（2022C）。

## §7.4 神经网络（BP / LSTM）

**是什么**｜多层非线性映射，用反向传播训练。LSTM 是带门控的循环网络，处理序列。

**什么时候用**｜国赛里**几乎总有更好的选择**。真要用，条件是：
样本量大（>几千）、关系强非线性且无机理可依、且你能给出可解释性补充。

**核心**｜前馈：$\mathbf h^{(l)}=\sigma(W^{(l)}\mathbf h^{(l-1)}+\mathbf b^{(l)})$，
损失对参数求梯度用链式法则，Adam 优化。
LSTM 用遗忘门/输入门/输出门控制细胞状态，缓解长程梯度消失。

**参数与坑**｜
- **它在"套路化"清单上被点名**（"神经网络；深度学习"）。用了必须回答
  **"为什么这道题非它不可"**，且要与简单模型对比，证明它确实更好。
  **对比不过就老实用简单模型**——这本身是加分的判断力。
- **必须固定所有随机种子**（numpy / torch / cuda）并报多次运行的方差。
  神经网络的运行间波动经常大于它相对基线的提升。
- **数据必须标准化**，输出也要（回归任务）。
- **小样本上必然过拟合**。要早停 + Dropout + 权重衰减，且报训练/验证曲线。
- **LSTM 在国赛级别的数据量上通常打不过 SARIMAX/Prophet**，还慢、还不可解释。
  2023C 一等奖论文有用 LSTM 的，但官方主线是 Prophet。
- 环境：`torch` 装不上是常见事故。**赛前验证**，或用 `sklearn.neural_network.MLPRegressor` 兜底。

**国赛出处**｜2021B（BP 神经网络）、2023C（LSTM）——都是一等奖论文的**辅助环节**，不是主线。

**骨架**｜
```python
from sklearn.neural_network import MLPRegressor            # 无 torch 时的兜底
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
import numpy as np

pipe = make_pipeline(StandardScaler(),
                     MLPRegressor(hidden_layer_sizes=(32,16), early_stopping=True,
                                  max_iter=2000, random_state=42))
scores = [make_pipeline(StandardScaler(),
          MLPRegressor((32,16), early_stopping=True, max_iter=2000, random_state=s)
          ).fit(Xtr,ytr).score(Xte,yte) for s in range(10)]
print(f'{np.mean(scores):.4f} ± {np.std(scores):.4f}')     # 报方差，别只报最好一次
```

**别用它的时候**｜大多数情况。先试 §4.3 回归、§7.3 树模型，
打不过它们就别用；打过了也要报对比。

## §7.5 高斯过程回归（GPR）

**是什么**｜把函数本身当随机过程，用核函数描述"两点的函数值有多相关"。
给出预测均值**和逐点的不确定性**。

**什么时候用**｜① 样本少（几十到几百）；② 函数光滑；
③ **需要预测的不确定度**（这是它相对其他 ML 的核心优势）；④ 贝叶斯优化的代理模型。

**核心**｜先验 $f\sim\mathcal{GP}(m,k)$，观测后后验仍是高斯：
$$
\mu_\*=k_\*^{\mathsf T}(K+\sigma_n^2I)^{-1}\mathbf y,\qquad
\sigma_\*^2=k_{\*\*}-k_\*^{\mathsf T}(K+\sigma_n^2I)^{-1}k_\*
$$
核函数选择就是先验假设：RBF（无限光滑）、Matérn 3/2 或 5/2（**更现实，首选**）、
周期核（有周期性）、核可以相加相乘组合。

**参数与坑**｜
- **复杂度 $O(n^3)$**。$n>5000$ 就跑不动了，要用稀疏 GP 或换模型。
- **必须加噪声项** `alpha` 或 `WhiteKernel`，否则 $K$ 奇异，数值上会崩。
- **RBF 核假设无限次可微，对真实数据常常过强**。默认选 Matérn(nu=2.5)。
- **`normalize_y=True`**，否则零均值先验会把预测往 0 拉。
- **长度尺度要给合理的初值和边界**，否则优化器会收敛到"全是噪声"或"完全插值"两个退化解。
- **它最大的卖点是置信带，一定要画出来**。只报均值等于浪费了这个模型。

**国赛出处**｜2025C（高斯过程回归，一等奖论文关键词）。

**骨架**｜
```python
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern, WhiteKernel, ConstantKernel as C

k = C(1.0, (1e-3, 1e3)) * Matern(length_scale=1.0, length_scale_bounds=(1e-2, 1e2),
                                 nu=2.5) + WhiteKernel(1e-3, (1e-8, 1e1))
gp = GaussianProcessRegressor(kernel=k, normalize_y=True, n_restarts_optimizer=10
                              ).fit(X, y)
mu, sd = gp.predict(Xq, return_std=True)
plt.fill_between(xq, mu-1.96*sd, mu+1.96*sd, alpha=.3)      # 置信带：必画
print(gp.kernel_)                                            # 报学到的超参
```

**别用它的时候**｜样本 > 5000 → 太慢。高维（> 20 维）→ 核方法失效。
不需要不确定度 → 用更简单的模型。

## §7.6 变量选择（VIP / PLS-DA / R 型聚类 / Lasso）

**是什么**｜从 $p$ 个变量里挑出真正有用的**若干原变量**（而不是造新变量）。

**什么时候用**｜变量多、样本少、要可解释的子集。
**2022C 官方把它单列为一个难点**："典型的**无监督变量选择问题**"。

**四条可行路线**｜

| 方法 | 有无标签 | 思路 | 适用 |
|---|---|---|---|
| **R 型聚类选代表** | 无 | 对**变量**聚类，每簇选一个代表（与簇内其他变量相关性最高的） | 无监督，2022C 官方认可 |
| **PLS-DA 的 VIP** | 有 | 偏最小二乘判别，VIP > 1 的变量保留 | 有分类标签、变量高度共线 |
| **主成分载荷** | 无 | 取在主要 PC 上载荷大的**原变量** | 简便；注意这与"用主成分当变量"完全不同 |
| **Lasso / 弹性网** | 有 | L1 惩罚把不重要的系数压到 0 | 有连续/二分类标签 |

**核心：PCA 不是变量选择**（再强调一次）｜
> 2022C 官方："有同学先做主成分分析，然后用几个主成分作为变量进行聚类，
> **这个不是真正的变量选择**"

区别在一句话：**变量选择的输出是原变量的一个子集**；PCA 的输出是全部原变量的线性组合。

**参数与坑**｜
- **必须交叉验证选 Lasso 的 $\lambda$**（`LassoCV`），且**先标准化**（L1 惩罚对量纲敏感）。
- Lasso 在强相关变量组里**只会留一个**（随机的那个）。要保留整组用**弹性网**（`ElasticNetCV`）。
- **变量选择必须放进交叉验证内部**。先用全部数据选变量、再交叉验证，
  会导致选择偏倚，指标虚高——这是很隐蔽且很常见的错误。
- **成分数据先 CLR**（§9.1）再做任何变量选择。
- 选完要**报稳定性**：自助重采样 100 次，看每个变量被选中的频率。频率 > 0.8 才算稳。

**国赛出处**｜**2022C 官方难点**（无监督变量选择 + "PCA 不是变量选择"）。

**骨架**｜
```python
import numpy as np
from sklearn.linear_model import LassoCV, ElasticNetCV
from sklearn.preprocessing import StandardScaler
from scipy.cluster.hierarchy import linkage, fcluster
from scipy.spatial.distance import squareform

Z = StandardScaler().fit_transform(X)
las = LassoCV(cv=5, random_state=42).fit(Z, y)
sel = np.flatnonzero(las.coef_ != 0)

D = 1 - np.abs(np.corrcoef(Z.T))                              # R 型聚类（无监督）
lab = fcluster(linkage(squareform(D, checks=False), 'average'), t=6, criterion='maxclust')
reps = [np.flatnonzero(lab == g)[np.argmax(np.abs(np.corrcoef(Z[:, lab == g].T)).sum(0))]
        for g in np.unique(lab)]                              # 每簇取代表变量

freq = np.mean([np.isin(np.arange(X.shape[1]),                 # 稳定性：必报
    np.flatnonzero(LassoCV(cv=5).fit(*boot(Z, y, s)).coef_ != 0)) for s in range(100)], 0)
```

**别用它的时候**｜变量本来就少（< 10）→ 全留，讨论每一个。
目的只是可视化 → PCA 就够，不必选变量。

# 第八族 · 评价类模型

**这一族的处境要说清楚**：AHP、模糊综合评估、熵权法连续四年出现在组委会的"套路化"清单上。
**但 2021C 的四篇一等奖论文把它们用了个遍**：

| 论文 | 重要性模型 |
|---|---|
| C066 | 6 指标 + **TOPSIS** |
| C085 | 4 指标 + **熵权法-TOPSIS** |
| C169 | 8 指标 + **投影寻踪 + 加速遗传算法** |
| C283 | 9 指标 + **熵权法 + AHP 修正** |

**结论**：在评价类子问题上这些是被接受的常规做法。
被批的是"**不从问题出发，乱套方法**"，不是方法本身。

**用评价模型时必须做的四件事**（缺一就落进"套路"）：
1. **指标从问题里推出来**，每个指标说明为什么选它、数据从哪来；
2. **权重方法要有依据**，且最好**主客观结合**（AHP 定主观 + 熵权定客观，再融合）；
3. **必须做权重敏感性分析**：权重扰动 ±20%，排名前三变不变；
4. **结果要能解释**：说明为什么第一名是第一名，哪个指标起了决定作用。

## §8.1 层次分析法（AHP）

**是什么**｜通过两两比较构造判断矩阵，导出主观权重，并检验一致性。

**什么时候用**｜指标的相对重要性只能靠专家/常识判断，没有数据可依。

**核心**｜
```
建层次结构（目标-准则-方案）→ 两两比较填 1–9 标度矩阵 A
  → 权重 w = A 的最大特征值对应特征向量（归一化）
  → 一致性检验 CI = (λmax − n)/(n − 1)，CR = CI/RI，要求 CR < 0.1
```
RI 查表：$n=3$ 时 0.58、$n=4$ 时 0.90、$n=5$ 时 1.12、$n=6$ 时 1.24、$n=7$ 时 1.32。

**参数与坑**｜
- **CR ≥ 0.1 必须调整判断矩阵**，不能硬用。**论文里要报 CR 的值**，不报等于没做一致性检验。
- **判断矩阵的来源必须交代**：文献、行业标准、小组讨论。凭空给一个矩阵是最典型的套路化。
- 指标 $n > 9$ 时两两比较不可靠（人脑做不到一致），要先分层。
- **AHP 只给主观权重**。单用它的说服力弱，配熵权法（§8.2）做客观校正，再说明融合方式。

**国赛出处**｜2021C（C283：熵权法 + AHP 修正）。

**骨架**｜
```python
import numpy as np
RI = {3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45}
def ahp(A):
    val, vec = np.linalg.eig(A)
    k = int(np.argmax(val.real)); lmax = val.real[k]
    w = np.abs(vec[:, k].real); w /= w.sum()
    n = len(A); CI = (lmax - n) / (n - 1); CR = CI / RI[n]
    assert CR < 0.1, f'一致性检验不通过 CR={CR:.3f}，需调整判断矩阵'
    return w, CR                                    # CR 必须报
```

## §8.2 熵权法

**是什么**｜按各指标数据的**离散程度**自动定权：变异大的指标信息量大，权重高。

**什么时候用**｜有完整的指标数据矩阵，且不想（或不能）引入主观判断。

**核心**｜
```
标准化（正向/负向指标分开处理）→ 计算比重 p_ij = x_ij / Σ_i x_ij
  → 熵 e_j = −(1/ln m) Σ_i p_ij ln p_ij
  → 差异系数 d_j = 1 − e_j  →  权重 w_j = d_j / Σ d_j
```

**参数与坑**｜
- **$p_{ij}=0$ 时 $\ln 0$ 是 $-\infty$**，而极差标准化**必然**把每列最小值压成 0，所以这个坑一定会踩到。
  正解是只在正元素上取对数（下面骨架里的 `np.log(..., where=P>0)`），
  **别加 1e-10 硬凑**（会引入尺度依赖的偏差）。
  注意 `np.where(P>0, P*np.log(P), 0)` 数值上对，但它会把两个分支都算一遍，
  仍然刷一串 `divide by zero` 警告——赛场上这种噪声会掩盖真正的报错。
- **负向指标（越小越好）必须先转向**：$x'=\frac{\max-x}{\max-\min}$，忘了转向权重就全错。
- **熵权法的权重完全由数据的离散度决定，与重要性无关**。
  某个不重要但波动大的指标会拿到高权重。**这是它最大的弱点，论文里要点出来并做敏感性分析。**
- 样本量小或指标高度相关时熵权极不稳定。要报权重的自助置信区间。

**国赛出处**｜2021C（C085、C283 都用了）。

**骨架**｜
```python
import numpy as np
def entropy_weight(X, neg_cols=()):
    X = X.astype(float).copy()
    for j in neg_cols:                                    # 负向指标转向：别忘
        X[:, j] = X[:, j].max() - X[:, j]
    X = (X - X.min(0)) / (X.max(0) - X.min(0) + 1e-12)   # 每列最小值变成 0
    P = X / X.sum(0, keepdims=True)
    plogp = np.zeros_like(P)
    np.log(P, out=plogp, where=P > 0)                    # 只在正元素上取对数
    plogp *= P
    e = -plogp.sum(0) / np.log(len(X))                   # 熵
    d = 1 - e                                            # 差异系数
    return d / d.sum()
```

## §8.3 TOPSIS

**是什么**｜按"离理想解近、离负理想解远"排序方案。

**什么时候用**｜多个方案、多个指标、要**排序或打分**。是评价类最常用的排序工具。

**核心**｜
```
标准化（向量归一化 x/√Σx²）→ 加权 → 定正理想解 A+（各列最优）与负理想解 A−
  → 算距离 D+ = ‖v − A+‖, D− = ‖v − A−‖
  → 贴近度 C = D− / (D+ + D−)，越大越好
```

**参数与坑**｜
- **权重从哪来是 TOPSIS 的全部争议点**。TOPSIS 本身不产生权重，
  必须配 §8.1/§8.2。**论文里"用了 TOPSIS"不算说明方法，"用熵权法定权 + TOPSIS 排序"才算。**
- **必须做权重敏感性分析**：权重 ±20% 扰动，看前三名排序变不变。稳则结论可靠，不稳要说明。
- **逆序问题**：增删方案可能改变原有方案的相对排序（因为理想解会变）。
  要么固定理想解（用理论最优/最劣值而非数据极值），要么在论文里说明这个局限。
- 负向指标要先转向（同 §8.2）。
- 向量归一化 vs 极差归一化会给出不同排序，**要说明选了哪种及理由**。

**国赛出处**｜2021C（C066、C085 一等奖）。

**骨架**｜
```python
import numpy as np
def topsis(X, w, neg_cols=()):
    X = X.astype(float).copy()
    for j in neg_cols: X[:, j] = X[:, j].max() - X[:, j]
    V = X / np.sqrt((X**2).sum(0)) * w
    Dp = np.linalg.norm(V - V.max(0), axis=1)
    Dn = np.linalg.norm(V - V.min(0), axis=1)
    return Dn / (Dp + Dn)

for pert in (0.8, 1.0, 1.2):                              # 权重敏感性：必做
    print(np.argsort(-topsis(X, w*np.array([pert,1,1,1])))[:3])
```
模板：`1_skill/code-templates/python/evaluation/topsis_template.py`

## §8.4 模糊综合评价

**是什么**｜评价等级本身模糊（"优/良/中/差"）时，用隶属度函数把清晰值映射到各等级，
再用模糊算子合成。

**什么时候用**｜评价标准本身是语言性的、边界不清晰的（"安全性较好"），
且有行业分级标准可依。

**核心**｜
```
定因素集 U、评语集 V → 对每个因素建隶属函数得模糊关系矩阵 R (|U|×|V|)
  → 定权重 W → 合成 B = W ∘ R（∘ 是模糊算子）
  → 按最大隶属度或加权平均定级
```
算子选择：$M(\cdot,\oplus)$ 加权平均型（**推荐，信息损失小**）
vs $M(\wedge,\vee)$ 主因素决定型（只保留最大值，损失严重）。

**参数与坑**｜
- **隶属函数的形状和参数必须有依据**（国标分级、行业规范、专家）。
  随手取三角形隶属函数是这个方法被批"套路化"的主因。
- **算子要选加权平均型**，别用主因素决定型（会丢掉除最大值外的全部信息）。
- **要做隶属函数参数的敏感性分析**。
- 单纯的"打分-加权"问题不必用模糊，直接加权和更清楚。**模糊的价值在于处理等级边界的不确定。**

**国赛出处**｜评价类常见；连续四年在"套路化"清单上——用它必须回答"这道题的模糊性在哪"。

**骨架**｜模板：`1_skill/code-templates/python/evaluation/fuzzy_eval_template.py`
```python
import numpy as np
def trimf(x, a, b, c):                                   # 三角隶属函数
    return np.clip(np.minimum((x-a)/(b-a+1e-12), (c-x)/(c-b+1e-12)), 0, 1)
R = np.array([[trimf(v, *par[j][k]) for k in range(K)] for j, v in enumerate(vals)])
B = W @ R                                                 # 加权平均型算子
grade = int(np.argmax(B))
```

**别用它的时候**｜评价标准清晰、有明确阈值 → 直接分段判定。

## §8.5 灰色关联与 GM(1,1)

**是什么**｜灰色关联度量曲线形状的相似程度；GM(1,1) 用一次累加生成把序列变光滑再拟合指数。

**什么时候用**｜**样本极少**（4–10 个点）且没有别的办法时。这是它唯一的合理适用场景。

**核心**｜
- **灰色关联度**：$\xi_i(k)=\frac{\min\min|x_0-x_i|+\rho\max\max|x_0-x_i|}{|x_0(k)-x_i(k)|+\rho\max\max|x_0-x_i|}$，
  $\rho=0.5$，对 $k$ 取均值得关联度。**注意它比的是曲线形状，不是相关性。**
- **GM(1,1)**：一次累加 $x^{(1)}$ → 拟合 $\frac{\mathrm dx^{(1)}}{\mathrm dt}+ax^{(1)}=b$
  → 解得 $\hat x^{(1)}(k+1)=(x^{(0)}(1)-\frac ba)e^{-ak}+\frac ba$ → 累减还原。

**参数与坑（这一条要说重话）**｜
- **GM(1,1) 本质上就是拟合一条指数曲线**。数据不是指数增长趋势时它必然失效，
  且**残差检验经常被略过**，于是错得无声无息。
- **必须做级比检验**：$\sigma^{(0)}(k)=\frac{x^{(0)}(k-1)}{x^{(0)}(k)}$ 全部落在
  $(e^{-2/(n+1)},\ e^{2/(n+1)})$ 内才能建模。**不检验就用是典型的套路化。**
- **必须做后验差检验**（$C=S_2/S_1<0.35$ 为好）和小误差概率 $P>0.95$。**要报这两个数。**
- **数据够多（> 20 点）时不要用 GM(1,1)**，ARIMA（§6.1）或回归（§4.3）在各方面都更好，
  且有完整的统计推断。灰色模型给不出置信区间。
- 灰色关联度**不能替代相关系数**做统计推断（没有分布、没有 p 值）。
  它只是一个描述性指标，用它下"显著相关"的结论是错的。
- 它在"套路化"清单上被点名（数据类："回归；主成分；聚类；**灰色**"）。

**国赛出处**｜2022C（灰色关联，一等奖论文关键词，作辅助）。

**骨架**｜
```python
import numpy as np
def gm11(x0):
    n = len(x0)
    sigma = x0[:-1] / x0[1:]                                     # 级比检验：必做
    lo, hi = np.exp(-2/(n+1)), np.exp(2/(n+1))
    assert np.all((sigma > lo) & (sigma < hi)), '级比检验不通过，不适合 GM(1,1)'
    x1 = np.cumsum(x0); z = 0.5*(x1[:-1] + x1[1:])
    B = np.column_stack([-z, np.ones(n-1)])
    a, b = np.linalg.lstsq(B, x0[1:], rcond=None)[0]
    f = lambda k: (x0[0] - b/a)*np.exp(-a*k) + b/a
    pred = np.diff(np.concatenate([[f(0)], [f(k) for k in range(1, n+5)]]))
    e = x0[1:] - pred[:n-1]
    C = e.std() / x0.std()                                        # 后验差比：必报
    return pred, C
```
模板：`1_skill/code-templates/python/evaluation/grey_relational_template.py`

**别用它的时候**｜数据点 > 20 → §6.1 或 §4.3，各方面都更好。
要做统计推断（p 值、置信区间）→ 灰色模型给不出，换统计方法。

# 第九族 · 成分数据

## §9.1 CLR / ALR / ILR 变换

**是什么**｜成分数据（各分量之和为常数）活在**单纯形**上而非欧氏空间。
对数比变换把它映到欧氏空间，做完统计再变回来。

**什么时候用（触发条件极明确）**｜
**题面出现"各成分比例累加为 100%""占比之和为 1""份额"** —— 立刻切到这条路线，
**全部方法选择都要改**。2022C 是典型。

**核心**｜设成分 $\mathbf x=(x_1,\dots,x_D)$，$\sum x_i=\kappa$：

| 变换 | 公式 | 特点 |
|---|---|---|
| **CLR**（中心对数比） | $\mathrm{clr}(\mathbf x)_i=\ln\dfrac{x_i}{g(\mathbf x)}$，$g$ 是几何平均 | 对称、可解释、**首选**。但结果和为 0（协方差奇异） |
| **ALR**（加性对数比） | $\ln\dfrac{x_i}{x_D}$，$i<D$ | 简单，但依赖分母的选择，不对称 |
| **ILR**（等距对数比） | 正交基下的坐标 | 度量正确、协方差非奇异，但坐标难解释 |

**完整流程**（照 2022C 官方路线）：
```
剔除无效样本 → 归一化到 100% → 零值用小量 ε 填充后再归一
  → CLR 变换 → 在欧氏空间做统计（检验/聚类/相关/回归）
  → CLR 逆变换回成分（自动满足定和约束）
```
CLR 逆变换：$x_i=\dfrac{e^{y_i}}{\sum_j e^{y_j}}\cdot\kappa$（softmax），**天然满足定和**。

**参数与坑**｜
- **Pearson 相关在成分数据上必然失真，有偏负倾向**。
  官方极端例子：只有两个成分时 $\mathrm{PCC}(x_1,x_2)=-1$，与实际关系无关。
  **必须先 CLR 再算相关。**
- **零值必须处理**（$\ln 0=-\infty$）。$\varepsilon$ 取检出限的 65%，或用
  乘法替换法（`zCompositions` 的 `multRepl`），填完**要重新归一化**。
  $\varepsilon$ 的取值要做敏感性分析。
- **CLR 后协方差矩阵奇异**（各行和为 0）。要做 PCA 没问题（丢掉最后一个零特征值），
  但要求矩阵可逆的方法（马氏距离、某些判别分析）会崩，此时用 ILR。
- **所有下游方法都要在变换后的空间做**：聚类、回归、检验、距离，一个都不能例外。
  只对相关做 CLR 而聚类用原始数据，是半途而废。
- **报结果时要变换回成分空间**，读者要看的是百分比不是对数比。

**关联的两条 2022C 官方要点**（都在成分数据语境下）：
- **聚类前的变量选择是独立难点**，官方称"典型的**无监督变量选择问题**"（→ §7.6）；
- **PCA 不是变量选择**（→ §7.2）。

**国赛出处**｜**2022C 官方主线**（中心化对数变换，一等奖论文关键词）。

**骨架**｜
```python
import numpy as np
from scipy.stats import gmean

def close(X, kappa=100.0):
    return X / X.sum(1, keepdims=True) * kappa

def clr(X, eps_frac=0.65, dl=0.01):
    X = np.where(X <= 0, dl*eps_frac, X)            # 零值替换
    X = close(X)                                     # 替换后重新归一：必做
    return np.log(X / gmean(X, axis=1, keepdims=True))

def clr_inv(Y, kappa=100.0):
    E = np.exp(Y - Y.max(1, keepdims=True))          # 减最大值防溢出
    return close(E, kappa)

Z = clr(X)
corr = np.corrcoef(Z.T)                              # 在 CLR 空间算相关
labels = KMeans(4, n_init=10, random_state=42).fit_predict(Z)   # 聚类也在 CLR 空间
centers_comp = clr_inv(centers_clr)                  # 报结果时变回成分
```

**别用它的时候**｜各分量之和**不**恒定 → 普通方法即可，别多此一举。
只关心单个分量的绝对值且分母无意义 → 直接分析该分量。

  步骤 1  按 …（初值构造依据）生成 N=… 个初始个体
  步骤 2  …
  步骤 3  终止条件：连续 … 代最优值相对改进 < 1e-8，或达到最大代数 2000

**参数设置**：种群规模 N=…，缩放因子 F=…，交叉概率 CR=…（依据：…）

**收敛性与稳定性**：固定随机种子 {0..9} 独立运行 10 次，
