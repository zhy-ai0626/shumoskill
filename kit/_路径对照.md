# 路径对照：`1_skill/` 在本仓库里就是仓库根目录

`kit/` 下的手册是从本地交付包 `交付/` 原样搬过来的，里面约 30 处写成
`1_skill/...`。那是**交付包里的**目录结构：

```
交付/                     ← 本地交付包
├── 1_skill/              ← skill 本体
├── 0_开赛操作手册.md
└── 5_算法讲解手册.md
```

**本仓库把 skill 摊在了根目录**，所以没有 `1_skill/` 这一层：

```
shumoskill/               ← 本仓库
├── SKILL.md              ← skill 本体直接在根
├── code-templates/
├── figures/
├── competitions/
└── kit/                  ← 就是原来的 交付/（去掉重复的 1_skill/）
    ├── 0_开赛操作手册.md
    └── 5_算法讲解手册.md
```

## 换算规则

| 手册里写的 | 在本仓库里 | 从 `kit/` 出发的相对路径 |
|---|---|---|
| `1_skill/code-templates/python/optimization/ga_template.py` | `code-templates/python/optimization/ga_template.py` | `../code-templates/...` |
| `1_skill/figures/cumcm_style.py` | `figures/cumcm_style.py` | `../figures/cumcm_style.py` |
| `1_skill/competitions/cumcm/题型与算法对照.md` | `competitions/cumcm/题型与算法对照.md` | `../competitions/...` |

一句话：**把 `1_skill/` 去掉就是仓库内路径**；在 `kit/` 里引用则换成 `../`。

## 两处要注意的

- `0_开赛操作手册.md` 第 30 行的安装命令写的是从本地交付包拷：
  ```bash
  cp -r "D:/Desktop/数学建模/交付/1_skill" ~/.claude/skills/cumcm-abc
  ```
  从**本仓库**装的话，是把仓库根（不含 `kit/`）放到 `~/.claude/skills/cumcm-abc`：
  ```bash
  git clone https://github.com/zhy-ai0626/shumoskill.git
  cp -r shumoskill ~/.claude/skills/cumcm-abc
  rm -rf ~/.claude/skills/cumcm-abc/kit    # kit 是配套手册，不属于 skill 本体
  ```

- `4_知识点总结_题型与模型.md` 与 `competitions/cumcm/题型与算法对照.md`
  是**同一文档的两处副本**，除互指句外应逐字相同。改一处要同步另一处
  （本地用 `_tools/check_repo.py` 对账）。

> 没有直接改那 30 处路径，是为了让 `kit/` 与本地 `交付/` 保持逐字节一致——
> 一改就分叉，而分叉不报错、只会让两边慢慢对不上。
