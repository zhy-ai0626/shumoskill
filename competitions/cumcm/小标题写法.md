# 一等奖论文的章节与小标题实际怎么写

样本：**44 篇官方展示论文**（2021–2025 ABC 题）的全文标题，用 MinerU OCR 文本
逐行匹配 `一、`/`N.M` 两种编号后统计。下面每个数字都是实测计数，不是经验之谈。

与 `摘要写法.md` 是同一批样本，可以对照读。**摘要归摘要，标题归标题**：
摘要里不写"模型评价"（只有 11% 会写），但正文里"模型评价"是一个独立章节
（68% 有）——这两条不矛盾，是同一件事的两端。

---

## 1. 先看数量：小标题远比你以为的多

| 统计项 | p25 / p50 / p75 |
|---|---|
| **每篇 `N.M` 形式的小标题数** | **25 / 30 / 39** |

中位数 **30 个**。这是最容易被忽略的一条：一等奖论文把正文切得很碎，
平均每 1.5～2 页就有一个带编号的小标题。

**自查**：如果你的论文只有 10 个小标题，不是"简洁"，是**没把任务链显式化**——
评委翻页时看不到你做了哪些步骤。反过来，超过 40 个通常意味着把
"一段话"也提成了标题。

（计数已按 `(编号, 标题)` 去重核对过：44 篇里 0 篇出现目录页重复计数，
所以这个分布不是被目录抬高的。）

---

## 2. 顶层章节的命中率（44 篇）

| 章节 | 命中 | 比例 |
|---|---|---|
| 问题重述 | 35 | **80%** |
| 问题分析 | 33 | **75%** |
| 符号说明 | 33 | **75%** |
| 模型评价（含"与推广/与改进/、改进与推广"等 10 种变体） | 30 | **68%** |
| 模型假设 | 29 | 66% |
| 参考文献 | 23 | 52% |
| 附录 | 9 | 20% |

**"模型建立与求解"有两种组织法，都常见**：

- **合成一章**：`模型的建立与求解`（14 篇）/ `模型建立与求解`（6 篇），
  下面用 `5.1 问题一模型的建立与求解`、`5.2 问题二…` 分小节；
- **拆成多章**：`六、问题二模型的建立与求解`、`七、问题三模型的建立与求解` …
  （逐问各占一个顶层章节，2021–2025 都有）。

题目子问题多（4～5 问）时拆成多章更好读；2～3 问时合成一章即可。

## 3. 小标题的真实词表

**照抄这些词，不要自己造词。** 括号内是 44 篇里的出现次数（同义变体已分列）。

**问题重述章下**
`问题背景`(30) · `问题提出`(11) · `问题要求`(7) · `问题的背景`(4)

**问题分析章下 —— 最该照抄的一条**
`问题一的分析`(24) · `问题二的分析`(25) · `问题三的分析`(24) ·
`问题四的分析`(18) · `问题五的分析`(5)

> 24～25 篇（≈ 55%）都是**在"问题分析"章下按子问题逐个开小节**，
> 标题就叫「问题N的分析」。这是整份样本里复现率最高的结构模式，
> 也是最省事的一条：有几问就开几节，一一对应。
> 少数写成 `2.1 问题一`(5) 这种极简形式，也可以。

**模型建立与求解章下**
`模型建立`(16) · `模型的建立`(12) · `模型求解`(14) · `模型的求解`(12) ·
`数据预处理`(13) · `建模思路`(5) · `优化模型求解`(4) · `模型汇总`(6)

**结果与检验**
`结果分析`(9) · `模型检验`(8) · `求解结果`(6) · `模型计算结果`(5) ·
`求解过程及结果分析`(4) · `敏感性分析`(4) · `灵敏度分析`(2) · `小结`(7)

**模型评价章下（三件套）**
`模型的优点`(23) + `模型优点`(9) = **32** ·
`模型的缺点`(18) + `模型缺点`(9) = **27** ·
`模型的推广`(15) · `模型的改进`(4)

> "优点 / 缺点 / 推广"是这一章的固定三小节。**写缺点不扣分，不写才扣分**——
> 27 篇明确列了缺点。

## 4. 不要用这些标题：实测 0 次

同目录 `distilled_structures.md` 把下面几个当"子章节切分"模板给出，
但在 44 篇官方展示论文里**一次都没出现过**：

| 该文件建议的标题 | 实测出现 |
|---|---|
| 题目任务 / 子问题列表 / 研究目标归纳 | 0 / 0 / 0 |
| 假设原则 / 假设清单 / 假设支撑 | 0 / 0 / 0 |
| 总体分析 / 方法路线与依赖链 | 0 / 0 |

那份文件的**信息功能**说得对（对齐题意、逐条给假设依据、写清依赖链），
照做没问题；但**别照抄它的标题字面**。要落成标题时，用 §3 的真实词表。

## 5. 2025 三份骨架，直接照抄

**2025 C023**（NIPT，4 问，合成式）
```
一、问题重述      1.1 问题背景 / 1.2 问题要求 / 1.3 我们的工作
二、模型假设
三、符号说明
四、问题一：Y染色体浓度与孕周、BMI的关联模型
                 4.1 问题分析 / 4.2 数据预处理
                 4.3 模型建立（4.3.1 响应变量与自变量处理 /
                     4.3.2 模型结构 / 4.3.3 模型的比较与选择）
                 4.4 模型求解 / 4.5 模型检验
```
注意它**把章节标题写成了"问题一：<这一问的实质>"**，而不是干巴巴的
"问题一模型的建立与求解"——评委翻目录就知道每问在解什么。这是个便宜的加分点。

`1.3 我们的工作` 是放总体技术路线图的地方（`figures/flow_pptx.py` 生成的
第 1 页正是这张）。但要说清：**这个标题 44 篇里只有这 1 篇用**，
别当通例；真正常见的是"有流程图"这件事本身（52% 有，平均 2.3 张）。

**2025 B157**（外延层厚度，3 问，合成式）
```
一、问题重述  1.1 问题背景 / 1.2 问题提出
二、问题分析  2.1 问题一 / 2.2 问题二 / 2.3 问题三
三、模型假设
四、符号说明
五、模型建立与求解
      5.1 问题一模型的建立与求解（5.1.1 两光束干涉厚度模型的建立 /
          5.1.2 …的求解）
      5.2 问题二模型的建立与求解（5.2.1 数据预处理 /
          5.2.2 基于Cauchy折射率模型的外延层厚度反演 / 5.2.3 结果可靠性分析）
      5.3 问题三模型的建立与求解（5.3.1 … 5.3.6）
六、模型评价  6.1 模型优点 / 6.2 模型缺点
```
最标准的一份，**三级编号到 `5.3.6`**。三级标题是把"一大段推导"切开的主要手段。

**2025 A196**（烟幕干扰弹，5 问，多章式）
```
一、问题重述  1.1 问题背景 / 1.2 问题提出
二、问题分析  2.1 问题一的分析 … 2.5 问题五的分析
三、模型假设
四、符号说明
五、模型准备    5.1 运动轨迹方程（5.1.1 导弹轨迹 / 5.1.2 无人机轨迹 /
                5.1.3 烟幕弹轨迹 / 5.1.4 云团中心轨迹）
                5.2 有效遮挡判定式（5.2.1 … 5.2.3）
六、问题一模型建立及求解  6.1 有效时长计算模型（6.1.1 … 6.1.3）/ 6.2 模型的求解
（七、八… 逐问各一章）
```
`五、模型准备` 值得单独说：**多问共用的运动学 / 判定式先立一章**，
后面每问直接引用，不重复推导。子问题之间共享机理时照这个办。

## 6. 三条落笔规则

1. **标题长度**：实测绝大多数在 4～8 个字。写成一句话（>15 字）的极少，
   只在"问题一：<实质>"这种点明内容时才长。
2. **编号体系**：顶层用 `一、二、三`，小标题用 `N.M` 与 `N.M.K`。
   两套混用是常态，不要全文用阿拉伯数字或全文用中文数字。
3. **一一对应**：`问题分析` 的小节数 = 题目子问题数；
   `模型建立与求解` 的小节（或章）数 = 子问题数。
   评委对着目录就能数出来你是不是每问都做了。

---

## 7. 数据可信度

- 标题来自 MinerU OCR，**计数是下界**：图片型标题、被识别成正文的标题会漏掉，
  所以真实命中率只会比表里更高，不会更低。
- 同义变体（`模型建立` vs `模型的建立`）故意分开列，没有合并——
  合并会掩盖"到底哪种写法更常见"。
- 复算方式见资料库 `_tools/_mine_headings.py`（依赖 `_解析文本/`，不随 skill 分发）。
