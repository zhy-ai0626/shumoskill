# 静默陷阱：不报错，只出错数

竞赛里最危险的不是崩溃——崩溃会逼你去看。危险的是**程序跑通了、图也画了、数字也有了，
但那个数是错的**。这类错误只能靠主动自查抓出来。

本文件收录实测遇到过的具体陷阱，以及抓它们的通用手段。
Stage 5（求解）与 Stage 6（稳健性）各过一遍。

---

## 零、通用手段：先写恒等式，再看结果

**最有效的一招是给每个中间量找一条它必须满足的恒等式，然后检查。**
恒等式不成立，说明要么算错了，要么用错了工具——两种都得查。

| 场景 | 该成立的恒等式 |
|---|---|
| 方差分解 | `var_固定 + var_随机 + σ² ≈ var(Y)` |
| 概率/分布 | 各类概率之和 = 1；CDF 单调、端点为 0 和 1 |
| 物理/机理 | 能量、质量、动量守恒；量纲两边一致 |
| 分组/分段 | 各组人数之和 = 总人数；各段长度之和 = 全区间 |
| 优化 | 目标函数在最优解处的值 = 逐项重算的值；约束逐条代回都满足 |
| 概率化的比例 | 分子 ≤ 分母；比例落在 [0,1] |
| 前后两问 | 后一问在退化参数下应还原成前一问的结果 |

**实证**：2025C 端到端演练里，混合效应模型的边际 $R^2$ 算出 0.422。
单看这个数没有任何异常。但做方差分解自查时发现
`var_f + var_r + σ² = 0.00214`，是 `var(Y) = 0.00112` 的 **1.91 倍**——
三部分之和不可能接近总方差的两倍。顺着查下去才找到根因（见 §1.1）。
真值是 0.182。**如果不做这个自查，一个虚高一倍多的指标就会写进论文和摘要。**

## 零点五、在合成数据上验过的估计器，不等于实测能用

**这一条最容易骗过自己**：自检全过、心里有底，然后一上真数据就悄悄错掉。

**实证（2025B 端到端演练）**：极值级次回归法在合成谱上的相对误差是
$9.9\times10^{-5}$（比相位法还高一个量级），一上实测数据返回
**$L=2174\ \mu$m，真值约 $40\ \mu$m**。

根因不是精度不够，而是**中间量的含义被噪声改掉了**：
该算法先取"相邻极值间距的中位数"作为一个条纹的单位；实测谱上叠着采样噪声，
`find_peaks` 把噪声峰也算成极值，于是"中位间距"变成了噪声的间距。
修复是先做 Savitzky–Golay 平滑，并给极值检测加最小间距约束。

**自查动作**：估计器第一次上真数据时，**打印它的中间量**，不要只看最终输出。
本例该打印的是「找到几个极值」「相邻间距的中位数是多少」——
一眼就能看出上万个极值、间距 1 cm$^{-1}$ 是不对的。
最终输出"像个数"是最没有信息量的信号。

| 估计器 | 该打印的中间量 |
|---|---|
| 峰值/极值类 | 极值个数、相邻间距的中位数与分布 |
| 频域类 | 峰位所在的 bin 序号（是不是第 1 个 bin？那就只是残余基线） |
| 回归类 | 样本数、条件数、残差 RMS、残差的自相关 |
| 迭代优化类 | 迭代次数、是否触界、多初值收敛到几个不同解 |

## 一、库函数的语义和你以为的不一样

### 1.1 `statsmodels` 的 `MixedLMResults.fittedvalues` 包含随机效应

`fittedvalues` 返回的是 $\bm X\hat{\bm\beta} + \bm Z\hat{\bm b}$（条件预测），
**不是**固定效应部分。要固定效应必须显式写：

```python
xb = np.asarray(res.model.exog) @ np.asarray(res.fe_params)   # 固定效应部分
# res.fittedvalues  ← 这个含随机效应，别拿它算边际 R²
```

- **后果**：Nakagawa 边际 $R^2$ 从真值 0.182 虚高到 0.422（2025C 实测）。
- **对照**：R 里要写 `predict(fit, re.form = NA)` 才是固定效应。
- 顺带：`res.resid` 是条件残差 $y - \bm X\hat{\bm\beta} - \bm Z\hat{\bm b}$，
  用于残差诊断是对的，这个没问题。

### 1.2 `statsmodels` 的 `MixedLM` 不填 `aic` / `bic`

`res.aic` / `res.bic` 返回 `NaN`，打印出来是一列 `NaN` 而不是报错。手算：

```python
k = len(res.params)
aic = -2 * res.llf + 2 * k
bic = -2 * res.llf + k * np.log(nobs)
```

### 1.3 随机效应的似然比检验不能直接查 $\chi^2$

检验"要不要加随机斜率"时，零假设 $\sigma_v^2 = 0$ 落在参数空间**边界**上，
LR 统计量不服从标准 $\chi^2_k$。加一个随机斜率 + 协方差时用混合分布：

```python
p = 0.5 * chi2.sf(LR, 1) + 0.5 * chi2.sf(LR, 2)
```

直接用 $\chi^2_2$ 会**高估** $p$ 值（偏保守，可能漏掉真实存在的随机效应）。

### 1.4 尺度变换后的对数似然不能直接比

比较"原尺度"和"logit 尺度"哪个模型更好时，两者的 $\ell$ 不在同一尺度，
必须用变量替换的雅可比行列式折算：

$$\ell_{\text{原尺度}}^{(\text{logit 模型})} = \ell_{\text{logit}} - \sum_i \log\big(y_i(1-y_i)\big)$$

2025C 实测：原尺度 $\ell = +2651.13$；logit 尺度 $\ell = -344.65$，
雅可比项 $+2969.57$，折算后 $+2624.92$ → **原尺度更优**。
不折算就直接比 $-344.65$ 和 $+2651.13$，会得出完全相反的结论。

## 二、统计口径用错

### 2.1 筛特征用标准化均值差 → 被离群点主导

小样本、重尾变量上，**几条极端记录就能把均值差顶到最高**，而那个变量根本没有判别力。

**实证**（2025C 问题 4）：候选变量里"被过滤掉读段数的比例"的标准化均值差
高达 **1.35**，全场第一，一度被当成最强信号写进分析。
改用 Mann–Whitney 秩统计量后 **AUC 只有 0.517**（等于随机）。
差异全部来自 2 条极端记录（过滤率 0.186 与 0.168，其余记录 $p_{99}$ 仅 0.034）。

**做法**：筛特征一律用**秩统计量**（AUC / Mann–Whitney U / Spearman），
均值差只在确认过分布近似对称、无重尾之后才用。

### 2.2 交叉验证不按个体分组 → 数据泄漏

同一对象有多条记录时（重复测量、面板数据），普通 K 折会把同一对象的记录
拆到训练集和测试集两边，模型只要"认出这个人"就能猜对标签。

用 `StratifiedGroupKFold(groups=对象ID)`。
并且**如实报告泄漏幅度**：2025C 实测虚高 0.003~0.015（标签的个体内聚集只有 2.2 倍，
所以幅度不大），别夸大成"严重高估"，也别因为幅度小就用错设计。

### 2.3 容差里的 `abs_tol` 别拿 `rel_tol` 顶

写数值比对时 `math.isclose(a, b, rel_tol=r, abs_tol=r)` 是个常见笔误：
对小数值等于给了一个 `r` 的**绝对**容差。`r=5e-3` 时 0.182 和 0.187 会被判为相等。
`abs_tol` 应该接近 0，只用来处理"和 0 比"的情形。

## 三、模型结构诱发的退化解

### 3.1 阶梯型目标函数在"平台内部"没有梯度

题面给出分档风险（如"早期低 / 中期高 / 晚期极高"）时，如果照字面写成三档**常数**，
那么中期内部任何时点代价相同，优化器就会跑到平台的另一端去优化别的项。

**实证**（2025C 问题 2）：三档常数下，高 BMI 组的最优检测时点跳到 **23 周**——
"反正进不了早期，那就拖到窗口末端把可判读率做满"。这显然不合临床。
把中期内部改成从 $r_\text{中}$ 线性升到 $r_\text{晚}$ 的单调形式后，
最优时点回到 11–12.5 周的合理区间。官方讲评给的 $Risk(t)$ 正是分段线性递增。

**判据**：目标函数里若有常数平台，先问一句——**平台内部真的无差别吗？**
治疗窗口、库存天数、工期这类量几乎总是连续变差的。

### 3.2 单调结构会让某一维决策变量失去意义

若目标只是某个"发现时点 $D$"的增函数，而 $D$ 关于决策变量 $t_0$ 单调不减，
那么"$t_0$ 取最小"对任何参数都最优——题目要求的**分组就退化成一组**。

**实证**（2025C 问题 2）：允许无限次复检时，所有 BMI 的最优首检时点都是 11.0 周，
分 4 组相对不分组的风险改善**恰好为 0**。
必须补上"复检次数有上限"这类真实约束，两端的取舍才成立。

**判据**：分组/分档做完之后，**一定要报"分组相对不分组改善了多少"**。
如果是 0 或接近 0，不是分组方法不好，而是目标函数漏了东西。

### 3.3 目标函数里两项量纲不可比时，别为了消掉权重就删掉一项

两项量纲不同（如"治疗窗口风险"与"检测可靠性"）时，答案完全由那个人为比值决定。
2025C 实测：该比值从 1 改到 3，高 BMI 组的最优时点在 10.5 周和 23 周之间跳。

删掉一项确实能消掉人为参数，模型更干净——但也可能把题目的核心取舍一起删了
（本次就因此让各组时点差异被压平）。**更好的做法**：保留该项，
明确声明它是**政策参数**而非估计量，并给出它在全量程上的解，把选择权交回给决策者；
或者改写成**约束形式**（"可靠性 ≥ $p_0$"），$p_0$ 是有临床含义的服务水平。

## 三点五、LaTeX / 排版的静默坑

这一类最危险：**PDF 照样生成，但内容已经丢了一大半**，不看页数根本发现不了。

### 3.5.1 hyperref 遇到标题里的数学命令会撑爆输入栈，后续内容整段丢失

**实证（2025A 端到端演练）**：小节标题写成

```latex
\subsection{$(\theta,v,t_d,\tau)\longleftrightarrow(\bm B,t_e)$ 是一一对应}
```

`xelatex` 报

```
! Illegal parameter number in definition of \Hy@tempa.
! TeX capacity exceeded, sorry [input stack size=10000].
```

然后**照样输出了 PDF**——只有 **2 页**，从这一节起后面全没了（应有 11 页）。
根因是 hyperref 生成 PDF 书签时要把标题展开成纯文本，`\bm` 这类需要展开的命令
会触发无限展开。

**修复**：凡是标题（`\section`/`\subsection`/`\caption`）里含数学命令，
一律用 `\texorpdfstring{数学版}{纯文本版}`：

```latex
\subsection{\texorpdfstring%
{$(\theta,v,t_d,\tau)\longleftrightarrow(\bm B,t_e)$ 是一一对应}%
{(theta, v, t_d, tau) 与 (B, t_e) 是一一对应}}
```

**自查**：编译后**必须核页数**，不能只看"有没有生成 PDF"。
`grep -c "^!" paper.log` 应为 0；页数用 `grep -o "Output written on .*pages\?)" paper.log`
从 log 里取（**别用 `pdfinfo`**，scheme-small 不带它）。
页数与预期不符，就去 log 里找**第一条** `!`——从那里往后的内容都可能已经丢了。

### 3.5.2 摘要溢出到第二页，往往不是字数问题

见 `摘要写法.md` §4.5：2025C 演练里摘要只有 680 汉字（低于一等奖 p25 的 848）却仍溢出，
真因是约 40 处行内公式的横向足迹。**先数公式，再看字数。**

### 3.5.2b pandoc 的**无标题表格**会让整篇论文只剩 1 页

**实证（2026-09-03，render_paper.py 链路首次实测）**：markdown 里写一个普通管道表格

```markdown
| 参数 | 取值 |
|---|---|
| 半径 | 10 m |
```

pandoc 因为它**没有标题**，生成的是

```latex
{\def\LTcaptype{none} % do not increment counter
\begin{longtable}[]{@{}ll@{}}
```

裸 `longtable` 下这没问题（不写 `\caption` 就用不到 `\LTcaptype`），但模板一旦加载
`caption` 宏包，它会去 `\refstepcounter{\LTcaptype}`：

```
! LaTeX Error: No counter 'none' defined.
```

**然后照样输出 PDF——从出错那一节起全没了，10 节的论文只剩 1 页。**

模板已修（`templates/latex/cumcm/main.tex` 里 `\newcounter{none}` 接住它），
但要知道这类症状的形状：**一个表格能吃掉整篇论文**。

顺带两条：

- **给表格写标题**。除了避开这个坑，评委也是要看表题的。
  markdown 里用 `: 表题` 紧跟表格即可。
- 编译报错但 PDF 存在时，`render_paper.py` 现在会把**页数和 `!` 报错数一起打出来**。
  页数不对就去 log 里找第一条 `!`。

### 3.5.2c 宏包不在本机 TeX 发行版里——直接 Emergency stop，连残缺 PDF 都没有

**实证（2026-09-03，2025B 演练）**：本机 TeX Live 是 **scheme-small**，`siunitx` 不存在：

```
! LaTeX Error: File `siunitx.sty' not found.
! Emergency stop.
```

这一条与本节其他坑相反——它**不静默**，是硬停、不出 PDF。
但值得记在这里，因为**发现得太晚的代价一样大**：
论文写到一半才第一次编译，这时删宏包意味着重写所有用到它的记号。

**本机实测清单**（用 `kpsewhich <pkg>.sty` 验证）：

| 可用 | 不可用 |
|---|---|
| `bm`、`multirow`、`booktabs`、`enumitem`、`subcaption`、`amsmath`、`ctexart` | **`siunitx`**、**`upgreek`** |

**做法**：**只用模板已经加载的宏包**。真需要 `\si{}` 这类记号，两行自定义就能顶掉：

```latex
\newcommand{\micro}{\mu}
\newcommand{\si}[1]{\ensuremath{\mathrm{#1}}}
```

**自查**：Stage 0 就把模板原样编译一次（`scripts/doctor.py` 的 `latex-smoke` 正是做这件事）；
写正文时不要引入模板之外的宏包，真要引入就**立刻编译一次再往下写**。

### 3.5.3 中文字体缺失只打 warning，图照出

matplotlib 缺中文字形时只打一行 `Glyph missing from font`，图正常生成，
评委看到的是一排方块。用 `code-templates/python/plot_setup.py` 的
`setup_mpl(strict_cjk=True)`——找不到中文字体就直接抛异常，
与其出一张全是方块的图，不如当场失败。

## 四、数据本身的静默坑

见 `题型与算法对照.md` §四与 `anti_patterns.md` Z 节。几条最常见的：

- 同一列**混合类型**（一半是 `int` 一半被 Excel 读成 `datetime`），`int()` 直接抛异常还算好的，
  更坏的是被 `pd.to_numeric(errors='coerce')` 静默变成 `NaN`。
- **大小写不一致**（如孕周里混了一个 `16W+1` 大写 W），正则不加 `re.I` 就静默丢一条。
- **两列本该自洽却对不上**（2025C 的孕周列与"检测日期 − 末次月经"只有 38.4% 吻合到 0.15 周内）。
  选哪一列当准，要在论文里写明理由。
- **恒等式关系的变量同时入模**（BMI ≡ 体重/身高²，VIF 达 $10^4$ 量级），系数不可解释。
