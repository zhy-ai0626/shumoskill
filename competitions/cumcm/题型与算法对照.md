## 零、先过这一关：组委会点名的「套路化」清单

2022–2025 四年《参赛和评阅情况》里有**一页一字不改**的幻灯片：

> 顽疾：论文模板化；**方法套路化**。套路与创新是格格不入的。**关键是要逻辑清楚、思路清晰**。
> 表现："n板斧"；盲目追求"高大上"（2025 加**"盲目使用 AI"**）；**不从"问题"出发，乱套"方法"**：
> - 评价类：**AHP；模糊综合评估；熵权法**；…
> - 数据类：**回归；主成分；聚类；灰色**；…
> - **遗传算法；神经网络；深度学习**；…

**这份清单恰好就是市面上"50 种常用算法""黄金算法匹配表"主推的东西。**

**但不是禁用**——一等奖论文里遗传算法出现 3 次、蒙特卡洛 2 次，粒子群、模拟退火都有。
**判据只有一条**：把你的方法段落换到另一道题上，如果照样成立，那就是套路。

### 反过来也要小心：别把"简化近似"判成错误

> 2024B 讲评（针对用正态近似代替二项精确检验）：「**学生使用公式一，不能说一定是错误的**…
> 这种方法本人计算过，只是数值上略有差异，方法是相同的。
> 总之，是否使用公式一不重要，**重要的是，抽样数要与次品数有关**。」

命题人的判据是**量与量的依赖关系对不对、逻辑是否闭合**，不是"用没用最严格的工具"。
（这条是我第 3 轮演练把"正态近似"列为错误、被官方原文否掉换来的。）

## 一、先判题型（题号 ≠ 题型）

反例：2021B 是数据拟合、2022B 是计算几何、2025B 是光学反演。

| 特征 | 题型 |
|---|---|
| 给的是物理规律、几何关系、运动参数，数据量小甚至无数据 | **机理/几何/运动类** |
| 给测量信号或几何观测，要反推物理量 | **工程反演/测量类** |
| 给一张观测表，任务是找关系、分组、判定 | **数据/统计类** |
| 给参数表、无数据附件，任务是做若干离散决策 | **统计决策类** |
| 各分量之和为常数（成分、占比、份额） | **成分数据类**（特殊支，方法全变） |

## 二、机理/几何/运动类（A 题常见）

```
解析表达优先（牛顿定律 / 微分方程 / 空间解析几何 / 坐标变换）
  → 数值求解（龙格-库塔、微元法、变步长遍历、二分/三分）
  → 优化（粒子群 / 遗传 / 差分进化，但必须先写清决策变量与目标函数）
  → 几何判别（分离轴定理、离散判别点集）
  → 蒙特卡洛验证 + 敏感性分析
```

**必做与技法**

- **有解析解就必须先给解析解**，数值只用来验证。
  2022A 官方给出最优阻尼的闭式解 `c_p = √((p₁²+p₂²)/(q₁²+q₂²))`（阻抗匹配形式）——
  这种题上遗传算法搜索是丢分。
- **极限退化自检是必做步骤，不是可选项**。新参数取边界值时公式应退化回上一问。
  （第 2 轮演练我写了这条却没执行，结果 sin/cos 配反没被发现。）
- **空间几何关系优先用"点法式"**（方向与法向内积为零）。2023B 官方原话：
  "公式推导最简单的方法是'点法式'…公式过于复杂会失去直观性"。
- **组合体的几何量要自己推**：质心、转动惯量、水线面积，题目不会直接给
  （2022A 官方专门用一节算圆柱壳+圆锥壳质心）。
- **先解静力平衡定初值**，别把初始条件取全零。
- **曲面问题先分块用平面近似，再复用简单情形的解法**（2023B 问题 4 官方路线）。
- **非惯性系要显式写出科氏力与牵连惯性力**，或改用拉格朗日方程自动生成。

**遮蔽 / 覆盖 / 可见性类的四条**（2025A 端到端实证，前三条我当时都栽了或没做到）

- **离散判别点集只取表面，不放内部点**。2025A 讲评原话：
  "部分参赛队将圆柱体内部点放在离散判别点集中，或者将**下底面圆的内部点**放在离散判别
  点集中，这些点都是不必要的，**因为导弹是看不到这些点的**。"
  官方还给了更强的化简："只要真目标上下底面的圆周均被烟幕遮蔽，则整个真目标也被遮蔽。"
- **能对参数求导解析求极值，就不要靠加密采样**。判据是
  `max_θ dist(球心, 线段(观测者, 目标圆周点 θ)) ≤ r`，
  官方对 θ 求导令其为 0，整理成关于 sin θ 的 **4 次或 2 次方程**（最多 4 或 2 个实根），
  于是"点点判断"变成"少数几个点的判断"。我用的是离散采样 + 向量化，够用但不如官方优雅。
- **覆盖判据的量词顺序**：多个遮挡体共同遮蔽有体积目标时是 `∀点∃体`，不是 `∃体∀点`。
  详见 `anti_patterns.md` **Z19**，含"角尺寸比值"这个判断协同有没有空间的现成判据。
- **时长用"网格定位 + 二分细化"，别直接二分**。2025A 讲评原话：
  "少数参赛队提到了用二分法，但没有给出具体的算法描述。**实际上，二分法不能直接使用**。
  如果某个时间点烟幕不能遮蔽真目标，此时并不能确定这个时间是下界还是上界，因为这会有
  两种情况……由此必须对二分法进行改进才能使用。"
  可用的实现：先用等步长网格把遮蔽区间**定位**出来（解决上下界不明的问题），
  再只在"一端为真、一端为假"的子区间内二分端点，可把误差压到 1e-7 s。

**决策变量的解析重参数化**（2025A 实证，把 4 维盲搜变成有几何含义的搜索）

抛体投放这类问题里，抽象的 `(航向 θ, 速度 v, 投放时刻 t_d, 起爆延时 τ)`
往往与**有几何含义的量**一一对应。2025A 的例子：

```
起爆点高度 B_z = z0 − ½gτ²        ⟹ τ = sqrt(2(z0−B_z)/g)   （高度唯一决定延时）
水平位移 (B_x,B_y) = UAV + v·t_e·(cosθ,sinθ) ⟹ v = |ΔB_xy|/t_e ，θ = atan2(ΔB)
```

于是决策空间变成"**起爆点 + 起爆时刻**"，可行域只剩三条代数约束，
初值可以直接放到"观测者—目标视线"附近去构造。**这一步比换优化器有用得多。**
注意初值要对准**遮蔽时刻**的视线而不是起爆时刻的视线（云团会下沉，起爆时须高出 `v_sink·Δt`）——
这一处写错，2025A 的可行组合数从 10150 掉到 111、最优初值从 4.58 s 掉到 2.33 s。

**官方点名的致命错误**（2025A 讲评「评阅中发现的问题」）：
"**直接用数据建立模型**"、"**没有给出具体算法**"。
后者尤其容易犯：写了优化模型却不写"用什么算法、怎么收敛、参数怎么定"照样扣分。

## 三、工程反演/测量类（2025B 型）

```
从物理原理推公式 → 先常数情形再推广到非常数 → 滤波 → 找波峰/波谷 → 计算
  → 牛顿迭代 / 非线性最小二乘 / 三次样条 / 傅里叶变换 → 误差分析 + 可靠性分析
```

2025B 讲评专门用一节辨析"**波峰坐标还是波谷坐标**"——这种细节辨析才是得分点。

### 三条实测技法（2025B 端到端演练得出）

**1. 观测量常常不是被估量本身，先把两者的关系写出来。**
周期信号反演参数时，从"间距"或"相位斜率"量到的往往是**群量**而不是原量。
2025B 里干涉相位 $\varphi=2\pi L(\nu)\nu$，量到的是
$L_g=\mathrm{d}(\nu L)/\mathrm{d}\nu = L+\nu\,\mathrm{d}L/\mathrm{d}\nu$。
折射率有色散时两者不等，混用让厚度偏 **+5.89%**，而谱看起来完全正常。
官方式 (9) 的差分形式与此等价。
**泛化自查**：写下"我量到的量 = 被估量的什么函数"，
若右端含被估量的导数，就不能直接代反演公式。

**2. 给正演模型留一个「标定增益」参数。**
凡是**用绝对幅值反演参数**的做法（如由反射率包络的 $R_{\max},R_{\min}$ 反演折射率），
都对仪器标定偏差敞口。2025B 实测：把增益 $g$ 留成待估量后，
拟合独立解出附件 2 偏高 **2.0%**、附件 3 与附件 4 相差 **10%**；
而官方主线（包络反演）把这份标定差直接变成了折射率差 7%、厚度差 7%
（同一块晶圆片，附件3 3.658 µm vs 附件4 3.410 µm）。
留 $g,b$ 两个自由度，换来对一整类系统误差的免疫。

**3. 用「未参与定目标量的参数是否自动对上」做交叉验证。**
比"两次算出来一样"强得多，因为它检验的是模型结构而不只是数值稳定性。
2025B 实测：两个入射角独立拟合，衬底等离子波数 $\nu_p$ 相差 0.64%、
界面渐变宽度 $\sigma$ 相差 1.7%——两者都是晶圆片的固有属性，
且都**没有**用来定厚度。它们自动吻合，说明模型没跑偏。

**另注：分清「联合拟合」与「联立求解」。**
两者都用多工况数据，但前者是同一组参数受更多约束（**良态**），
后者是用工况间之差去解新增未知量（**常常病态**）。
2025B 里"用 10° 与 15° 联立解折射率"的误差放大倍数是 **356×**——
理论信号只有 0.26%、而单角残差 1.8%，实测比值连符号都反，硬解无实根；
而官方展示论文 B157 的"双角联合拟合共享厚度与色散参数"是良态的。
**多工况数据的默认用法是联合约束 + 一致性校验，不是联立求解。**

## 四、数据/统计类（C 题常见）

### 第一步：判断要不要预处理（两个方向都栽过）

判据不是"附件长什么样"，而是**这一步是统计习惯，还是领域方法的组成部分**：

| 步骤性质 | 做不做 |
|---|---|
| 常规统计预处理：去重、插补、类别平衡、按分位删异常值 | **不做**，除非题目明确要求 |
| 原始流水/交易数据的聚合与口径统一（2023C 零售流水） | **做**——这是建模的一部分，不叫预处理 |
| 领域方法内在要求的质控（2025C 问题 4 的测序质量 QC） | **做**，并在论文里写明依据 |

2025C 讲评末页原文：「对问题附件中的数据**无需进行清洗、删补、平衡等常规的、
无益于问题解决的预处理**」。注意限定语是"**常规的、无益于问题解决的**"。

**这句话不能泛化到所有子问题。** 同一份讲评里，官方解问题 4 的第一步就是质控：
对原始读段数 L、比对比例 M、唯一比对读段数 O 保留 ≥Q05，
对重复读段比例 N、过滤读段比例 AA 保留 ≤Q95 的「中心 90% 截断」，
604 例筛到 501 例（本地复现 503/605，比例吻合）。

这条是两轮演练换来的，**两个方向都栽过**：

- 第 5 轮方案演练：从 2023C 的零售流水泛化出"数据类必须预处理"，被讲评末页那句话否掉；
- 第 6 轮端到端演练：反过来把"不做样本删除"写进论文的数据口径，
  **整个问题 4 没试质控路线**，性能差了一个量级（官方逐染色体 Se 0.92–1.00 @ Sp 99%，
  本地不做质控的合并模型分组交叉验证 AUC 0.810、Sp 95% 时 Se 仅 0.373）。

判据的另一半仍然成立，但要分清语境：**建模用**的时候，看着像"质量指标"的列
（GC 含量、读段数、过滤比例）多半是给你做分层校正的**协变量**，不是筛样本的门槛，
把协变量当过滤条件等于自己扔信息；而在**判定流程的质控**里，它们就是门槛。
同一列两种用法可以并存，取决于这一问在做什么。

### 主线

```
分布刻画（先分离时间效应 → 分布拟合 → K-S 检验）
  → 相关性（非正态用 Spearman）
  → 预测（Prophet / ARIMA / 混合效应模型）
  → 决策（报童模型 / 随机规划 / CVaR / 期望损失最小化 / NSGA-II）
  → 风险（贝叶斯 + 共轭先验 / 蒙特卡洛 / 3σ）
```

**观测不独立就上混合效应模型**：同一对象多条记录（2025C 同一孕妇多次检测）时，
普通 OLS 违反独立性假设，要用随机截距 + 随机斜率。

### 两条命中率最高的反模式

**1. 有序连续变量分组不能用聚类**
> 2025C 评阅："**超半数队伍**选择 K-means、层次聚类等经典方法直接对 BMI 数据本身进行聚类，
> 未考虑协变量孕周的变化对 BMI 有序分组的影响…整体答题情况较为一般"

BMI、年龄、孕周这类**有序连续量**分组，正解是**在分点集合上优化**：
目标写成"组内差异小、组间差异大"，用惩罚项定组数（官方用 `argmax Q(A) − λ(G−1)`，得 G=4）。
聚类既不保证区间连续（业务不可解释），也不优化你真正关心的目标。

**2. 异常判定 ≠ 二分类**
> 2025C 评阅："多选择机器学习算法如 XGBoost、逻辑回归等…**忽略了异常判定与普通分类的区别**，
> **绝大多数队伍**此题完成效果并不理想，未能给出合理的落地判定方案"

罕见事件 + 要控假阳性 → 走**统计判定**：经验零分布（别直接套 N(0,1)）、
按质量指标分层校正、多重检验校正（FDR/Bonferroni）、输出**三级判定**
（阴性/可疑/阳性）、在给定 FPR 下报检出数。ML 只当对照基线且报 AUC/召回。

### 上监督学习前先问：训练标签在哪里

> 2022C 讲评："**数据中只有风化后的数据，缺少风化前的数据与之配对，
> 没有配对的学习样本来建立普通的预测模型。只能通过分布匹配**，在比较强的假设下给出预测"

没有配对样本，就不是监督学习问题。改走**分布/均值匹配**或机理模型，并写明所依赖的假设。

## 五、统计决策类（2024B 型：给参数表、无数据附件）

```
识别决策变量（通常是若干二元决策）
  → 先用逻辑必要条件剪枝
  → 在可行集上全枚举，算期望利润/成本
  → 闭环用不动点迭代或等比级数求解
  → 参数不确定时上贝叶斯（共轭先验），给决策翻转边界
```

- **组合数几十以内就全枚举，别上智能算法**。2024B 官方逐一列出 16 种组合
  （`NNN、NNY、…、NYY_YNY`）。在正文写明"因组合数仅 N，枚举即精确解"本身是得分点。
- **先剪枝再枚举**。官方原文："如果在装配成品时，零配件没有做过检测，
  则**拆解时一定要对零配件做检测**，否则不合格的零配件永远在成品中，
  将会有**无限次的拆解或赔偿**。" —— 先用反证排除不可行组合，再枚举。
- **有回收/退货/返工就是闭环**，一趟流水线算不出期望利润。官方做法是迭代到收敛。
- **"检测次数尽可能少"是在提示序贯抽样**（SPRT）。官方点评：
  "如果学生使用序贯抽样检验…还是一种不错的方法"。
- 参数由抽样得到时，**交付的不是重算一遍数字，而是决策翻转边界**。

## 六、成分数据类（2022C 型：各分量和为常数）

**一旦题面出现"各成分比例累加为 100%""占比之和为 1"，全部方法选择都要改。**
成分数据活在**单纯形**上，不是欧氏空间。

```
剔除无效样本 → 归一化到 100% → 零值用小量 ε 填充后再归一 → CLR 中心对数比变换
  → 在欧氏空间做统计（检验/聚类/相关）→ CLR 逆变换回成分（自动满足定和）
```

- **Pearson 相关必然失真**，有**偏负倾向**。官方极端例子：只有两个成分时 `PCC(x₁,x₂) = −1`。
- **聚类前的变量选择是独立难点**，官方称其为"典型的**无监督变量选择问题**"。
  可行实现：R 型聚类选代表变量 / PLS-DA 的 VIP 重要性 / 主成分**载荷系数**大的原变量。
- **PCA 不是变量选择**。官方："有同学先做主成分分析，然后用几个主成分作为变量进行聚类，
  **这个不是真正的变量选择**"——主成分是全部原变量的线性组合，一个都没剔除。
- 分类变量关联用卡方检验；期望频数不足时改 **Fisher 精确检验**或用 **Yates 校正**。

## 七、贯穿所有题型的两件事

### 1. 解法节奏：从最简情形起步，逐步加约束

- 2025A：1 弹 → 3 弹 → 3 导弹 5 无人机 3 弹
- 2025B：常数折射率 → 非常数折射率 → 多光束干涉
- 2025C：探索性简单回归 → 分段线性 → 非线性混合效应
- 2022A：线性阻尼精确解 → 非线性阻尼 → 纵摇耦合

**每一步都要说清"上一步为什么不够"。** 这正好对上那句"关键是要逻辑清楚、思路清晰"。

### 2. 结果呈现与分析：失分占比最高的地方

2022A 讲评「评阅中发现的问题」共 9 条，其中 **5 条与建模无关**：

> 2. 计算方法不清楚　3. 计算结果不完整　4. 没有很好地呈现结果
> 5. **没有对结果进行分析**　6. **没有结果文件或文件格式不对**

跨年份同一模式：2023B「**没有给出测线的具体坐标，计算方法也不完善**」、
2025A「**没有给出具体算法**」、2025C「**未能给出合理的落地判定方案**」。

**每问算完后必交五件**：
1. 决策变量/结果的**具体数值表**（坐标、时刻、分组边界），不只报聚合结论
2. **计算方法说明**（积分器、步长、初值、收敛判据、环境），写到能复现
3. **结果文件严格按题目命名与格式**（列名、单位、行列顺序）——纯送分/送死项
4. **对结果的分析**：物理业务含义、是否符合直觉、异常点归因、与基线对比
   （数字可追溯性用 `scripts/check_numbers.py` 跑，别靠眼睛核）
5. **稳健性/灵敏度**：参数扰动后结论是否翻转

## 多参数设计题：先做量纲级估算，再开搜索

**实证（2023A 讲评原话）**：

> 密集排布时，光学效率一般不大于 0.65，则要达到 60MW 总输出，
> 镜面总面积需不小于 92300 m²，地面总面积为 353429 m²，因此镜地比要大于 0.2611，
> 由下表知，镜面尺寸需考虑不小于 25m²。而从截断效率考虑，镜面尺寸不宜大于 7×7。

一段话、两个上下界，就把镜面尺寸锁进了 $5\times5$ 到 $7\times7$ 的窄区间。

本项目那轮演练没做这一步，直接从 $6.0$ 扫到 $8.0$ 才发现同一件事，多花约 20 分钟机时。
在 72 小时里这不算致命，但**估算还有第二个作用**：
它给出的是"物理上可能的范围"，搜索给出的是"我这套实现算出来的范围"，
两者对不上就说明实现有问题——这是一个免费的交叉验证。

**做法**：对每个待定参数，用一个粗上界（或粗下界）反解它的可行区间：
效率有上限 → 面积有下限 → 尺寸有下限；某个损失项随尺寸单调 → 尺寸有上限。
不需要精确，数量级对就够用。
