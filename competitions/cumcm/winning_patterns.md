## 0. 选方法前先过这一关：组委会点名的「套路化」清单

2022–2025 四年《参赛和评阅情况》里有**一页一字不改**的幻灯片：

> 顽疾：论文模板化；**方法套路化**。套路与创新是格格不入的。**关键是要逻辑清楚、思路清晰**。
> 表现："n板斧"；盲目追求"高大上"（2025 加 **"盲目使用 AI"**）；**不从"问题"出发，乱套"方法"**：
> - 评价类：**AHP；模糊综合评估；熵权法**；…
> - 数据类：**回归；主成分；聚类；灰色**；…
> - **遗传算法；神经网络；深度学习**；…

**绝不是禁用清单。** 2021C 端到端复现时逐篇核对了四篇一等奖论文的问题一做法：

| 论文 | 重要性模型 |
|---|---|
| C066 | 6 指标 + **TOPSIS** |
| C085 | 4 指标 + **熵权法-TOPSIS** |
| C169 | 8 指标 + **投影寻踪 + 加速遗传算法** |
| C283 | 9 指标 + **熵权法 + AHP 修正** |

**被点名的 AHP、熵权法、TOPSIS、遗传算法，四篇一等奖用了个遍，照样拿一等奖。**
在评价类子问题上，这些是被接受的常规做法。

**组委会批评的是"不从'问题'出发，乱套'方法'"——无理由地套，不是方法本身有罪。**

**唯一判据**：把你的方法段落换到另一道题上，如果照样成立，那就是套路，
Stage 3 打回去补一句"为什么这道题必须用它"，而**不是换掉方法**。

> 曾经的误判：本 skill 早期版本把"避开这些方法"当默认策略，
> 这会误导使用者放弃可行且被认可的做法。同类偏差在 2024B 演练里也出现过
> （把"用正态近似"判为错误，被官方原文否掉）。
> **反模式清单是用来要求给出理由的，不是用来禁用工具的。**

## 1. 五类题的算法主线（Stage 3 用）

先判题型，**题号不等于题型**（2021B 是数据拟合、2022B 是计算几何、2025B 是光学反演）。

### 机理/几何/运动类

`解析表达优先（牛顿定律/微分方程/空间解析几何/坐标变换）` →
`数值求解（龙格-库塔、微元法、变步长遍历、二分/三分）` →
`优化（粒子群/遗传/差分进化，但必须先写清决策变量与目标函数）` →
`几何判别（分离轴定理、离散判别点集）` → `蒙特卡洛验证 + 敏感性分析`

**三条操作技法（2023B 演练实证，前两条我当时栽了）**：

- **极限退化自检是必做步骤**，不是可选项。新引入的角度/参数取边界值时，
  公式必须退化回上一问的简单情形（2023B：β=90° 应退化为平坦 `W=2D·tan(θ/2)`，β=0° 应退化为问题 1）。
  **不执行这一步，三角函数配对错了也发现不了。**
- **推空间几何关系优先用"点法式"**（平面上任意方向与法向内积为零），
  比硬凑三角恒等式直观。2023B 讲评原话："公式推导最简单的方法是'点法式'…
  公式过于复杂会失去直观性，没有给后面的计算带来启发。"
- **曲面问题先分块用平面近似，再复用简单情形的解法**。2023B 问题 4 的官方路线就是
  "分块拟合…用平面近似曲面，再应用问题 3 的求解方法"；分块准则是"每个子海域中的
  等深线要尽量平行，做不到就把子域面积取小"。

2022A 讲评的顺序是先求**精确解**再谈数值。**组合体的几何量（质心、转动惯量、水线面积）通常要自己从几何推**，题目不会直接给——2022A 官方专门用一节算圆柱壳+圆锥壳的质心坐标。**2025A 讲评「评阅中发现的问题」原文点名**：
"直接用数据建立模型"、"**没有给出具体算法**"——写了模型不给算法照样扣分。

**遮蔽/覆盖/可见性类再加四条**（2025A 端到端实证，前三条当时都栽了或没做到）：

- **离散判别点集只取表面**。2025A 讲评："部分参赛队将圆柱体内部点…或**下底面圆的内部点**
  放在离散判别点集中，这些点都是不必要的，**因为导弹是看不到这些点的**。"
  更强的化简是官方给的："只要上下底面的圆周均被遮蔽，则整个真目标也被遮蔽。"
- **能对参数求导解析求极值就别加密采样**。官方对圆周参数 θ 求导，
  把 `max_θ` 化为 sin θ 的 4 次或 2 次方程，"点点判断"变成少数几个点。
- **覆盖判据是 `∀点∃体`，不是 `∃体∀点`**（详见 `anti_patterns.md` **Z19**，
  含"角尺寸比值"这个判断协同有没有空间的现成判据）。讲评说**绝大多数队**栽在这。
- **时长用"网格定位 + 二分细化"，别直接二分**。官方："**二分法不能直接使用**…
  某个时间点不能遮蔽时并不能确定这个时间是下界还是上界…必须改进才能使用。"

**决策变量的解析重参数化**：抛体投放类问题里，
`(航向, 速度, 投放时刻, 起爆延时)` 常与"**起爆点 + 起爆时刻**"一一对应
（`B_z=z0−½gτ²` 定 τ、`|ΔB_xy|/t_e` 定 v），换过去之后可行域只剩几条代数约束、
初值能直接放到视线附近。**这一步比换优化器有用得多。**
注意初值要对准**遮蔽时刻**的视线（云团会下沉，起爆时须高出 `v_sink·Δt`）——
2025A 这一处写错，可行组合从 10150 掉到 111、最优初值从 4.58 s 掉到 2.33 s。

### 工程反演/测量类

`从物理原理推公式` → `先常数情形，再推广到非常数` → `滤波 → 找波峰/波谷 → 计算` →
`牛顿迭代 / 非线性最小二乘 / 三次样条 / 傅里叶变换` → `误差分析 + 可靠性分析`

2025B 讲评专门用一节辨析"**波峰坐标还是波谷坐标**"——这种细节辨析才是得分点。

### 数据/统计/决策类

**先判断要不要预处理**（这一条 2025C 演练**两个方向都栽过**）：

判据不是"附件长什么样"，而是**这一步是统计习惯，还是领域方法的组成部分**：

| 步骤性质 | 做不做 |
|---|---|
| 常规统计预处理：去重、插补、类别平衡、按分位删异常值 | **不做**。2025C 讲评原文："对问题附件中的数据**无需进行清洗、删补、平衡等常规的、无益于问题解决的预处理**" |
| 原始流水/交易数据的聚合与口径统一（2023C 零售流水） | **做**——这是建模的一部分，不叫预处理 |
| 领域方法内在要求的质控（2025C 问题 4 的测序质量 QC） | **做**，并写明依据 |

**关键：上面那句"无需预处理"不能泛化到所有子问题。** 同一份 2025C 讲评里，
官方解问题 4 的第一步就是质控——对读段数 L、比对比例 M、唯一比对读段数 O 保留 ≥Q05，
对重复读段比例 N、过滤读段比例 AA 保留 ≤Q95 的「中心 90% 截断」，604 例筛到 501 例。
把末页那句话当成"任何子问题都不筛"，会整条丢掉问题 4 的解法路线（详见 `anti_patterns.md` Z18）。

另一半判据仍然成立：**建模用**的时候，"质量指标"列（GC 含量、读段数、过滤比例）
多半是给你做分层校正的协变量，不是筛样本的门槛；**判定流程的质控**里它们才是门槛。
同一列两种用法可以并存，取决于这一问在做什么。

**这一类有两条命中率最高的反模式，Stage 3 必须先排除**（详见 `anti_patterns.md` Z1/Z2）：

- **有序连续变量（BMI/年龄/孕周）分组不能用聚类**。2025C 评阅原文：
  "**超半数队伍**选择 K-means、层次聚类…整体答题情况较为一般"。
  正解是在分点集合上优化："组内差异小、组间差异大" + 惩罚项定组数。
- **"异常判定"不是二分类**。2025C 评阅原文："…忽略了异常判定与普通分类的区别，
  **绝大多数队伍**此题完成效果并不理想"。走统计判定：经验零分布 + 分层校正 +
  多重检验校正 + 三级判定（阴性/可疑/阳性）。

主线：`分布刻画（先分离时间效应 → 分布拟合 → K-S 检验）` → `相关性（非正态用 Spearman）` →
`预测（Prophet / ARIMA / 混合效应模型）` → `决策（报童模型 / 随机规划 / CVaR / 期望损失最小化 / NSGA-II）` →
`风险（贝叶斯+共轭先验 / 蒙特卡洛 / 3σ）`

### 统计决策类（2024B 型：给参数表、无数据附件）

`识别决策变量（通常是若干二元决策）` → **`先用逻辑必要条件剪枝`** →
`在可行集上全枚举，算期望利润/成本` → `闭环用不动点迭代或等比级数求解` →
`参数不确定时上贝叶斯（共轭先验）并给决策翻转边界`

- **组合数小（几十以内）就全枚举，别上智能算法**。2024B 官方解法就是逐一列出 16 种组合
  （`NNN、NNY、…、NYY_YNY`）算期望利润。在正文里写明"因组合数仅 N，枚举即精确解"本身是得分点。
- **有回收/退货/返工就是闭环**，一趟流水线算不出期望利润。官方做法是迭代到收敛：
  "每次装配都会再次产生次品，直到没有次品，迭代结束"。
- **"检测次数尽可能少"是在提示序贯抽样**（SPRT）。官方点评："如果学生使用序贯抽样检验…
  还是一种不错的方法"。
- 参数由抽样得到时（2024B 问题 4），**交付的不是重算一遍数字，而是决策翻转边界**。

### 特殊数据类：成分数据（2022C 型，各分量和为常数）

**一旦题面出现"各成分比例累加为 100%""占比之和为 1"，全部方法选择都要改。**
成分数据活在**单纯形**上，不是欧氏空间。官方原话：
"成分数据是在单纯形空间上取值，一般采用**中心对数比变换(CLR)**转换到低一维的欧氏空间"。

固定流水线：

`剔除无效样本 → 归一化到 100% → 零值用小量 ε 填充后再归一 → CLR 变换 →
在欧氏空间做统计（检验/聚类/相关）→ CLR 逆变换回成分（自动满足定和）`

- **Pearson 相关在成分数据上必然失真**，有**偏负倾向**。官方极端例子：只有两个成分时
  `PCC(x₁,x₂) = −1`。要算相关必须先 CLR。
- **无配对样本就不能用监督学习**。2022C 问题 1 要"预测风化前成分"，官方判据是数据结构层面的：
  "**数据中只有风化后的数据，缺少风化前的数据与之配对，没有配对的学习样本**" →
  只能做**分布/均值匹配**：`CLR_目标 = CLR_观测 + Δmean`，再逆变换。
  这也是为什么"简单套用机器学习方法进行预测，是完全错误的"。
- **聚类前的变量选择是独立难点**，官方专列一节称其为"典型的**无监督变量选择问题**"。
  可行实现：R 型聚类选各类代表变量 / PLS-DA 的 VIP 重要性 / 主成分**载荷系数**大的原变量。

## 2. 贯穿所有题型的解法节奏

命题人的解法骨架**几乎都是「从最简情形起步，逐步加约束」**：

- 2025A：1 弹 → 3 弹 → 3 导弹 5 无人机 3 弹
- 2025B：常数折射率 → 非常数折射率 → 多光束干涉
- 2025C：探索性简单回归 → 分段线性 → 非线性混合效应
- 2022A：线性阻尼精确解 → 非线性阻尼 → 纵摇耦合

**照这个节奏组织正文最安全**，也正好对上那句"关键是要逻辑清楚、思路清晰"。
每一步都要说清"上一步为什么不够"。

## 2.5 结果呈现与分析（Stage 5–7 用）★ 这一节的失分占比最高

**跨年份统计**：2022A 讲评「§6 评阅中的问题」共 9 条，其中 **5 条与建模无关**，
是"算完之后怎么呈现和解释"：

> 2. 计算方法不清楚　3. 计算结果不完整　4. 没有很好地呈现结果
> 5. **没有对结果进行分析**　6. **没有结果文件或文件格式不对**

同一模式跨年重复出现：

- 2023B §6.3：「**没有给出测线的具体坐标，计算方法也不完善**。只是说明：34 条（68 海里）是最优结果」
- 2025A §9：「**没有给出具体算法**」
- 2025C：「**未能给出合理的落地判定方案**」

### 每问算完后必须交付的五件东西

1. **决策变量/结果的具体数值表** —— 坐标、时刻、分组边界、参数值，
   逐个列出。只报"最优值是 68 海里"这类聚合结论等于不可核验。
2. **计算方法说明** —— 用了什么积分器/求解器、步长、初值、收敛判据、
   运行环境。写到别人能照着复现的程度。
3. **结果文件严格按题目要求命名与格式** —— `result1-1.xlsx`、`result1.xlsx` 之类，
   列名、单位、行列顺序都照模板。这条是纯送分/送死项。
4. **对结果的分析，而不只是罗列** —— 结果的物理/业务含义是什么、
   是否符合直觉、异常点怎么解释、与基线相比如何。**"没有对结果进行分析"是官方原话点名的第 5 条。**
5. **稳健性/灵敏度** —— 关键参数扰动后结论是否翻转（一等奖摘要里 32% 会提，
   提了是加分）。

### 呈现上的两条硬要求

- **图要能读**：坐标轴含义、单位、图例齐全；对比类结果画在同一张图上；
  等高线/热力图优于一堆数字（2024C、2023C 一等奖图数 p50 分别是 19、32）。
- **数值要能追溯**：摘要与正文里出现的每个数字，都要能在结果表或结果文件里找到同一个值。
  **别靠眼睛核**，跑 `python <skill>/scripts/check_numbers.py --paper paper.tex --results results/`；
  论文里的数字多半是从终端手抄进 LaTeX 的，抄错一位不会报错。

## 3. 摘要（Stage 8 用）

44 篇一等奖摘要的实测成分命中率：

| 成分 | 命中率 |
|---|---|
| 用"本文/首先"起句 | 98% |
| **写出具体数值结果** | **91%** |
| 用"针对问题一/二…"分段 | 86% |
| 明写"建立了……模型" | 82% |
| 提灵敏度/稳健性 | 32% |
| 写"模型评价/优缺点" | **仅 11%** |
| 提"创新" | **仅 5%** |

字数中文 p25/p50/p75 = **848 / 927 / 1010**；关键词 p50 = 4 个。

骨架：`开场 2–4 句（背景 + 本文建立了什么框架）` → `针对问题一…四：目标 → 模型 → 算法 → 具体数值` →
`可选创新点（有正文支撑才写）`。

**每个"针对问题"段必须落到数字**——这是评委在摘要页唯一能核验的硬信息。
**别在摘要写模型评价**（只有 11% 这么做，那是正文倒数第二章的事）；
**别硬凑创新点**（只有 5% 提；组委会把"声称创新却无正文证据"列为反模式）。

## 4. 正文结构分位（Stage 4–8 用）

官方展示论文（44 篇）：主章节 p50 **10**、子章节 p50 **31**、公式块 p50 **49**、
表 p50 **9**、图 p50 **20**、参考文献 p50 **4**、全文中文 p50 **12799** 字。

常见骨架：`摘要 → 问题重述 → 问题分析 → 模型假设 → 符号说明 →
（按子问题展开建模与求解）→ 模型检验/稳健性 → 模型评价与推广 → 参考文献 → 附录`。

拉开差距的不是有没有这些章节，而是每章内部有没有闭环：
**定义问题 → 建立数学对象 → 给出结果 → 回到题意解释**。

## 5. 可信度边界（必须遵守）

- 散文与结论来自 OCR，可信。
- **公式不可直接引用**：OCR 对复杂公式有错误（2025A 讲评的导弹位移方程就串了）。
  要用公式请回 资料库的 `2_官方讲评/`、`3_优秀论文/官方展示/` 原 PDF 核对（这两处体积大，不随 skill 分发，见 `assets/official/README.md`）。
- 2025 年官方展示样本仅 5 篇，**不做跨年份质量比较**。
- 章节识别约 85–90% 干净，单篇引用前先看一眼。
